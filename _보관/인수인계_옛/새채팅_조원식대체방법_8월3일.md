# 3. 확정된 사실 (전부 계산으로 재현됨)

## 3-1. 두 식의 출처

**식(2) = `P_control1`** — 타깃 `PT-1004 − 25 − PT-1100`, 회귀변수 (T, F_kmol/h, z_BEN), 전체 3,066행:

| 계수 | 재현값 | 시뮬 값 |
|---|---|---|
| 절편 | −60.2700 | −60.3808 |
| T | +0.08499 | +0.08516 |
| F | +0.21425 | +0.21436 |
| z | +5.5689 | +5.60222 |

R² = 0.99906, RMSE = 0.0922 kPa → **사실상 완전 일치. 출처 확정.**

**식(1) = `P_control2`** — 타깃 `PT-1100`, 같은 변수. 유량·조성 계수는 일치(+8.747 vs +8.7337, +875.6 vs +887.0), 절편·온도 계수는 불일치. R² = 0.99890. (원인 미확정)

`25 kPa` = HX-1005 튜브측 DP 0.25 bar **[주어짐]** rev2 Appendix B Table 4

## 3-2. 식(1)은 삭제해야 한다 — 이건 결론 남

**상류 압력 체인이 입구압을 이미 결정한다:**
```
R-1100.In.P = 3100(PROPENE.P) − 539.379862691488(FCV-1004.DP) − 25(HX-1005)
            = 2535.6201373085
.simx 파일값 = 2535.6201373085119        ← 13자리 일치
```

→ `Out.P = In.P − DP` 로 자동으로 닫힌다. 출구압 지정은 방정식 1개 초과.

**검증셋 출구압 예측 오차:**

| 방식 | 오차 |
|---|---|
| 식(1) 직접 예측 | **5.137 kPa** |
| (In.P − 식(2)) | **0.103 kPa** |

**50배 차이.** 출구압 변동 435 kPa 중 반응기 기여는 27.5 kPa (6.3 %) 뿐이라, 절대압 0.275 % 오차가 ΔP 기준 **24.4 %** 가 된다.

## 3-3. 식(2)의 변수가 물리적으로 근거 있다

Ergun 관성항을 반응기 입구 상태량으로 정리하면:
```
ΔP ∝ G²/ρ,  G = ṁ/Ac,  ρ = P·MW/(RT),  ṁ = F_kmol·MW
   ⇒  ΔP ∝ F_kmol² · MW · T / P
```

| Ergun 이 요구 | 식(2) 변수 | 관계 |
|---|---|---|
| T | `.T` | 그대로 |
| F_kmol | `.F × 3600` | 그대로 |
| **MW** | **`z[BENZENE]`** | **MW = 42.182 + 35.933·z, 상관 +1.000000** |
| P | (절편에 흡수) | ΔP/P_in = **1.11 %** (사실상 등압) |

**계수 3개 부호가 전부 물리와 일치:**

| 계수 | 값 | 물리 |
|---|---|---|
| b_T | +0.08516 | 온도↑→밀도↓→유속↑→ΔP↑ ✓ |
| b_F | +0.21436 | 질량속↑→ΔP↑ ✓ |
| b_z | +5.60222 | z↑→MW↑→(F 고정) ṁ↑→ΔP↑ ✓ |

## 3-4. ⚠️ 그런데 "Ergun 유도"라고 주장하면 안 된다

적합 계수를 역산하면:
```
(1−ε)/(d_p·ε³) = 23,265 1/m
```

| ε | 대응 d_p | 판정 |
|---|---|---|
| 0.35 | 0.65 mm | 통상 촉매(1~5 mm)보다 작음 |
| 0.40 | 0.40 mm | 비현실적 |
| 0.45 | 0.26 mm | 비현실적 |

**절편이 −23.23 kPa 인데 물리항 평균 기여가 +50.69 kPa 다.** 순수 Ergun 에는 절편이 없다.

절편 없이 강제하면 ε=0.35 에서 d_p=1.18 mm 로 그나마 그럴듯해지지만 **검증 RMSE 가 2.582 kPa 로 16배 악화**된다.

**원인:** 라벨이 순수 촉매층 ΔP 가 아니다.
`PT-1004` 는 Appendix A 상 **"Pressure of propene feed stream"** 이며 PFD Figure 1 에서 FCV-1004 하류·벤젠 합류 티 앞이다. **반응기 입구 압력 계기는 존재하지 않는다.**
따라서 라벨에 배관·믹서 손실 + HX-1005 사양값 편차 + Ergun 점성항이 섞여 있고 절편이 이를 흡수한다.

**다만 이 상수는 기울기에 영향을 주지 않는다:**

| 차감량 | 절편 | b_T | b_F | b_z |
|---|---|---|---|---|
| 0 kPa | −35.1931 | **+0.089271** | **+0.212507** | **+4.08484** |
| 25 kPa | −60.1931 | **+0.089271** | **+0.212507** | **+4.08484** |
| 50 kPa | −85.1931 | **+0.089271** | **+0.212507** | **+4.08484** |

소수점 6자리까지 동일.

## 3-5. 정확도와 물리 검사

| 항목 | 값 |
|---|---|
| 학습 R² | **0.99821** |
| 검증 캠페인 RMSE | **0.1549 kPa** (ΔP 평균 27.45 kPa 의 0.56 %) |
| 물리군 `F²·MW·T/P` 2모수 모델과 예측 상관 | **0.999394** |
| 케이스 격자 9슬라이스: B/P↑→ΔP↓ | **9/9 ✓** |
| 케이스 격자 9슬라이스: 총유량↑→ΔP↑ | **9/9 ✓** |

**실측 확인:** 총유량 17,800~18,200 kg/h 에서 B/P 4.5→5.5 일 때 ΔP 29.85 → 28.46 kPa (MW 67.99 → 68.78)

# 4. 입력 변수에 대해 지금까지 확인된 것

## 4-1. 입력 형태별 비교 (검증 = 10/17-18)

| 형태 | 검증 RMSE | B/P↑→ΔP↓ | 총유량↑→ΔP↑ |
|---|---|---|---|
| **식(2): (T, F_kmol, z_BEN)** | **0.1549 kPa** | **9/9 ✓** | **9/9 ✓** |
| (T, 프로펜유량 FT-1004, B/P) | 0.1479 | **0/9 ✗** | 9/9 |
| (T, 총질량유량, B/P) | 0.1910 | 9/9 ✓ | 9/9 |
| (T, F, B/P, F·B/P) | 0.1376 | 9/9 ✓ | 9/9 |
| 물리군 절편+F²·MW·T/P (2모수) | 0.1791 | 9/9 ✓ | 9/9 |

**(T, 프로펜유량, B/P) 가 0/9 인 이유:** ΔP 는 총유량 = F·(1+R) 이 정하는데, (F, R) 을 1차로만 넣으면 이 **곱**을 표현할 수 없다.

**식(2) 는 이 문제가 없다.** F_kmol 이 총질량유량에 거의 비례하고 z 가 B/P 의 함수이므로, (T, F_kmol, z) 는 사실상 (T, 총유량, B/P) 의 재파라미터화다.

```
총유량 18,000, B/P 4 →  프로펜 3,600.0 kg/h,  F_kmol 269.69,  z_BEN 0.68354
총유량 18,000, B/P 6 →  프로펜 2,571.4 kg/h,  F_kmol 258.47,  z_BEN 0.76415
```

## 4-2. 검토했으나 배제된 입력

| 후보 | 배제 사유 |
|---|---|
| 밀도 ρ 추가 | 반응기 입구 밀도 계기 없음. 이상기체 계산 시 AVEVA SRK 와 **9.24 % 차이** (이상기체 32.593 vs SRK 35.936 kg/m³, Z ≈ 0.908). ΔP ∝ 1/ρ 이므로 곧 2.5 kPa 오차 |
| 압력 추가 | 케이스스터디가 압력 미지정. 개선폭 0.148 → 0.109 kPa (0.14 %p). ⚠️ `(T,F,R,PT-1004,PT-1100)` 5입력은 RMSE 0.0000 이 나오는데 이는 **라벨 정의를 되먹인 데이터 누출** |

## 4-3. ⚠️ 새로 발견된 문제 — z 의 학습/사용 불일치

**이게 새 채팅에서 다뤄야 할 핵심이다.**

| | z[BENZENE] |
|---|---|
| **학습 시** (FRC-1004 에서 대수 계산) | 0.72973 |
| **사용 시** (`.simx` 플로우시트 값) | **0.715766** |
| 차이 | **0.013964** |
| ΔP 로 환산 (× b_z 5.60222) | **0.078 kPa** |
| 모델 자체 RMSE 대비 | **50.5 %** |

**원인:** 학습 시 우리는 벤젠+프로펜+프로판만으로 z 를 계산하는데, 플로우시트의 `HX-1005_Tube_Out` 에는 **재순환에서 온 큐멘이 0.43 %** 들어있다.

```
.simx 스냅샷:  HX-1005_Tube_Out.Fc[BENZENE] = 0.0524445272201833
               HX-1005_Tube_Out.Fc[CUMENE]  = 0.00031548583567214585
               HX-1005_Tube_Out.F           = 0.07327055062136692
               → z_BEN = 0.715766,  z_CUM = 0.004306
```

**즉 "계측기가 없다"가 문제가 아니라, "학습과 사용의 정의가 다르다"가 문제다.**

이건 **현재 식(2)에도 이미 있는 문제**다 — ONNX 로 바꾸든 안 바꾸든 해결해야 한다.

# 5. 검토해야 할 입력 후보 (§Q1, Q2)

| # | 입력 | 장점 | 검토 필요 사항 |
|---|---|---|---|
| A | (T, F_kmol, z_BEN) ← 현재 | 성능·물리 모두 통과 | **z 의 학습/사용 불일치 (§4-3)** |
| B | (T, F_kmol, **MW_avg**) | 물리가 직접 요구하는 변수. 양쪽에서 동일하게 정의 가능 | 성능·물리 검사 미실시 |
| C | (T, **총질량유량 ṁ**) 2변수 | ṁ = F_kmol × MW 이므로 두 변수를 하나로 합침. 가장 직관적 | 조성 정보가 사라짐. 성능 확인 필요 |
| D | (T, ṁ, MW_avg) | C + 조성 | 미실시 |
| E | (T, **ṁ²/ρ**) 물리군 1개 | Ergun 형태 그대로. 2모수 | ρ 계산에 SRK 필요 → 학습/사용 불일치 위험 |
| F | (T, 총질량유량, B/P) | 계측에 가장 가까움 | 0.1910 kPa (약간 나쁨), 9/9 통과 |

**우선 검토 대상: B 와 C.**
- B 는 z 대신 MW 를 직접 쓰므로 물리 서술이 깔끔해지고, 플로우시트에서도 `MW` 를 직접 읽을 수 있어 정의 불일치가 줄어든다.
- C 는 변수가 2개로 가장 단순하고 직관적이다. "유량이 많으면 압력이 더 떨어진다" 한 줄로 설명된다.

# 6. 식을 대체할 방법 후보 (§Q3)

| # | 방법 | 상태 |
|---|---|---|
| 1 | **식(2) 유지 + 설명 붙이기** | 가능. §3 이 근거 |
| 2 | **ONNX2 로 옮기기** | 가능. 입력을 바꾸지 않으면 **성능 손실 0** (동일 0.1549) |
| 3 | AVEVA 내장 `Process.RxnDP` | **불가** — §6-1 참조 |
| 4 | ΔP 를 상수 스펙 | **불가** — 케이스 범위에서 20.9 → 29.3 kPa 로 40 % 변함 |
| 5 | 순수 Ergun (절편 없음) | **불가** — 검증 RMSE 2.582 kPa (16배 악화) |
| 6 | 입력을 바꾼 새 상관식 (§5 의 B~F) | **미검토** ← 새 채팅에서 할 것 |

## 6-1. 내장 `Process.RxnDP` 를 못 쓰는 이유

```
HX-1005_Tube_Out.W  = 5.0 kg/s      (= 18,000 kg/h, 실제 반응기 유량)
R-1100.DPcalc.W[1]  = 6.3496 kg/s   (= 22,858 kg/h, 27 % 큼)
R-1100.DPcalc.F[1]  = 0.07327 kmol/s   (= R-1100.In.F, 입구 몰유량)
R-1100.DPcalc.MW[1] = 86.66 kg/kmol    (= 5.0/0.05770, 출구 분자량)
```

**입구 몰유량 × 출구 분자량** → 질량 보존 위반. 반응기 입구 실제 평균분자량은 68.24 kg/kmol.
ΔP ∝ W² 이므로 (6.3496/5.0)² = **1.61배 과대평가** 우려.

(⚠️ AVEVA 내부 변수 정의가 다를 가능성 배제 못 함. 다만 숫자 관계가 위와 같이 정확히 떨어진다.)

## 6-2. ONNX2 로 옮기는 것의 실질 이득

| | 커스텀 수식 유지 | ONNX2 |
|---|---|---|
| 플로우시트 커스텀 `<Equation>` | 1개 | **0개** |
| 대회 §3.3-5 서술 | "수식 1개 + ONNX 1개" 혼합 | **"ML 모델 2개"로 통일** |
| 심사 질문 | "그 수식은 뭐냐" | "ML 모델 출력입니다" |
| 성능 (입력 동일 시) | 0.1549 | **0.1549 (동일)** |

⚠️ **정직하게 쓸 것:** ONNX 로 감싸도 내용은 4계수 선형식이다. "ML 로 압력강하를 예측했다"고만 쓰면 과장. ONNX 를 택한 것은 커스텀 방정식을 남기지 않고 전환율 모델과 형식을 맞추기 위함이라고 명시.

# 9. 별건 — 함께 처리할 시뮬레이션 문제

`FCV-1004.DP = 539.379862691488` 이 **고정 스펙**이다. 고정이면 유량을 올려도 반응기 압력이 안 오른다.

**실측은 반대다:**

| B/P 5±0.05, T 350±3 °C | 평균 총유량 | PT-1004 |
|---|---|---|
| 저유량 (n=110) | 16,200 kg/h | 2,332.8 kPa |
| 고유량 (n=95) | 18,000 kg/h | **2,561.3 kPa** |

corr(총유량, PT-1004) = **+0.9988** (10/13 +0.9999, 10/17-18 +0.9973)

**확인 방법:** 케이스스터디를 15,000 / 18,000 kg/h 로 돌리고 `R-1100.In.P` 를 본다.
안 변하면 밸브를 Cv 기반으로 바꾼다. 기준: 15,000 → 18,000 에서 반응기 압력 약 **+18 %** 상승.

> ⚠️ **2026-08-04 정정 — 기존 "+9~10 %"는 시작점 오인용.** 위 표는 **16,200 → 18,000**(+9.8 %)이고
> 이 문장은 **15,000** 기준이다. 실측 15,000 → 18,000 은 **+17.9 %**(밴딩) / **+18.35 %**(선형적합).
> 근거표는 `ONNX2_만들기_폐기_2026-08-01.md` §4-6, `results/stage1_비재현목록.md` #12.

방치 시 15,000 kg/h 조건에서 하류 스트림 압력이 **15~17 % 틀어진다.**
rev2 §3.2 가 "각 스트림의 온도·압력·상·조성이 기술적으로 타당해야 한다"고 요구하므로 감점 요인.
