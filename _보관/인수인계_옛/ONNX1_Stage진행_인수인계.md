# 2. 절대 규칙 (CLAUDE.md 요약 — 반드시 준수)

1. **원본 대회 파일 수정 금지** (rev2 PDF, Attachment1 CSV, .simx)

7. 모든 수치는 코드로 재계산 검증. 기존 값이 재현 안 되면 **재현값을 따르고 그 사실을 명시**

### ⚠️ 물리 단조성 방향은 실측에서 유도했다 (일반론과 반대)

```
밴드(B/P 5±0.05, T 350±3): 총유량 16200 → 18000 kg/h 일 때 X 0.7423 → 0.8370 (증가)
corr(총유량, PT-1004) = +0.9988,  corr(총유량, X) = +0.9256
```

원인: 유량↑ → FCV-1004 개도↑ → 밸브 손실↓ → 반응기 압력↑ → 속도↑

**따라서 기준은 "총유량↑ → X↑". "총유량↑ → X↓"(체류시간 일반론)는 이 공정에서 성립하지 않는다.**

### 큐멘 kg/h 유도

```
큐멘 [kg/h] = X × n_propene_kmol_h × 120.196
  n_propene_kmol_h = 0.94773 × FT-1004.PV / 42.081
  0.94773 [계산] Appendix B Table 3 (0.95/0.05 mol) 에서 유도
  42.081, 120.196 [주어짐] AVEVA 물성
  1:1:1 몰비 [주어짐] rev2 §1
```
⚠️ 이건 **반응기 출구 기준 생성량**이며 제품유량 `FT-1201`(평균 4950.4)과 다르다 (차이 −1.91%, 상관 0.858, 시간지연 때문).

# Stage 2 — 타깃 변환 비교
##############################################
고정: 입력 I1 = [TT-1006.PV, FT-1004.PV, FRC-1004.PV], 주 분할, Stage 0 프로토콜 전부
대상 모델: Stage 1 상위 4개 (블록20% 기준). 최소한 Ridge Poly2, Linear1, Linear2 는 포함할 것

비교할 타깃 변환 5종:
  (a) raw        : y = X 그대로
  (b) logit      : z = log(y/(1-y)), 예측은 sigmoid.  ← 현재 채택안, eps=1e-6 클립
  (c) log        : z = log(y),          예측은 exp
  (d) log(1-y)   : z = log(1-y),        예측은 1-exp
  (e) arcsin√y   : z = arcsin(sqrt(y)), 예측은 sin(z)^2

각 (모델 × 변환) 조합에 Stage 0 의 0-2~0-6 을 전부 적용:
  - 지표: 전환율 RMSE/MAE/MAPE/R²/최대오차 + 큐멘 kg/h RMSE (반드시 전환율 원 스케일에서 계산)
  - 불확실성: 블록 잭나이프 60분(주) + 120분, 부트스트랩 60분(교차)
  - 승자 선택: 블록20% 로만. 검증셋은 확인용
  - LOCO-5 강건성 열
  - 캠페인 민감도
  - 물리 검사 27점 (총유량↑→X↑ 방향 주의. 실측에서 유도된 기준이며 일반론과 반대)
  - ONNX 변환 가능 여부 (변환 파이프라인이 변환마다 다름 — 역변환 노드를 ONNX 그래프에 붙일 수
    있는지 반드시 실제로 확인할 것. 붙일 수 없으면 대회 §3.1 미충족으로 별도 열)

⚠️ 이 단계의 핵심 질문은 RMSE 가 아니라 "예측이 물리적으로 가능한 범위에 머무는가" 다:
  - 케이스스터디 상한 365°C 는 학습 최대 349.977°C 를 넘는 외삽이다

  - logit·arcsin 은 구조적으로 (0,1) 에 가둔다. 이 "구조적 안전성"이 성능보다 중요한 선정 근거다
  - Stage 1 에서 Poly3 가 block20 11위인데 검증 22위였던 사례(외삽 발산)를 참고할 것
