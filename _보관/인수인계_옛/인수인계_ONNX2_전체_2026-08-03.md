## 1-1. ONNX2 제작 확정 (08-01 "안 만듦" 결정을 뒤집음)

- **입력 = (입구온도 TT-1006, 총질량유량, 벤젠/프로펜 비율 FRC-1004). z(벤젠 몰분율) 폐기.**
- **정직한 맞바꿈(보고서에 명시할 것):** z 가 검증 RMSE 0.036 kPa 더 정확하다(z 0.1549 vs 총유량 0.1910).
  그럼에도 총유량을 택한 이유:
  1. 총유량은 계기 두 개 합(FT-1003+FT-1004)이라 투명하고, z(몰분율)처럼 "분석기 필요" 오해가 없다.

  3. 전환율 모델과 형식(2 ONNX) 통일 → 플로우시트 커스텀 방정식 0개.

  차이 0.078 kPa = 모델 RMSE 의 50%. 총유량·FRC 는 이 문제가 없다.

## 1-2. DP 모델 형태·계수 (데이터로 확정·검증됨)

- **모델 = 선형 1차.** 제곱항 추가 시 악화(0.1910 → 0.2027)로 확인. 로짓 등 변환 없음(ΔP kPa 직접).

- **계수 (학습 10/13-16, 1924행):**
  ```
  ΔP[kPa] = −52.500 + 0.090071·T[°C] + 0.00311059·총유량[kg/h] − 1.00681·(B/P)
  ```

  검증(10/17-18) RMSE = **0.1910 kPa** (재현 확인). 학습 R² = 0.99694.
  배포 최종본은 전 캠페인(10/13-18) 재학습 → 절편만 −52.50 → **−51.73** 이동, 기울기 거의 불변.

- **물리검사 27점 격자:** 총유량↑→ΔP↑ **9/9**, B/P↑(총유량고정)→ΔP↓ **9/9**. 예측범위 20~33 kPa(실측 19.89~31.48 정합).

## 1-5. AVEVA 배선 — 이번에 밝혀낸 것 (제작 후 필수)

**(a) 순환식 삭제.** 시뮬에 `Eqn1: PT1100.PV − "R-1100_in".P = "R-1100".DP` 를 넣으면 DP=0 으로 붕괴한다.
  이유: 출구압(PT1100) = 입구압 − DP 인데, DP 를 그 출구압으로 정의하면 `DP = (In−DP) − In = −DP → DP=0`.
  **DP 를 출구압으로 정의하면 안 된다(순환).** 이 식은 삭제.

**(b) 자유도.** 압력망은 {입구압 P1, 출구압 P2, DP} 에 `P2 = P1 − DP` 하나 → 2개를 정해야 함.
  - **P1 은 상류가 이미 정한다:** `3100(프로펜소스) − 539.38(FCV-1004) − 25(HX-1005) = 2535.62 kPa` (파일값 13자리 일치).
  - **DP 는 ONNX2 가 준다.** → P2 는 자동 계산. **ONNX2 출력 1개면 spec 이 닫힌다**(P1 은 상류가 채웠으므로).
  - 팀 식(1)(출구압 직접 지정)은 방정식 1개 초과 → **삭제.**

**(c) DPModelType.** 현재 `Process.RxnDP`. → **"DP 외부 입력" 모드로 변경**해 ONNX2 의 DP 를 쓰게 한다.
  RxnDP 는 쓰지 말 것(입구몰유량×출구분자량 → 질량 6.35 vs 실제 5.0 kg/s, ΔP∝W² 이라 1.61배 과대).
  ⚠️ 정확한 옵션명은 AVEVA Process 문서 확인 필요(미해결).

**(d) FCV-1004 (별건, 병렬 진행).** `FCV-1004.DP = 539.38` 고정 스펙이라 유량 올려도 반응기 압력이 안 오른다.
  실측은 corr(총유량, PT-1004)=+0.9988. **밸브를 고정 DP → Cv 기반으로** 바꿔 PT-1004 가 유량 따라 변하게.
  PT-1004 직접 스펙을 그냥 지우면 미결정 → **Cv 밸브 모델로 자유도를 채운 뒤** PT-1004 를 계산값으로.
  검증: 케이스 15,000/18,000 kg/h 에서 입구압 약 **+18%** 상승하면 성공. 방치 시 rev2 §3.2 위반 감점.
  ⚠️ 2026-08-04 정정: 기존 "+9~10%"는 **16,200→18,000**(+9.8%) 값을 15,000 기준 문장에 잘못 붙인 것.
     실측 15,000→18,000 = **+17.9%**(밴딩, n=2,476) / **+18.35%**(선형적합). `stage1_비재현목록.md` #12.

**(e) `P_control2` 제거 검증 완료 (2026-08-04).** 가설대로였다.
  - `P_control2` 삭제 → 스펙 1개 부족(AVEVA 문서 p.99 "방정식 1개 = 변수 1개" 규칙대로).
  - **Changed Specifications 의 SpecSet 15 에는 `FCV-1004.DP` 단 하나**뿐이었다.
    → `P_control2`(출구압 직접 지정)가 압력망 자유도를 잠식해 밸브 DP 를 계산값으로 밀어내고 있었음이 확정.
  - `FCV-1004.Cv` 를 사양으로 지정하니 **Input·Spec·Solved 전부 통과.**
  - 즉 `P_control2` 는 없어도 되는 식이었을 뿐 아니라, **있어서 FCV-1004 를 망가뜨리고 있었다.**
    (d) 의 FCV 문제와 `P_control2` 제거는 별건이 아니라 같은 원인이었다.

## 1-6. ONNX1 Stage 3·4 결과 (참고)

```
    (a)(b) 행별 최대차·평균차% (문서 0.0102% 재현).
  ⚠️ 런타임에 ONNX2 가 받는 입력은 반응기 입구 스트림 질량유량 R-1100_in.W (재순환 포함 가능).
     (a)(b)(신선공급)와 R-1100_in.W 정의가 같은지, 재순환으로 얼마나 벌어지는지 따져 kPa 로 환산 보고.
     (학습·런타임 총유량 정의 불일치가 있으면 그 크기 명시 — z 버린 이유와 같은 검사. 재순환가정_민감도.md 참조)
  캠페인별 스윕 표(10/13 유량/10/14 고정/10/15 유량+B/P/10/16 온도/10/17-18 온도+유량).

# 3. DP 거동
  분포·이상치. 상관 ΔP vs (온도·총유량·FRC), 캠페인 내부 상관도.
  물리 방향 원자료 확인: 총유량↑→ΔP↑ / 총유량고정 후 B/P↑→ΔP↓
    (실측 재현: 총유량 17800~18200 에서 B/P 4.5→5.5 일 때 ΔP 29.85→28.46).
  시계열: 잔차 자기상관 1분·60분, 과도 구간 유무(참고만, 최종은 전데이터 무가중).

# 4. 물리군 대조

  ⚠️ "Ergun 유도"라고 쓰지 말 것.

# 5. 모델 스크리닝 (선형 충분한지 — 최종선택 아님)
```
