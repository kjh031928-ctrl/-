## 3. 식(2)를 유지하는 근거

### 3-1. ⚠️ 먼저 — d_p 와 ε 는 가정하지 않는다

**이게 이 방식의 핵심이다.** Ergun 식을 쓰면 촉매 입자경 d_p 와 층 공극률 ε 가 필요한데, 문제(Appendix B Table 5)는 튜브 수(234), 튜브 지름(76.2 mm), 층 길이(2 m), 촉매 밀도(1,600 kg/m³)만 주고 **d_p 와 ε 는 주지 않는다.**

그런데 Ergun 식을 정리하면 이 둘은 **항상 뭉친 형태로만 나타난다:**

$$\Delta P = \underbrace{\frac{150\,\mu L(1-\varepsilon)^2}{d_p^2\varepsilon^3}}_{=\,A}\cdot u \;+\; \underbrace{\frac{1.75\,L(1-\varepsilon)}{d_p\varepsilon^3}}_{=\,B}\cdot \rho u^2$$

**A 와 B 를 데이터로 적합하면 d_p 와 ε 를 개별로 알 필요가 없다.**
팀 식의 4개 계수가 바로 이 뭉친 상수들에 해당한다.

| 값 | 성격 |
|---|---|
| Ergun 상수 150, 1.75 | 문헌값 (Ergun 1952). 가정 아님 |
| L = 2 m, D = 76.2 mm, N_t = 234 | **주어짐** (Appendix B Table 5) |
| **d_p, ε** | **주어지지 않음 → 가정하지 않고 계수에 흡수** |

> ⚠️ 이전 분석 문서에서 Re_p 크기를 어림하려고 d_p = 3 mm, μ = 1.2×10⁻⁵ Pa·s 를 임시로 쓴 적이 있다.
> **이 두 값은 "관성 지배인지 점성 지배인지"를 정성적으로 보려던 것이며, 어떤 모델 계수에도 들어가지 않았다.**
> 보고서에서는 이 언급을 빼도 무방하다.

### 3-2. 변수 선택이 Ergun 식이 지시하는 것과 일치한다

Ergun 관성항을 반응기 입구 상태량으로 정리하면:

$$\Delta P \propto \frac{G^2}{\rho},\quad G=\frac{\dot m}{A_c},\quad \rho=\frac{P\,\overline{MW}}{RT},\quad \dot m = F_{kmol}\cdot\overline{MW}
\;\;\Longrightarrow\;\; \Delta P \propto F_{kmol}^2\cdot\overline{MW}\cdot\frac{T}{P}$$

즉 압력강하는 **(몰유량, 평균분자량, 온도, 압력)** 으로 결정된다. 팀 식이 쓰는 변수가 정확히 이것이다:

| Ergun 이 요구 | 팀 식 변수 | 관계 |
|---|---|---|
| T | `"HX-1005_Tube_Out".T` | 그대로 |
| F_kmol | `"HX-1005_Tube_Out".F × 3600` | 그대로 |
| **MW** | **`z[BENZENE]`** | **MW = 42.182 + 35.933·z, 상관 +1.000000** [계산] |
| P | (절편에 흡수) | ΔP/P_in = **1.11 %** 로 반응기는 사실상 등압 |

**`z[BENZENE]` 은 임의로 넣은 변수가 아니라 평균분자량의 대리변수다.** 상관이 +1.000000 이다.

### 3-3. 세 계수의 부호가 모두 물리와 일치한다

| 계수 | 값 | Ergun 편미분 | 일치 |
|---|---|---|---|
| b_T | +0.08516 | ∂ΔP/∂T ∝ +F²·MW/P (온도↑→밀도↓→유속↑) | ✓ |
| b_F | +0.21436 | ∂ΔP/∂F ∝ +2F·MW·T/P (질량속↑) | ✓ |
| b_z | +5.60222 | z↑→MW↑→(F 고정 시) ṁ↑→ΔP↑ | ✓ |

**계수 하나하나에 물리적 의미가 붙는다.** 우연히 맞춘 숫자가 아니다.

## 4. ⚠️ 과대주장 금지 — 이 식은 "1차 원리"가 아니다

**이 절이 보고서 방어의 핵심이다. 여기를 정직하게 쓰면 오히려 강해진다.**

적합 계수를 역산해서 어떤 (d_p, ε) 조합에 대응하는지 확인했다:

$$(1-\varepsilon)/(d_p\varepsilon^3) = 23{,}265\ \mathrm{1/m}\quad(\text{절편 포함 적합 기준})$$

| ε | 대응 d_p | 판정 |
|---|---|---|
| 0.35 | 0.65 mm | 통상 촉매(1~5 mm)보다 작음 |
| 0.40 | 0.40 mm | 비현실적 |
| 0.45 | 0.26 mm | 비현실적 |

절편 없이 적합하면 ε = 0.35 에서 d_p = 1.18 mm 로 그나마 그럴듯해지지만, 검증 RMSE 가 **2.582 kPa** 로 16배 나빠진다.

**절편 문제:**

```
절편 = −23.23 kPa,  물리항 평균 기여 = +50.69 kPa,  합 = ΔP 평균 27.45 kPa
```

**절편이 물리항의 절반 크기다.** 순수 Ergun 식에는 절편이 없다.

### 왜 이렇게 되나 — 라벨이 순수 촉매층 ΔP 가 아니기 때문

```
라벨 = PT-1004 − 25 − PT-1100
```

`PT-1004` 는 Appendix A 상 **"Pressure of propene feed stream"** 이며, PFD Figure 1 에서 FCV-1004 하류·벤젠 합류 티 앞에 있다. **반응기 입구 압력 계기는 존재하지 않는다.**

따라서 이 라벨은 다음을 전부 포함한다:
- 프로펜 라인 ~ 믹서 ~ HX-1005 입구 배관 손실
- HX-1005 튜브측 실제 압력강하와 사양값 25 kPa 의 차이
- 촉매층 압력강하 (← 이것만이 진짜 목표)
- Ergun 점성항 (관성항만 남겼으므로)

**절편이 이 전부를 흡수한다.**

### 그래서 보고서에는 이렇게 써야 한다

| 쓰면 안 되는 표현 | 써야 하는 표현 |
|---|---|
| "Ergun 식으로 유도했다" | "Ergun 식이 지시하는 변수를 사용한 데이터 상관식이다" |
| "1차 원리 기반 압력강하 모델" | "물리적으로 옳은 방향을 갖는 계측 기반 상관식" |
| "d_p, ε 를 적합했다" | "d_p, ε 를 개별로 가정하지 않고 계수에 흡수했다" |
| (역산 결과 언급 회피) | "역산 시 입자경이 통상 범위보다 작게 나오는데, 이는 라벨이 순수 촉매층 압력강하가 아니기 때문이다" |

## 5. 식(1)을 삭제하는 근거

### 5-1. 구조적으로 불필요하다 — 압력 마디 과잉지정

`.simx` 에서 확인한 상류 압력 체인:

```
R-1100.In.P = 3100(PROPENE.P) − 539.379862691488(FCV-1004.DP) − 25(HX-1005 튜브측)
            = 2535.6201373085
파일값       = 2535.6201373085119        ← 13자리 일치
```

**입구압이 상류에서 이미 결정되므로 `Out.P = In.P − DP` 로 자동으로 닫힌다.**
DP 와 Out.P 를 둘 다 지정하면 방정식이 하나 남는다.

### 5-2. 정확도가 나쁘다 — 조건수 문제

출구압 변동 435 kPa 중 반응기가 만드는 몫은 **27.5 kPa (6.3 %)** 뿐이다. 나머지 93.7 % 는 상류 밸브·열교환기가 만든다.

| 방식 | 검증 RMSE | 상대오차 |
|---|---|---|
| 절대 출구압 직접 예측 | 6.705 kPa | 평균 2,438 kPa 의 0.275 % |
| ↳ 이 오차를 ΔP 기준으로 환산 | 6.705 kPa | ΔP 평균 27.45 kPa 의 **24.4 %** |
| ΔP 직접 예측 | 0.155 kPa | ΔP 평균의 **0.56 %** |

검증 캠페인에서 출구압 예측 오차: **식(1) 사용 5.137 kPa vs (In.P − 식(2)) 사용 0.103 kPa** → **50배 차이**

### 5-3. 물리적 대응물이 없다

| | 식(2) — ΔP | 식(1) — P_out |
|---|---|---|
| 물리적 대응물 | Ergun 관성항 | **없음** |
| 계수 부호 해석 | 3개 전부 가능 | **불가** (b_T 가 음수인 이유 설명 불가) |
| 상류 설계 변경 시 | 영향 없음 | **조용히 틀림** |

출구 절대압은 소스 압력·밸브 손실·열교환기 손실이 정하는 **경계조건의 결과**이지, 반응기의 물성이 아니다.

### 6-1. ⚠️ 내장 `Process.RxnDP` 는 쓰지 말 것

```
HX-1005_Tube_Out.W  = 5.0 kg/s     (= 18,000 kg/h, 실제 반응기 유량)
R-1100.DPcalc.W[1]  = 6.3496 kg/s  (= 22,858 kg/h, 27 % 큼)
R-1100.DPcalc.F[1]  = 0.07327 kmol/s  (= R-1100.In.F, 입구 몰유량)
R-1100.DPcalc.MW[1] = 86.66 kg/kmol   (= 5.0/0.05770, 출구 분자량)
```

**입구 몰유량 × 출구 분자량** 을 쓰고 있어 질량 보존이 깨진다. 반응기 입구 실제 평균분자량은 68.24 kg/kmol 이다.
ΔP ∝ W² 이므로 (6.3496/5.0)² = **1.61배 과대평가** 우려.

(⚠️ AVEVA 내부 변수 정의가 다를 가능성을 배제하지 못한다. 다만 숫자 관계가 위와 같이 정확히 떨어진다.)

### 6-2. 별건 — FCV-1004 (ONNX1 케이스스터디에도 영향)

`.simx` 에 `FCV-1004.DP = 539.379862691488` 이 **고정 스펙**이다. 고정이면 유량을 올려도 반응기 압력이 안 오른다.

실측 플랜트는 반대다:

| B/P 5±0.05, T 350±3 °C | 평균 총유량 | PT-1004 |
|---|---|---|
| 저유량 (n=110) | 16,200 kg/h | 2,332.8 kPa |
| 고유량 (n=95) | 18,000 kg/h | **2,561.3 kPa** |

corr(총유량, PT-1004) = **+0.9988** (10/13 +0.9999, 10/17-18 +0.9973)

**확인 방법:** 케이스스터디를 15,000 / 18,000 kg/h 로 돌리고 `R-1100.In.P` 를 본다.

## 7. 보고서 서술 (초안 — 그대로 쓸 수 있음)

> ### 반응기 압력강하의 처리
>
> **왜 상관식이 필요한가.** 대회 문제는 반응 속도식만 미지로 규정하며(rev2 §1, Appendix B Table 5 `RxnModelType = Unknown`), 압력강하는 원칙적으로 1차 원리로 계산 가능하다. 그러나 Ergun 식을 닫으려면 촉매 입자경 d_p 와 층 공극률 ε 가 필요한데, Appendix B Table 5 는 튜브 수, 튜브 지름, 층 길이, 촉매 밀도만 제공하고 이 두 값은 주지 않는다. **두 값을 임의로 가정하는 대신, Ergun 식에서 이들이 항상 뭉친 형태로만 나타난다는 점을 이용해 계수 자체를 계측 데이터로 적합했다.** 따라서 본 모델에는 d_p 와 ε 에 대한 가정이 들어가지 않는다.
>
> **변수 선정 — Ergun 식이 지시하는 변수를 쓴다.** Ergun 관성항을 질량 기준으로 정리하면 ΔP ∝ ṁ²·T/(P·MW) 이므로, 압력강하는 총질량유량·온도·평균분자량·압력으로 결정된다. 총질량유량 ṁ 은 촉매층을 지나는 모든 화학종의 질량유량이며, 계기 두 개의 합(`FT-1003` + `FT-1004`)으로 직접 얻는다. 평균분자량은 벤젠/프로펜 비율(`FRC-1004`)이 정하고, 압력은 반응기가 사실상 등압(ΔP/P_in ≈ 1.1 %)이어서 상수항에 흡수된다. 따라서 상관식 변수를 (입구 온도, 총질량유량, 벤젠/프로펜 비율)로 선정했다. 벤젠 몰분율(z)을 쓰면 검증 RMSE 가 0.036 kPa 더 낮지만(0.155 vs 0.191), z 는 반응기 입구에 계측기가 없고 재순환 조성에 따라 정의가 흔들리므로, 계기 원값으로 정의되는 총질량유량·비율을 택했다. **정확도를 입력의 투명성·재현성과 맞바꾼 선택임을 밝힌다.**
>
> **적합 결과와 물리적 타당성.** (학습 = 10/13~16 캠페인, 1,924행)
> ΔP [kPa] = −52.500 + 0.090071·T[°C] + 0.00311059·ṁ[kg/h] − 1.00681·(B/P)
> 세 계수의 부호는 모두 Ergun 식의 편미분 부호와 일치한다. 온도 계수(+)는 온도 상승 시 밀도 감소로 유속이 증가하는 효과, 총질량유량 계수(+)는 질량속 증가 효과, 비율 계수(−)는 총질량유량 고정 조건에서 벤젠 비율이 오르면 평균분자량이 커져 몰유량이 줄고 압력강하가 감소하는 효과에 대응한다. 학습 R² = 0.99694, 검증 캠페인 RMSE = 0.191 kPa 로 압력강하 평균 27.45 kPa 의 0.70 % 다. (배포용 최종 모델은 전 캠페인 10/13~18 로 재학습하며, 기울기는 거의 불변이고 절편만 −52.50 → −51.73 으로 이동한다.)
>
> 케이스 스터디 격자(온도 3수준 × 총유량 3수준 × B/P 3수준)의 9개 슬라이스 전부에서 "총유량 증가 → 압력강하 증가"와 "B/P 증가(총유량 고정) → 압력강하 감소"를 만족했다. 후자는 실측과 일치한다(총유량 17,800~18,200 kg/h 구간에서 B/P 4.5→5.5 일 때 ΔP 29.85 → 28.46 kPa, 평균분자량 67.99 → 68.78).
>
> **한계의 명시.** 본 상관식을 Ergun 식의 유도 결과로 주장하지 않는다. 계수는 데이터 적합값이며, 상수항(−52.5 kPa)의 크기가 압력강하 평균(27.45 kPa)을 웃돈다 — 즉 온도·유량·조성 항의 평균 기여가 상수항에 크게 상쇄되며, 순수 Ergun 식에는 이런 상수항이 없다. 이는 압력강하 라벨이 순수 촉매층 압력강하가 아니기 때문이다. `PT-1004` 는 Appendix A 상 프로펜 공급 스트림 압력이며(PFD Figure 1 에서 FCV-1004 하류·벤젠 합류 전), 반응기 입구 압력을 직접 계측하는 태그가 존재하지 않는다. 따라서 라벨에는 배관·믹서 손실과 HX-1005 튜브측 사양값(0.25 bar)과의 편차, Ergun 점성항이 함께 포함되며, 상수항이 이를 흡수한다. 다만 이 상수는 기울기에 영향을 주지 않는다(차감량을 0~50 kPa 로 변경해도 온도·유량·조성 계수가 소수점 6자리까지 불변).
>
> **반응기 출구 압력은 지정하지 않는다.** 플로우시트가 공급원 압력과 상류 손실로부터 반응기 입구 압력을 계산하므로(3,100 − 539.38 − 25 = 2,535.62 kPa), 출구 압력은 입구 압력에서 압력강하를 빼어 닫힌다. 출구 절대압을 직접 상관식으로 지정하면 그 변동의 93.7 % 가 상류 밸브·열교환기 성분이어서 반응기 모델이 담을 이유가 없는 정보를 포함하게 되며, 절대압 기준 0.275 % 의 오차가 압력강하 기준으로는 24.4 % 가 된다. 실제로 검증 캠페인에서 출구압을 직접 적합한 경우 오차가 5.137 kPa 인 반면, 입구압에서 압력강하를 뺀 값의 오차는 0.103 kPa 였다.
