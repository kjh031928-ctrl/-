## 3. ✅ ONNX2 AVEVA 배선 완료 (`PFR_ML.simx`)

### 3-1. ONNX 블록 (LM.ONNXAdaptor)
- NI=3, NO=1, Path=`...\reactor_dp.onnx`
- **InputLabel = `X`**, **OutputLabel = `dP`** (← 이게 안 맞아서 처음에 에러났음. onnx 텐서 이름과 정확히 일치해야 함)
- Setup: Configure → Solve

### 3-2. 방정식
```
Eqn7 :  ONNX2.x[1] = "HX-1005_Tube_Out".T − 273.15      (하이픈은 반드시 키보드 -, 유니코드 − 금지)
Eqn10:  ONNX2.x[2] = "HX-1005_Tube_Out".W × 3600         (★총유량 18000, 프로펜 3000 아님)
Eqn11:  ONNX2.x[3] = "T-1001_out".W / "FCV-1004_out".W   (=FRC)
Eqn12:  "R-1100".DP = ONNX2.y[1]
```
- 스트림은 `"HX-1005_Tube_Out"` 사용(반응기 입구 스트림, ONNX1이 이미 쓰는 것). `"R-1100_in"`은 식에서 에러남.

### 3-3. 반응기 설정 (R-1100, Process.PFR)
- **DPModelType = `Process.RxnDP`** ★
  - `RxnDPErgun`은 **불가**: eps·dp 둘 다 필요한데 dp 미제공, 하나만 지정 시 비물리적 값. (우리 §5 분석대로 = ONNX2가 필요한 이유의 실물 증거)
  - RxnDP 내부 계산기는 부실하지만 **Eqn12가 DP를 덮어써서** 안 쓰임 → RxnDP로 두는 게 맞음.
- **eps = 0.4** (RxnDPErgun 실험 중 0.262로 튀었다가 복원함)
- 나머지: Nt=234·L=2·D=0.0762·rhoc=1600·Basis=CatalystMass·Operation=Adiabatic

### 3-4. 압력망 스펙 (재적용 완료)
- **FCV-1004.Cv = 17.6059 [SPEC]** (IEC 60534 역산, 재현 확인)
- **P_control1 삭제**, **P_control2 삭제**, **R-1100.DP 자유**(Eqn12가 공급)
- ⚠️ **저장본(.simx) 확인 필요**: 디스크 파일은 Cv=17.4042(계산값)로 남아있었음. **라이브에서 17.6059 SPEC인지 + 저장했는지 새 채팅에서 확인할 것.**

### 3-5. 결과
**DP = 29.9371 kPa = ONNX2 출력**(계수로 검산 일치, 소수 4자리). Solution Status 세 등 초록. **ONNX2가 DP를 구동함이 확정됨.**

## 6. 📝 보고서 서술 논리 (내일 쓸 재료)

### (가) 왜 반응기를 ML로 대체하나
rev2 §3.1: **반응 속도식만 미지**(Table 5 `RxnModelType=Unknown`). 나머지(HX·컬럼·플래시)는 first-principles 가능. 그래서 반응기만 데이터 기반 ML로 대체. → **운전데이터의 역할 = 반응기 학습.** (주최측 "정렬 안 됨"은 전체 플랜트 얘기지 반응기 학습 무효가 아님)

### (나) 왜 출력이 DP인가 (P1/P2 아님)
`P2 = P1 − DP`. **P1(입구압)은 플로우시트가 정확히 계산** → 미지는 DP뿐. 큰 값(P1 ~2550)은 모델이 재예측할 이유 없음, 작은 미지(DP ~29, 절대압의 1.1%)만 모델링. P2 직접 지정은 하류 경계 과지정(조원 P_control2가 그것 → 삭제). ★사후 오차비교 없이 **사전(a priori) 분해 논거**로 성립.

### (다) 왜 ML인가 (Ergun/손수 만든 선형식 아님)
- **Ergun 불가**: eps·dp 필요, dp 미제공, 가정 시 비물리적(d_p≈0.38mm) + 촉매층만 계산(라벨의 10%). **AVEVA RxnDPErgun이 실물에서 실패한 게 증거.**
- **손수 만든 선형식** = 조원 P_control1. 우리 ONNX2도 수학은 같은 선형이나, **출처·재현성·형식**이 다름(계측 태그만·z 없음·학습 로그 있음·플로우시트 커스텀식 0개).
- **왜 ML**: 문제(§3.3-1)가 ML 모델선택을 요구 → 실제로 선형·물리군·GBR·RF 스크리닝 수행 → **선형이 이긴 건 ML 절차의 결과.**

### (라) 왜 선형인가
§2-2 스크리닝: 비선형이 선형 못 이김 + 외삽 clamp + RF 물리방향 실패. §8-3(오차 64%가 입력으로 설명 불가) = 복잡한 모델로 갈 여지 없음.

### (마) 왜 무가중인가
가중 vs 무가중 ΔRMSE 0.000132 → "안 해봐서가 아니라 정량적으로 따져보고 뺐다"(투명성).

### (바) 정직한 맞바꿈 (숨기지 말 것)
- ONNX2는 제1원리가 아니라 데이터 기반 상관식(이유: dp 미제공, 라벨이 촉매층 아님).
- ONNX1은 재순환 큐멘 1 mol% 라벨(r1). 실제값(~0.6%)은 r0~r1 안이라 영향 무의미.
- "Ergun 유도"라 쓰지 말 것 → "Ergun이 지시하는 변수".

## 8. 내일 = ML 보고서 초안

**사용자(채지민)가 보고서 목차를 제공 → 그에 맞춰 초안.** rev2 §3.3 요구항목 기준 ML 담당 부분:

2. **입출력 변수와 선정 방법** → ONNX1 [입구온도·프로펜유량·FRC]→전환율, ONNX2 [입구온도·총유량·FRC]→DP. §6-(나)(다) 논거
3. **정확도 지표·스코어링** → 검증 RMSE(ONNX1 0.021·ONNX2 0.1910), 물리 27점 격자, 캠페인 기준 분할(무작위 금지), 독립검증(에너지수지 +0.9956·물질수지 ±3%)
4. **(일부) ML↔시뮬 통합** → §3 배선(Eqn7·10·11·12, DP=ONNX2.y[1]), 왜 반응기 대체했나

**서술 톤**: [주어짐]/[계산]/[가정] 구분, 정직한 맞바꿈 명시(§6-바), "Ergun 유도" 금지.
