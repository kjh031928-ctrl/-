3-3. 물리 방향을 **원자료에서 직접** 확인 (모델 없이):
     (i) 온도·B/P 를 밴딩해 비슷하게 맞춘 뒤 총유량↑ → ΔP↑ 인가
     (ii) 총유량 고정 후 B/P↑ → ΔP↓ 인가
     재현 대조값: 총유량 17,800~18,200 kg/h 구간에서
       B/P 4.3–4.8 (n=10) ΔP 29.85 · MW 67.99 · ρ 34.29

       B/P 5.2–5.7 (n=19) 28.46 · 68.78 · 33.97
     ⚠️ n=10, n=19 는 표본이 매우 적다. 재현되더라도 **표본수를 반드시 함께 보고**하고,
        이 밴딩만으로 방향을 단정하지 말 것. 다른 총유량 밴드에서도 같은 방향이 나오는지 확인하라.
3-4. 시계열 성격: ΔP 에 (T, 총유량, FRC) 선형적합을 한 뒤 잔차의 자기상관을 1분·60분 지연에서 보고.

     과도 구간이 ΔP 에도 있는지 확인. 기준은 CLAUDE.md 의 "직전 12분 창 변동폭 > 0.003068"
     이지만 그것은 X 에 대한 기준이다. ΔP 에 그대로 쓰지 말고,
     쓰려면 ΔP 용 기준을 데이터에서 어떻게 읽었는지 명시하라.
     ⚠️ 최종 모델은 전 데이터 무가중·지연보정 없음으로 이미 확정되어 있다.

# 4. 물리군 대조 (Ergun 이 지시하는 형태)
##############################################
질량형   ΔP ∝ ṁ² · T / (P · MW)
몰형     ΔP ∝ F_kmol² · MW · T / P
  - 두 물리군을 데이터로 만들어 ΔP 와의 **상관** 및 **2모수 회귀(절편 + 물리군) 검증 RMSE** 보고.
  - MW 는 FRC 로 계산한다. 문서: MW = 42.182 + 35.933·z, z 는 FRC 의 함수, 상관 +1.000000.
    이 관계식과 상관을 직접 재현 확인할 것. 재현 안 되면 재현값을 따르고 명시.
  - P 는 무엇을 쓰는지 명시하라. **PT-1004·PT-1100 을 쓰면 라벨 정의를 되먹이는 누출이다**(§6).
    누출 없이 P 를 넣을 방법이 없으면 "반응기 사실상 등압(ΔP/P_in ≈ 1.1 %)이라 상수 흡수"
    라는 문서 논리를 **직접 재현 확인**하고, 물리군에서 P 를 상수로 둘 근거로 삼아라.
    P 를 상수로 두는 경우와 실측 P 를 쓰는 경우를 **둘 다** 계산해 차이를 보고하되,
    후자는 "누출 포함, 참고용"으로 명확히 라벨링할 것.
  - 문서 대조값: 물리군 2모수 모델과 팀 식(2) 예측의 상관 0.999394 /
    절편 −23.23 kPa, 물리항 평균 기여 +50.69 kPa /
    절편 없는 순수 Ergun 형태는 검증 RMSE 2.582 kPa 로 16배 악화.
  ⚠️ **"Ergun 유도"라고 쓰지 말 것.** 반드시 "Ergun 이 지시하는 변수" 로만 서술한다.
     역산하면 입자경이 통상 범위보다 작게 나온다는 사실((1−ε)/(d_p·ε³) = 23,265 1/m)도
     재현해 보고, 이는 라벨이 순수 촉매층 ΔP 가 아니기 때문임을 명시한다.

비교 대상:
  (i)   선형 1차 (LinearRegression)                        ← 후보
  (ii)  선형 + 총유량²                                       (제곱 이득 있나. 문서 기대: 0.1910 → 0.2027 악화)
  (iii) 물리군 2모수 (절편 + ṁ²·T/(P·MW))
  (iv)  비선형 기준선 1~2개 (GradientBoosting, RandomForest) ← "선형이 성능을 얼마나 남기나" 확인용
        하이퍼파라미터는 **sklearn 기본값**을 쓰고 random_state=42 로 고정, 문서에 그대로 기록할 것.
        기본값 외의 값을 임의로 정하지 말 것.

보고: 각 모델의 검증 RMSE + **물리 27점 격자** 결과
  격자 = T {335, 350, 365} °C × 총유량 {15000, 16500, 18000} kg/h × B/P {4, 5, 6}
  판정 = 총유량↑ → ΔP↑ (9/9), B/P↑(총유량 고정) → ΔP↓ (9/9), 예측범위 20~33 kPa
  선형 1차의 학습 계수 대조값:
    ΔP[kPa] = −52.500 + 0.090071·T[°C] + 0.00311059·총유량[kg/h] − 1.00681·(B/P)
    학습 R² = 0.99694, 검증 RMSE = 0.1910 kPa

⚠️ 이 절의 목적은 **"선형 1차가 물리를 통과하면서 비선형 대비 충분히 좋은가"** 를 데이터로 확인하는 것이다.
   비선형이 크게 낫지 않고 물리 방향을 보장하지 못하면 그것이 선형 채택의 근거가 된다.
   **여기서 최종 배포 결정은 하지 말 것.** 결론은 §7 에 "제작 단계로 넘길 권고"로만 적는다.
⚠️ 검증셋(10/17-18)은 최종 확인용이다. 이 절에서 검증 RMSE 를 보고 모델을 고르지 말 것.
   사용 이력을 results/validation_usage_log.md 에 누적 기록하라.
