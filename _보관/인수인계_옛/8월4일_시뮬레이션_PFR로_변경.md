# 0-1. 🔴 ONNX2 를 만드는 목적 — **남은 식 하나(`P_control1`)를 없애기 위해서다**

## 한 줄 요약

> **조원이 플로우시트에 손으로 박은 압력 상관식은 2개였다. 하나는 이미 없앴다.
> ONNX2 는 남은 하나 `P_control1` 을 없애려고 만드는 것이다.**

| 식 | 무엇을 지정 | 상태 | 어떻게 없앴나 / 없앨 것인가 |
|---|---|---|---|
| **`P_control2`** | 반응기 **출구압** | ✅ **제거 완료 (08-04)** | 삭제 후 **`FCV-1004.Cv` 를 SPEC** 으로 지정해 자유도를 닫았다 (§7-1) |
| **`P_control1`** | 반응기 **압력강하 ΔP** | ❌ **아직 남음** | ← **이것을 없애려고 ONNX2 를 만든다** |

**`P_control2` 는 밸브 Cv 지정으로 대체됐다. `P_control1` 은 대체재가 아직 없다.**
ΔP 를 누군가는 줘야 하므로, `P_control1` 을 그냥 지우기만 하면 시뮬레이션이 안 풀린다.
**그 자리를 채울 것이 ONNX2 다.**

> ⛔ **새 채팅이 "ΔP 모델은 필요 없을 수도 있다"로 결론내면 안 된다.**
> 그러면 `P_control1` 이 플로우시트에 그대로 남는다 — **프로젝트 목적 자체가 실패한다.**
> "안 채운다"는 선택지가 아니다. **무엇으로 채울지만 열려 있다.**

|---|---|---|

| `P_control2` | ✅ 삭제됨 (08-04 작업) | ❌ **살아 있음** |
| `P_control1` | ❌ 살아 있음 | ✅ 삭제됨 |
| `FCV-1004.Cv` | ✅ 17.6059 SPEC | ❌ 미지정 (17.4042 계산값) |
| `R-1100.DP` | `P_control1` 이 공급 | **29.977 상수 SPEC (임시)** |

```

```

### 왜 `P_control2` 를 없애야 하나 — 4가지, 전부 검증됨

| 사유 | 근거 | 검증 |
|---|---|---|
| **압력 마디 과잉지정** | 입구압은 상류가 정하고 `P2 = P1 − DP` 로 닫히는데 출구압을 또 지정 | ✅ **08-04 SpecSet 15 로 증명** (§7-1) |
| **FCV-1004 를 망가뜨림** | 잠식된 자유도를 밸브 DP 가 떠안아 유량에 반응 못 함 | ✅ 삭제 후 `Cv` 지정만으로 정상화 (§7-1) |
| **정확도 50배 나쁨** | 출구 절대압 직접 예측 5.137 kPa vs (입구압−DP) 0.103 kPa | ✅ 문서 재현 |
| **물리적 대응물 없음** | 출구 절대압은 소스압·밸브손실이 정하는 경계조건의 결과. `b_T` 음수 설명 불가 | ✅ |

**→ 논쟁 끝. 이미 삭제 결정됐고 08-04 에 실증됐다.**
(⚠️ `PFR_ML.simx` 에는 아직 살아 있다. 다시 지울 것 — §1-1 #1)

### 왜 `P_control1` 도 없애야 하나

| 사유 | 근거 |
|---|---|
| **학습 z ≠ 사용 z** | 학습 0.72973(FRC 로 계산) vs 사용 0.715766(`.simx`, 재순환 큐멘 포함). 차이 0.013964 × b_z 5.60222 = **0.078 kPa = 모델 RMSE 의 50 %** |
| **계수 출처 불명이었음** | 4개 계수가 어디서 왔는지 문서가 없었고, 실측 CSV 재현으로 뒤늦게 밝혀냄 (R²=0.99906) |
| **플로우시트에 박힌 적합식** | 심사에서 "이 −60.3808 은 어디서 왔습니까"에 답해야 함. 버전관리·재현 경로가 없음 |
| **`z` 는 계측기가 없다** | 반응기 입구 조성 분석기 부재. "분석기가 필요한 모델"로 오해받음 |

임시 상태다 (§6-1-5). 이건 해결이 아니라 미룬 것이다.

# 5. 🔑 핵심 계산 — Ergun 으로 계산하면 ΔP 가 실측의 1/10 이다

이것이 **이번 판단에서 가장 중요한 숫자**다. 반드시 새 채팅에서 재검산할 것.

**조건** (Table 5 [주어짐] + SRK 반응기 입구 상태 [계산])
```
단면적 A = 234 × π/4 × 0.0762² = 1.06713 m²
질량유량 W = 5.0 kg/s (= 18,000 kg/h, 정상운전)
질량속   G = 4.6855 kg/m²s
밀도     ρ = 35.936 kg/m³  (SRK)  [계산]
점도     μ = 1.2e-5 Pa·s          [가정 — 근거 약함, §6-4]
```

**Ergun 예측 ΔP [kPa]** (실측 정상운전 ΔP = **29.22 kPa**)

| ε \ d_p | 1 mm | 2 mm | 3 mm | 5 mm |
|---|---|---|---|---|
| 0.40 | 22.69 (78 %) | 10.68 (37 %) | 6.98 (24 %) | 4.12 (14 %) |
| **0.50** | 9.49 (32 %) | 4.51 (15 %) | **2.96 (10 %)** | 1.75 (6 %) |
| 0.60 | 4.31 (15 %) | 2.07 (7 %) | 1.36 (5 %) | 0.81 (3 %) |

**역산 — 실측 29.22 kPa 를 내려면 d_p 가 얼마여야 하나**

| ε | 필요 d_p | 판정 |
|---|---|---|
| 0.40 | 0.799 mm | 통상 촉매(1~5 mm)보다 작음 |
| **0.50** | **0.378 mm** | **비현실적** |
| 0.60 | 0.196 mm | 비현실적 |

### 5-1. 이 표가 말하는 것

**ε=0.5, d_p=3 mm 같은 상식적 값을 넣으면 촉매층 ΔP 는 약 3 kPa 이고, 실측 라벨 29.22 kPa 의 10 % 다.**

나머지 90 % 는 촉매층이 아니다. 라벨의 정의를 보면 이유가 분명하다:

```
라벨 ΔP = PT-1004 − 25 − PT-1100
```
- `PT-1004` 는 Appendix A 상 **"Pressure of propene feed stream"** — PFD Figure 1 에서
  **FCV-1004 하류·벤젠 합류 티 앞**이다. **반응기 입구 압력 계기는 존재하지 않는다.**
- 따라서 라벨에는 프로펜 라인 배관 손실 + 믹서 손실 + HX-1005 실제값과 사양 0.25 bar 의 편차가
  **전부 포함**된다.
- 기존 ONNX2/팀 상관식의 **절편이 −52.5 kPa (물리항 평균 기여의 절반 이상)** 였던 이유가 이것이다.

> **결론적 관찰:** ΔP 라벨은 애초에 "촉매층 압력강하"가 아니었다.
> PFR + Ergun 은 **촉매층만** 계산한다. 둘은 같은 물리량이 아니다.

### 5-2. 촉매질량 검산 (Basis = CatalystMass 이므로 반응속도에 직결)

| ε | 촉매 질량 = A·L·(1−ε)·ρ_cat |
|---|---|
| 0.40 | 2,048.9 kg |
| **0.50** | **1,707.4 kg** |
| 0.60 | 1,365.9 kg |

⚠️ **ε 는 압력강하만의 문제가 아니다.** `Basis = CatalystMass` 이므로 ε 를 바꾸면 촉매 질량이 바뀌고,
**반응속도(=ONNX1 이 대체하는 부분)와의 정합성도 바뀐다.** ε 선택은 ONNX1 쪽에도 영향을 준다.
ONNX1 은 전환율 X 를 직접 내놓으므로 촉매질량과 무관해 보이지만, **PFR 로 바꾼 뒤 `Eqn4`
(전환율 부과 방정식)가 여전히 성립하는지 확인해야 한다**(§6-2).

# 6. 새 채팅에서 확인·결정할 것

## 6-1. ✅ [해결됨] `PFR_ML.simx` 실물 확인 결과 — **Ergun 은 쓸 수 없다**

사용자가 올린 `PFR_ML.simx` 를 직접 열어 확인했다. **결론부터: ε 는 있지만 Ergun 은 못 쓴다.**

### (1) `eps` 는 존재한다 — 변수명 추측이 맞았다

```
R-1100.eps   = 0.4      [SPEC]
R-1100.rhoc  = 1600     [SPEC]   ← Table 5 일치
R-1100.Nt    = 234      [SPEC]   ← Table 5 일치
R-1100.L     = 2        [SPEC]   ← Table 5 일치
R-1100.D     = 0.0762   [SPEC]   ← Table 5 일치
R-1100.Basis = CatalystMass [PARAM]  ← Table 5 일치
R-1100.Operation = Adiabatic [PARAM] ← Table 5 일치
```
**Table 5 가 전부 반영되어 있다.** PFR 전환은 성공적이다.

### (2) ⚠️ 그러나 `eps` 는 압력강하가 아니라 **촉매질량**에 쓰인다

```
Mc = V × (1 − eps) × rhoc = 2.1331699272 × 0.6 × 1600 = 2,047.8431 kg
파일값 R-1100.Mc                                       = 2,047.8431   ← 완전 일치 [검증됨]
```
`Basis = CatalystMass` 이므로 반응속도가 촉매질량에 비례한다.
**즉 `eps` 는 반응 쪽 변수이지 ΔP 쪽 변수가 아니다.**

### (3) ⚠️ **입자경(d_p) 파라미터가 모델에 존재하지 않는다**

`R-1100` 하위 전 변수를 `dp`·`Dp`·`particle`·`.d`·`Ergun` 으로 전수 검색 → **0건.**

**Ergun 식은 ε 와 d_p 를 둘 다 요구한다. d_p 가 모델에 없으므로 Ergun 을 쓸 수 없다.**
→ **"ε 를 알면 Ergun 을 쓸 수 있으니 ONNX2 가 불필요해진다"는 가설은 성립하지 않는다.**

### (4) `DPModelType` 은 여전히 `Process.RxnDP`

파일 전체에서 나오는 `DPModelType` 값은 `Process.RxnDP` 하나뿐이다.
(단 이는 *현재 값*이며 *드롭다운 선택지 전체*는 아니다 — 화면에서 목록을 한 번 확인할 것.)

그리고 RxnDP 계산기가 **두 벌** 있고 서로 다른 값을 쓴다:

| | `DPCalc` (대문자 C) | `DPcalc` (소문자 c) |
|---|---|---|
| `W[1]` | 0.021368 kg/s | **6.3496 kg/s** |
| `MW[1]` | **68.240** (입구 분자량 — 맞음) | **86.660** (출구 분자량 — 틀림) |
| `D` | 0.0762 (튜브 지름) | 1.1648 (정체 불명) |
| `DP` | 29.977 [SPEC] | 29.9777 (계산) |

실제 반응기 유량은 **5.0 kg/s** 다. 어느 쪽도 맞지 않는다.
`인수인계_ONNX2_전체_2026-08-03.md` §1-5(c) 의 "RxnDP 쓰지 말 것" 지적이 PFR 에서도 유효하다.

### (5) 현재 ΔP 는 **상수로 박혀 있다**

```
R-1100.DP = 29.977   [SPEC]      ← 사용자가 지정한 상수
P_control1  : 파일에 0회 등장 (삭제됨) ✅
P_control2  : 파일에 1회 등장 (**아직 살아 있음**) ⚠️
```
`P_control1` 을 지우고 그 값(29.977)을 상수로 대신 넣은 상태다.
**어제 `P_control2` 를 지운 작업이 이 PFR 파일에는 반영되어 있지 않다.** 다시 지워야 한다.

⚠️ ΔP 상수 고정은 임시방편이다. 케이스 스터디 범위에서 실측 ΔP 가 **19.89 ~ 31.48 kPa (40 % 변동)**
하므로 상수로 두면 rev2 §3.2 위반 소지가 있다.

## 6-1b. ⚠️⚠️ 새로 발견된 최대 쟁점 — `RxnModelType = CumeneRates`

```
R-1100.RxnModelType = CumeneRates   [PARAM]
```

**AVEVA CC2 예제의 큐멘 반응속도식이 켜져 있고, 실제로 돌고 있다** [검증됨]:
```
Rxn.r1 = 7.6049435e-06 kmol/(kg-cat)/s × Mc 2,047.843 kg = 0.015573731 kmol/s
Elem[1].Rate[PROPENE] 파일값                              = -0.015573731   ← 완전 일치
```

**그런데 rev2 Table 5 는 `RxnModelType = Unknown` 이다.**
알려진 속도식(CumeneRates)을 쓰면 **"속도식이 미지라서 ML 로 대체한다"는 프로젝트 전제 자체가 무너진다.**
이것이 PFR 전환에서 가장 먼저 정리해야 할 문제다.

### 다행히 ONNX1 은 이중 계상이 아니다 [검증됨]

`R-1100.X[PROPENE] = 0.80508` vs `ONNX1.y[1] = 0.82980` 이 달라서 이중 계상을 의심했으나,
**분모 차이일 뿐이고 `Eqn4` 가 정상 작동 중이다:**

```
반응기 입구 프로펜  0.019344330 kmol/s   (재순환 포함)
신선 프로펜(FCV출구) 0.018768131 kmol/s   비 = 0.970214
ONNX1.y[1] × 0.970214 = 0.82979661 × 0.970214 = 0.805080
R-1100.X[PROPENE] 파일값                        = 0.80507989   ← 소수 6자리 일치
```
→ ONNX1 은 **신선 프로펜 기준** 전환율, AVEVA `X[PROPENE]` 은 **반응기 입구 기준**. 정의 차이다.

**그렇다면 CumeneRates 는 무엇을 하고 있나?** `Eqn4` 가 전환율을 부과하는데 CumeneRates 도 속도를
계산한다. 자유도 장부(방정식 1개 = 변수 1개)상 어딘가 한 변수가 free 되어 CumeneRates 의 속도가
ONNX1 에 맞춰 스케일링되고 있을 가능성이 높다(`Rxn.C = 0.43295` 등이 후보).
**화면에서 `Rxn.C` 와 `RxnL1.C` 의 체크박스 상태를 확인할 것.**

### (A) §4 물리군 대조 [미완]
- `ṁ²·T/(P·MW)` (질량형) 과 `F_kmol²·MW·T/P` (몰형) 을 만들어 ΔP 와의 **상관** 및

- `MW = 42.182 + 35.933·z` (z 는 FRC 의 함수) 관계식과 **상관 +1.000000** 을 직접 재현 확인
- ⚠️ **P 를 무엇으로 둘지 명시할 것.** `PT-1004`·`PT-1100` 을 쓰면 라벨 정의를 되먹이는 **누출**이다.

- 대조값: 물리군 2모수 vs 팀 식(2) 예측 상관 **0.999394** / 절편 −23.23 kPa · 물리항 평균 +50.69 kPa /
