## 2. L1 변수선택 교차검증 (부록 C) — 물리 선택을 통계로 뒷받침

- 후보에 프로펜유량·총유량을 함께 넣고 캠페인 LOCO·표준화·무가중·seed 42로 Lasso/ElasticNet.
- **전환율=프로펜유량(계수비 1.55), ΔP=총유량(3.97)** 각각 1순위 유량 → 물리와 일치.
- 삭제검사: 물리 3변수 모두 필수(하나만 빼도 held-out ×2.1~34). 후보 7종 전부 넣으면 교차검증 악화(과적합).
- 누출 시연: ΔP에 압력(PT-1004·PT-1100) 넣으면 RMSE 0.191→0.000005(붕괴, 라벨 정의 복원) → 통계만으론 누출 못 막음(전환율은 압력 탈락, 붕괴는 ΔP 한정).
- 상세 원자료: `26-08-06/`(다른 세션 산출), `docs/L1_변수선택_교차검증.md`.

**FRC 결론(§4 정밀화):** FRC는 배포 좌표계 [한 유량+비율]에서 **필수**(삭제검사 ×2.1/×1.7, L1도 유지: 계수 전환율 +0.137·ΔP −0.323). FRC가 0으로 떨어지는 건 후보에 **비율을 재구성하는 잉여 벤젠량 변수(총유량 또는 벤젠유량)**가 있을 때뿐 = 재매개화이지 "덜 중요"가 아니다. → 보고서엔 "필수/중요" 톤으로.

## 3. §3.7을 삭제한 이유 (중요 결정)

§3.7 물리·보존 재현(`docs/검증_37_재현.md`) 결과, 네 검사 중 여럿이 주장값과 어긋났다:
- 27점 격자: **ΔP 9/9 통과** / **전환율 9/27**(온도축만 통과 — 단, 유량↑→X↑는 데이터 자체가 그렇고 유량·압력이 분리 조작된 적 없어 체류시간 효과 식별 불가 = 모델 결함 아님).
- 에너지수지 +0.9887(주장 ≥0.99에 근소 미달), 큐멘 물질수지 최대 −7.2%(주장 ±3% 초과 — 단 라벨 그대로 써도 −2.4% 남아 **모델 오차 아니라 하류 수지 불폐합**), 자기상관 ΔP 0.9997·전환율 0.995(학습 구간).

→ 실패 항목이 있고 통과만 골라 쓰면 체리피킹처럼 보임 + 20장 제한. **§3.7 삭제.** 핵심(365°C clamp 없음=외삽 안정성)은 **이미 §3.5.4에 있음**. "모델 available"은 §3.6 R² 0.98/0.99 + parity(F2·F3)로 충분.

**단, 유지된 사실(초안 반영 완료):** §3.2.2 자기상관은 "학습 구간 ΔP 0.9997·전환율 0.995"로 구간 명시. §3.6.4에 "배포 ONNX=10/13–18 재학습, 성능은 held-out 값 인용" 명시.

## 5. ★미적용 편집 3건 (새 채팅에서 제일 먼저 반영) — 오늘 폴더 연결이 끊겨 못 함

정본 `ML보고서_초안_대단원3.md`에 아래 3건을 적용할 것.

1. **§3.5.2 (전환율 심층 비교): "27점" 삭제.** 전환율은 27점 물리방향이 9/27로 실패했고 §3.7도 삭제했으므로, 전환율 후보 비교는 **검증 RMSE + 외삽(clamp 여부)**만으로 서술. 27점 열/언급 제거.

2. **§3.5.3 (ΔP 심층 비교): 물리방향(27점)은 ★유지 권장 — 삭제 주의.** 사용자가 "이것도 안 하기로 한 것 아니냐"고 물었으나, ΔP는 상황이 다르다: **F1(프로펜유량)의 RMSE 0.1479가 F2(총유량) 0.1910보다 오히려 낮다.** F2를 택하는 유일한 근거가 **물리방향(F2는 B/P↓ 9/9 통과, F1은 0/9 실패)**이다. 이걸 빼면 F1이 더 좋아 보여 총유량 선택이 무너진다. ΔP 물리방향은 **9/9 깨끗이 통과**하며 §3.7(최종모델 검증, 삭제됨)과 달리 **스크리닝(모델 선정) 근거**다. → 유지하되, "이건 최종검증이 아니라 후보 선정 기준"임을 한 줄 명시하면 일관됨. (사용자 최종 확인 필요.)

3. **§3.6.1 라벨 생성(SRK 밀도역산 + 브렌트법) 블록 삭제 → 대단원 2 이관.** 사용자 지시. §3.6.1은 "모델 형태(로짓 1차)"부터 시작하게. 삭제하는 SRK/브렌트 상세 설명은 조원 대단원 2로 넘길 것(내용 유실 방지: 본 인수인계 §7에 요지 보존).

## 7. 삭제되는 SRK 라벨생성 요지 보존 (대단원 2로)

전환율 라벨은 측정이 아니라 **SRK 상태방정식으로 출구밀도(AT-1100)를 재현하는 전환율을 역산**한 값. 2단 중첩:
1. 입구 조성(프로펜·프로판=FT-1004 질량분율, 벤젠=FT-1001 신선+FT-1300 재순환, 재순환 큐멘 1 mol%)
2. 시험 X → 화학량론으로 출구 조성 → SRK 3차식 `Z³−Z²+(A−B−B²)Z−AB=0`을 **Z에 대해** 풀어 기상(최대 실근) 밀도 ρ(X). Z는 X 종속(독립 미지수 아님).
3. ρ(X)=AT-1100을 만족하는 X를 **브렌트법(Brent's method)**으로 역산(구간 [1e-6,0.999999]). 밀도가 X에 단조라 근 유일. (문서의 "구간이분법"은 부정확 — 브렌트법.)
- SRK는 **대회 지정**(rev2 PDF p7 Table 1) + AVEVA 상수 → 시뮬 일관성 위해 사용(PR 등 대체 금지). 코드: `src/srk.py`·`src/labels.py`.
