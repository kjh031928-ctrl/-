# 부록 재현 명세 (스크립트·프롬프트) — 대단원 3

> **용도:** 보고서 본문을 다 쓴 뒤, **부록 표 C1~C4와 그림 F1~F3를 한 번에 재현**하기 위한 명세.
> 각 표/그림이 어떤 스크립트·방법·입력·파라미터에서 나오는지, 그리고 **재현이 맞았는지 확인할 목표 수치**를 적어 둔다.
> 이 파일은 내부 재현용이며 **보고서 본문에는 넣지 않는다.**

---

## 0. 공통 규칙 (모든 스크립트 준수)

- 원본 대회 파일은 **읽기 전용**. 파생변수는 메모리에서만 계산. **`.xlsx` 산출 금지.**
- 분할은 **날짜(캠페인) 기준만** — 학습 10/13–16, held-out 10/17–18, 10/12는 **앵커**(통계 미포함).
  무작위 KFold·train_test_split·shuffle **금지.**
- **seed = 42** 고정. `sklearn`·`numpy` 버전을 출력에 남긴다(재현 환경: sklearn 1.9.0 · numpy 2.5.1).
- 폐기물 미사용: `ML_weight`, τ=3분, `TT-1006_rate_*`, `*_weighted.json`. **전 구간 무가중(OLS).**
- 보고하는 성능은 **held-out 기준.** 모든 수치는 스크립트가 재계산한 값을 따르고, 인용값과 다르면 재현값을 채택하고 그 사실을 명시.

## 2. 표별 재현 명세

### 표 C1 — CV 최적 α에서 표준화 계수 (변수선택)
- **스크립트:** `L1_변수선택_교차검증_재현스크립트.py` (기존, §3-1).
- **방법:** 후보 7종 `[TT-1006, FT-1004(프로펜), 총유량, FRC-1004, TT-1004, FT-1001, FT-1300]`,
  표준화 후 Lasso·ElasticNet, 캠페인 LOCO(leave-one-group-out)로 최적 α 선택. Lasso·ElasticNet 병행(결과 일치).
- **재현 목표(핵심):** 유량 승자·비 = **전환율 프로펜/1.55배**, **ΔP 총유량/3.97배**. FRC·FT-1300 계수 0(이 후보셋에서).
- **주의:** FRC=0은 후보에 비율 재구성 잉여 벤젠량 변수가 있을 때뿐. 배포 좌표계 `[한 유량+비율]`로 돌리면 FRC 유지(계수 전환율 +0.137·ΔP −0.323) — 이 대조도 스크립트에 포함.

### 표 C2 — 삭제검사(물리 3변수 중 1개 제거 시 held-out 오차 배수)
- **스크립트:** 동 스크립트(§3-4 증분/삭제).
- **재현 목표:** 입구온도 ×7.2 / ×3.8, 유량 ×4.5 / ×34, 비율 FRC **×2.1 / ×1.7**. (범위 1.7~34배.)
  후보 7종 전부 투입 시 CV 악화(전환율 ×2·ΔP +18%)도 함께 출력.

### 표 C3 — 누출 시연(압력을 후보에 추가)
- **스크립트:** 동 스크립트(§5 누출).
- **재현 목표:** 전환율+압력 → 압력 **탈락**(계수 0), held-out 0.0341→0.0314. ΔP+압력 → 압력 **선택**(PT-1100 −27.08 / PT-1004 +7.23), held-out 0.191→**0.000005(붕괴)**.
- **논지:** ΔP 라벨 정의(PT-1004−25−PT-1100)를 그대로 복원한 누출. 통계는 못 막고 물리로 막는다.

### 표 C4 — 순열 중요도 (permutation importance, 모델-불문 3차 재확인) — **신규 스크립트 필요**
- **산출물:** `permutation_importance_검증.py` → `results/permutation_importance.json`.
- **방법:**
  1. 배포 ONNX(`reactor_conversion_r1.onnx`·`reactor_dp.onnx`)를 직접 실행.
  2. held-out(10/17–18) 기준, 그림용은 학습(13–16) 재적합본과 동일 규약.
  3. 각 입력을 **60분 블록 단위로 셔플**(단순 행 셔플 금지 — 자기상관 때문), **N=200회** 반복 후 평균 ΔRMSE.
  4. 정규화 중요도(그 타깃 ΔRMSE 합=100%)로 순위화.
  5. 공선성 점검: 가장 상관 큰 쌍을 같은 블록순서로 함께 섞는 **grouped 셔플** 병행. 입력 쌍 `|corr| ≤ 0.51` 확인.
  6. 배포 in-sample 전 구간(3,066행)으로도 반복해 순위 불변 확인.
- **재현 목표:**
  - baseline RMSE: 전환율 0.021 · ΔP 0.191(§3.6.4와 동일).
  - 전환율: 입구온도 0.188(**74.3%**) > 프로펜유량 0.046(18.3%) > FRC 0.019(7.5%).
  - ΔP: 총유량 3.543(**83.2%**) > 입구온도 0.576(13.5%) > FRC 0.140(3.3%).
  - grouped 셔플(전환율 0.047·ΔP 3.38)이 개별값과 정합 → 공선성 왜곡 없음.
  - in-sample 반복 순위 동일(전환율 온도 56%·ΔP 총유량 85%).
- **결론:** 물리 선정 → L1 통계선택 → 순열 중요도, 세 경로 순위 일치.

## 4. 코딩 에이전트용 프롬프트 (표 C4 신규 스크립트 요청 시 붙여넣기)

```
목표: 배포 반응기 대체모델의 순열 중요도(permutation importance)를 계산해 부록 표 C4를 재현한다.

규칙(반드시 준수):
- 입력 데이터 ML_마스터데이터_PV.csv(읽기 전용). 배포 라벨 X_conv_r1_deployed. .xlsx 산출 금지.
- 분할: 학습 10/13–16, held-out 10/17–18, 10/12 앵커(제외). 무작위 셔플 금지. seed=42.
- 모델: reactor_conversion_r1.onnx(입력 TT-1006·프로펜유량·FRC-1004), reactor_dp.onnx(입력 TT-1006·총유량·FRC-1004)를 직접 실행.

절차:
1) baseline: held-out에서 두 모델 RMSE 계산(목표 전환율 0.021·ΔP 0.191).
2) 각 입력을 60분(=60행) 블록 단위로 셔플해 예측→RMSE 증가폭(ΔRMSE)을 N=200회 평균.
3) 타깃별로 정규화(ΔRMSE 합=100%)해 순위표 출력.
4) 상관 최대 쌍을 함께 섞는 grouped 셔플 병행, 입력 쌍 |corr| 출력(≤0.51 기대).
5) 배포 in-sample 전 구간(3,066행)으로 반복해 순위 불변 확인.
6) 결과를 results/permutation_importance.json 으로 저장하고, 위 목표 수치와 대조표를 콘솔에 출력.

출력물: permutation_importance_검증.py · results/permutation_importance.json · 콘솔 재현 대조표.
```
