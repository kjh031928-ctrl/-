## 산출물 형식 (사용자 지시, 위반 금지)

- **엑셀(.xlsx) 파일을 만들지 말 것.** 어떤 경우에도 산출물을 스프레드시트로 내지 않는다.
  분석 결과는 Word(.docx) 문서로 정리하고, 필요한 경우에만 그림(.png)을 함께 만든다.
- 문서에는 **꼭 필요한 그래프만** 넣는다. 장식용·중복 그림 금지.
- 스크립트(.py)는 재현 목적일 때만 남긴다.

## 작업 원칙 (기존)

- 정확한 근거(ref) 필요. 확증 편향 금지, 임의 판단 금지, 없는 것 지어내지 말 것.
- 원본 대회 파일 수정 금지 (읽기 전용).

- 문제는 rev2 기준.

## 대단원 2 / 대단원 3 분담 (2026-08-07 확정, 위반 금지)

**대단원 3(ML)은 대단원 2가 정한 입력·출력 세트를 "받아서" 모델을 고르고·학습·평가한다.**
아래는 **대단원 2 소관**이므로 대단원 3 보고서에서 근거를 다시 세우지 않는다(포인터만 남김):

- **입력·출력 세트 선정**(어느 변수·최소화·경계). 대단원 2는 5개 조작 SP 기반 물리·공정 논리로 선정.
- **압력 변수 제외** — 입력 후보에 절대압이 애초에 없음(조작 SP 기준). "왜 압력을 뺐나"는 대단원 2 서술.
- **라벨 생성** — 전환율 라벨(SRK 밀도 역산·브렌트법·재순환 큐멘 1 mol%)과 ΔP 라벨(`ΔP = PT-1004 − 25 kPa − PT-1100`, HX-1005 손실)은 대단원 2가 작성(2.2·2.3.3.1). 전달 자료: `대단원3_보고서작성/대단원2_전달_SRK전환율라벨생성.md`.

**대단원 3에 남기는 것:** L1 통계 교차검증(§3.2.4·부록 C)은 "물리로 고른 입력을 통계로 독립 재확인하는 방법 검증"으로 대단원 3에 둔다(대단원 2와 협의 완료 — 대단원 2 변수선정은 물리 기반이라 통계 L1은 대단원 3 몫).

### 출력 후보 확정 (대단원 2 확정, 2026-08-07)
- **반응 성능:** 전환율 X  vs  (AT-1100 출구밀도 + TT-1100 출구온도) → **채택 전환율 X**(밀도·온도는 X에서 계산되는 종속 상태량: TT-1100=f(입구온도,X) R²0.96 · AT-1100=f(X,Tout,P) R²0.997·밀도는 압력에 종속 corr0.996).
- **압력강하:** **ΔP 단일**. PT-1100은 후보가 아니라 `PT-1100 = P1 − ΔP`로 계산되는 종속값.
- 입력: 전환율 [입구온도 TT-1006, 프로펜(프로필렌)유량, FRC-1004(B/P비)] / ΔP [TT-1006, 총유량(FT-1003+FT-1004), FRC-1004]. 온도 태그는 양쪽 **TT-1006.PV**.

### 재순환 큐멘 1 mol% 서술 방침 (2026-08-07 사용자 지시, 위반 금지)
- r1 = 1 mol%는 **안전을 위한 보수적(상한) 가정**으로 서술한다(재순환 큐멘↑→전환율 라벨↓→과소예측=안전 방향).
- **실제 시뮬값(~0.43 mol%, z[CUMENE]=0.004306)이나 "영향 미미(ΔRMSE·r0↔r1 차이)" 정량 근거는 보고서에 쓰지 않는다.** (내부 참고용 사실일 뿐.)

## 표본 가중치 — 폐기 (2026-07-31 확정, 위반 금지)

**`ML_weight`와 τ=3분은 문서·보고서·발표·질의응답 어디에도 쓰지 않는다.**
설명할 수 없는 것을 근거로 쓰지 않는다는 원칙에 따른 결정이다.

- 폐기 대상: 가중 함수 `w = 1/(1+(τ·rate)²)`, 시정수 **τ=3분**(가정값),
  파생 컬럼 `ML_weight`·`TT-1006_rate_C_per_min`, "0.01 / 0.1 °C/min" 임계값.
- 최종 모델은 **무가중**이다 (`linear2_logit_I1_r1_unweighted.json` → `reactor_conversion_r1.onnx`).
  가중/무가중 성능 차는 0.000126으로 무의미했다.
- `src/`의 가중치 배관과 `results/*_weighted.json` 73개는 **재현성 보존을 위해 남겨둔다.**
  최종 경로에서 호출되지 않는다. 문서에서 근거로 인용만 하지 않으면 된다.

### 무가중(OLS) 서술 규칙 (2026-08-08 추가, 위반 금지)

**τ=3분뿐 아니라 아래 「대체 기준」의 과도/준정상 상태 분류(잡음바닥 0.003068·3σ·이동창 12분)도
보고서·발표·질의응답에서 "무가중/전 데이터 사용"의 근거로 삼지 않는다.**
이들은 데이터로 확정할 수 없는 임의 가정이고 재현도 어긋난다(아래 캐비앗). 무가중은 다음 두 축으로만 서술한다:

- ① **입증책임:** 어떤 가중 규칙도 정당화 불가능한 가정 파라미터(정착 판정 기준·시정수·창 길이)를 요구하므로,
  동일 가중(OLS)이 기본값이다 — 이것이 τ-가중을 폐기한 이유와 동일 논리다.
- ② **모델측 결과:** 적합한 정적 모델이 정상상태 앵커(10/12)를 재현하고 held-out R²=0.983·캠페인 LOCO에서
  안정적이어서, 특정 구간이 적합을 왜곡했다는 징후가 없다.

"과도 점이 대칭 산포한다 / 과도 RMSE 1.7배 / 부호잔차 ≈ 0" 등 **상태 분류에 딸린 서술·수치도 근거로 쓰지 않는다.**

### 대체 기준 — 과도상태 / 준정상상태 구분

상수는 두 개뿐이고 **둘 다 데이터에서 직접 읽은 값**이다. 가정한 함수 형태가 없다.

| 상수 | 값 | 출처 |
|---|---|---|
| 잡음 바닥 | **0.003068** | 10/14(입력 3종 전 구간 고정)의 X 표준편차 |
| 정착시간 | **12분** | 10/17 18:00 계단에서 X가 최종값 ±0.003068 안에 들어오기까지 |

**판정: 직전 12분 창의 X 변동폭(max−min) > 0.003068 이면 과도, 아니면 준정상.**

자체 검증 — 입력을 건드리지 않은 두 캠페인에서 과도 0%가 나와야 하고, 실제로 나온다:
10/12 **0.0%** · 10/14 **0.0%** · 10/13 51.8% · 10/15 65.9% · 10/16 71.9% · 10/17-18 51.6%.

> **캐비앗 (2026-08-08, 재현 확인):** 위 상수·백분율은 현재 마스터데이터로 곧이곧대로 재현되지 않는다 —
> 10/14 X 표준편차 재계산값은 **0.00355**(≠0.003068)이고, 창=12행·임계 0.003068로 재현하면
> 10/14가 **2.3%**(≠0.0%), 나머지도 몇 %p씩 높게 나온다. 정의(창 길이·잡음바닥 산출구간)가
> 문서에 고정돼 있지 않아 생기는 차이다. **따라서 이 분류는 진단·내부 참고용으로만 두고, 보고서 근거로
> 인용하지 않는다.** 인용이 꼭 필요하면 스크립트로 정의를 재확정하고 재현값을 따르며 그 사실을 명시한다.
> (무가중 서술은 위 「무가중(OLS) 서술 규칙」의 입증책임+모델측 근거로만 한다.)

### 반응기 응답 지연 = 2~3분 (측정값, 가정 아님)

세 방법이 독립적으로 일치한다.

1. **계단응답** — 10/17 18:00(전 캠페인 유일한 입력 계단). 입구온도 저점 → X 저점까지 **3분**.
2. **지연 스캔** — 입구온도를 k분 전 값으로 치환, 최종 레시피(로짓 1차·I1·r1) 검증 RMSE:

## 압력 변수 제외의 확정 근거 (2026-07-31 재검증)

압력은 **안 중요해서 뺀 것이 아니다.** 물리적으로는 온도 다음으로 센 변수다.

- 적합된 속도식 기준 **r ∝ P^2.31** (농도 ∝ 압력, 속도 ∝ 농도^2.31).
- 10/14(입력 3종 고정)에서 압력 13.2 kPa(+0.52%) 변동 → 물리 예측 ΔX = **+0.0137**,
  실제 관측 ΔX = **+0.0097**. 즉 "노이즈 바닥 0.003068"은 순수 잡음이 아니다.

그럼에도 제외하는 이유 세 가지 (**2026-08-07부터 이 근거는 대단원 2 입력 선정 서술용 — 대단원 3 보고서에는 넣지 않음**):

1. **압력을 독립적으로 조작한 캠페인이 없다.** 압력은 유량의 그림자로만 움직였다
   (10/13 corr(PT-1100, FT-1004) = +0.9997). 학습된 압력 계수는 사실상 유량 효과다.
   입력 3종으로 압력을 회귀하면 R² = 0.9492 (PT-1004, VIF 19.7) · 0.9487 (PT-1100, VIF 19.5), 고유 정보는 5.1%뿐.
2. **케이스 스터디에서 압력 값을 지정할 수 없다.** PDF §3.3-6은 T·유량·비율만 준다.
   시뮬레이션에서 반응기 압력은 플로우시트가 **계산해 내놓는 값**이므로,
   입력으로 받으면 ONNX↔플로우시트 순환 의존이 생긴다.
3. **PT-1100은 결과 쪽에 가깝다.** 반응 2몰→1몰이라 전환율↑ → 몰수↓ → 압력손실↓ → 출구압↑.
   10/14 선행/후행 분석에서 **전환율이 약 12분 먼저** 움직인다(최대 상관 +0.984).
   12분은 반응기 응답(2~3분)이 아니라 컬럼→재순환 경로의 시간 규모다.

편상관(입력 3종 효과를 양쪽에서 제거한 뒤 비교): PT-1004 +0.1435, PT-1100 +0.1391
→ 남은 설명력 약 2%. 성능이 안 오른 정량적 이유.
