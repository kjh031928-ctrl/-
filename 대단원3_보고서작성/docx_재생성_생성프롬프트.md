> `초안으로 만든것들/보고서 본문.docx`·`Appendix.docx`(8/8판, 압력방향 오류·구버전)를 삭제한 뒤,

## 1. 소스와 산출 구조

- **콘텐츠 소스는 오직 `ML보고서_초안_대단원3.md`** 하나다. 이 파일이 정본이며, 수치·논지·문헌은 이미 재현·검증되어 있다. 새 사실을 지어내거나 근거 없이 추가하지 않는다(임의판단 금지).
- 산출은 기존과 같이 **두 파일**로 나눈다.
  - `보고서 본문.docx` — §3.1 ~ §3.6 (본문) + §3.5.4 성능표.
  - `Appendix.docx` — 부록 A(모델 용어집)·부록 B(참고문헌)·부록 C(L1 통계 교차검증).
- `.md` 말미의 「⏳ 초안 완성 전 남은 재료」 섹션과 최상단 HTML 주석(`<!-- 작성 지침 ... -->`)은 **내부용이므로 docx에 옮기지 않는다.**

## 2. ★확정 정정 — 압력 방향 (반드시 이 방향으로)

기존 8/8 docx는 `PT-1100 = P1 − ΔP`(P1을 독립, P2를 종속)로 **거꾸로** 서술했다. 이는 오류다. 대단원 2 최신본(§2.3.2·§2.3.3.3·§2.3.4)과 정본 `.md` §3.1.2가 확정한 올바른 방향은 다음과 같다.

- **독립적으로 결정되는 값:** 출구압 **P2(PT-1100)** — 후단 밸브모델(HV-1101, 유량계수 39.88·출구압 1.8 bar)에서 APS가 계산. 그리고 **ΔP** — ML(ONNX2)이 예측.
- **종속적으로 산출되는 값:** 입구압 **P1 = P2 + ΔP**.
- 따라서 "PT-1100(P2)을 ML 출력으로 두지 않는 이유"는 *계측기가 이미 있어서*가 아니라 **후단 밸브모델이 그 값을 계산하기 때문**이다.
- 단, ΔP **라벨 생성** 단계에서는 P2=PT-1100 **실측**을 쓴다(대단원 2 §2.3.3.1). 이 둘(배포 구조 vs 라벨 생성)을 혼동하지 않는다.

> 재생성 시 이 방향이 다시 뒤집히지 않도록 `.md` §3.1.2의 표·주의문단을 그대로 따른다.

## 3. 문체·형식 규칙 (작성 규칙 준수)

- **논문체 산문.** 개조식·구어체 금지. 각 절을 완결된 문단으로 서술한다.
- **표·불릿·볼드 최소화.** `.md`의 대부분 표와 불릿은 **산문(문단)으로 전환**한다. 아래 「§5 표 처리」의 소수 예외만 표로 남긴다.
- **다양한 문장 길이**로 매끄럽게 흐르게 하고, 불필요·중복 문구는 제거한다.
- **대단원 2 재변론 금지.** 입력·출력 선정·라벨 생성·압력 제외는 대단원 2 소관이므로 **짧은 포인터 한 번**으로만 인용하고 근거를 다시 세우지 않는다(§4 포인터표 참조).
- **페이지 제한(rev2 20장)** 을 의식해 간결하게. 보충자료(표 S1a/S1b 등)는 부록/보충으로 분리하거나 축약한다.
- **내부 작업원칙 문구 미기재.** "설명할 수 없는 것을 근거로 쓰지 않는다"류 우리 작업원칙 표현, 폐기된 표본가중(`ML_weight`·τ=3분·0.01/0.1 °C/min 임계값), 과도/준정상 상태분류(잡음바닥 0.003068 등)를 **무가중 정당화 근거로 쓰지 않는다.** 무가중은 ① 입증책임(정당화 불가한 가정 파라미터 불요) + ② 모델측 결과(앵커 재현·held-out R²·LOCO 안정)로만 서술(=`.md` §3.2.1·§3.2.3 그대로).

## 4. 용어·단위·포인터 (★기존 표기 유지)

**사용자 지시: 기존 표기를 그대로 유지한다(알아보기 쉬워야 함).** 대단원 2가 '프로필렌'을 쓰더라도 **본 장은 정본 `.md`의 표기를 바꾸지 않는다.**

| 항목 | 유지할 표기 (정본 `.md` 기준) | 비고 |
|---|---|---|
| 프로펜/프로필렌 | **`.md`대로 유지**(프로펜·프로펜유량) | 대단원 2 표기로 변환하지 않음 |
| ΔP 손실 단위 | **`.md`대로**(예: `0.25 bar = 25 kPa` 병기) | 바꾸지 않음 |
| 태그 | `.md`대로(TT-1006·FT-1004·FRC-1004·FT-1003/FT-1002 등) | §3.1.2 태그 각주 유지 |

**대단원 2 최신본 포인터(참조용, 인용 정확도만 확인 — 표기는 바꾸지 않음):**

- 전환율 라벨(SRK 밀도역산·Brent·재순환 큐멘 1 mol%) → **§2.2.1.1**
- 압력 출력·구조: 출구압 P2 밸브모델 → **§2.3.2** / ΔP 라벨 구성 → **§2.3.3.1** / ML 기반 ΔP → **§2.3.3.3** / **압력 관계 정리(P1=P2+ΔP) → §2.3.4(신설)**
- 입력 선정·압력 변수 제외 → **§2.4**(및 §2.5–§2.6), 외삽 판단 위임 → **§2.6**

> 정본 `.md`가 이미 위 포인터로 서술돼 있으면 그대로 둔다. 압력 관계를 한 곳으로 인용할 때는 **§2.3.4**를 쓰면 가장 깔끔하다(대단원 2가 이번에 신설·확정함).

## 5. 표 처리 — 산문 전환 vs 표 유지

`.md`의 표는 원칙적으로 **산문으로 전환**하되, 아래 소수만 **표로 유지**한다(수치 대조가 본질적이라 문단화가 오히려 불리한 것).

**표로 유지(권장):**
- **표 3-3(a/b) 스크리닝 상위 6종** — 상위권 RMSE 밴드 비교. (25종 전체 S1a/S1b는 보충자료로 축약·분리)
- **§3.5.4 성능 종합표**(ONNX1/ONNX2 × RMSE·R²·MAE) — 핵심 결과표.
- **부록 C 표 C1~C4**(표준화계수·삭제검사·누출시연·순열중요도) — 부록 성격상 표 유지.

**산문 전환(권장):**
- §3.1.2 출력 선정 표 → 문단(전환율 채택 근거·ΔP 종속 P1 관계).
- §3.4.3·§3.4.4 대표 후보 비교 표 → 문단.
- §3.4.5 곡률 반전점 표·XGBoost 3종 비교 표 → 문단.
- 부록 A 모델 용어집 표 → 계열별 문단 또는 최소 표(판단은 지면 여유에 따름).

> 판단 기준: **"표를 지우고 문장으로 옮겨도 정보 손실이 없으면 산문화"**, 수치 격자 대조가 핵심이면 표 유지.
