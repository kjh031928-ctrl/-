## A. 출력 후보 — 반응 성능

**(1) 대단원 3 가정**
후보 = {전환율 X, 출구밀도 AT-1100, 출구온도 TT-1100} 세 가지, 이 중 **전환율 X 채택**.

**(2) 대단원 2 실제**

후보 설정 경로는 §2.2.1에서 두 갈래로 제시된다.

- 직접 계측 방안: "반응기 출구에서는 출구온도 TT-1100, 출구압력 PT-1100 및 출구밀도 AT-1100이 계측되고 있다. 이 중 출구압력은 … 압력 관계 산출 기능에 포함하여 별도로 검토하였다. 따라서 반응 성능 및 출구 품질 산출을 위한 직접 계측정보로는 **출구온도와 출구밀도를 각각 독립적인 산출 대상**으로 고려하였다." (§2.2.1)
- 성능지표 방안: "두 번째는 반응 진행 정도를 나타내는 **프로필렌 전환율 (X)**을 ML의 산출값으로 사용하는 방법이다." (§2.2.1)

최종 후보 확정 문장은 §2.2.1.2 말미에 있다.

> "따라서 이후 ML 모델의 산출 후보로 **출구밀도 ρ_out, 출구온도 T_out, 프로필렌 전환율 X_P의 세 가지**를 설정하였다. … 세 방안 중 **실제 ML 산출값의 최종 선정은 이후 장에서 물리적 관계와 데이터 특성을 추가로 검토하여 수행하였다.**"

§2.6에서도 출력은 `y_reaction`이라는 **미지정 기호**로만 남는다: "(T_in, B⁄P, F_P) → y_reaction".

**(3) 판정**
- 후보 **개수 3개·물리량·태그명(TT-1100, AT-1100)**: **일치**. 세 후보는 **묶음이 아니라 개별**로 설정됨.
- **"전환율 X 채택"**: **미정(TBD)**. 대단원 2는 선정을 명시적으로 **대단원 3(이후 장)으로 위임**했다.

**(4) 참조 절**
- 후보 도출: **§2.2.1 반응 성능 및 출구 품질 산출 대상 검토**
- 후보 3종 확정: **§2.2.1.2 역산 전환율의 에너지수지 기반 일관성 검토** (마지막 단락)
- 출력 기호 유지: **§2.6 예측 목적별 이중 ML 모델 구성**

> ⚠ 대단원 3은 "전환율 채택은 §2.x 참조"라고 **포인터만 달 수 없다.** 채택 근거를 대단원 3 본문에서 세우고, 대단원 2에는 "세 후보 설정"까지만 포인터를 걸어야 한다.

## B. 출력 — 압력강하

**(1) 대단원 3 가정**
ΔP 단일 출력. 반응기 출구압 PT-1100은 후보가 아니라 **PT-1100 = P1 − ΔP**로 계산되는 종속값.

**(2) 대단원 2 실제**

기본 관계식은 동일하다. (§2.3) "반응기 입구압력 P1, 출구압력 P2 및 반응기 압력강하 DP는 다음의 관계를 가진다. **P2 = P1 − DP**"

그러나 **무엇을 독립적으로 결정하는가**가 대단원 3 가정과 반대다.

- §2.3.1: 입구압력 P1을 FCV-1004로 산정하려 했으나 실패. "따라서 FCV-1004에 압력강하 또는 유량계수와 같은 단일 조건을 부여하는 것만으로는 **반응기 입구압력 P1을 전체 운전범위에서 독립적으로 결정하기 어렵다**고 판단하였다."
- §2.3.2: P2를 **APS 밸브 모델**로 계산. "이에 **HV-1101의 유량계수를 39.88로 지정**하고 출구압력 1.8 bar를 적용하여 **APS에서 반응기 출구압력 P2가 계산되도록 구성**하였다." (검증: 총 급송유량 15,003∼18,389 kg/h에서 R²=0.9989, 기울기 실측 대비 102.4%)
- §2.3.3.3: ΔP만 ML 출력. "이에 **반응기 압력강하 DP를 ML 모델의 출력변수로 설정**하였다."
- §2.3.3.3: 최종 결선. "최종 APS 모델에서는 HV-1101의 밸브 모델을 통해 **반응기 출구압력 P2를 계산**하고 ML 모델이 예측한 압력강하를 **더하여 반응기 입구압력 P1을 산출**하도록 구성하였다. … 따라서 **반응기 출구압력은 후단 밸브 모델에서, 반응기 압력강하는 ML 모델에서 각각 결정되며 두 값을 이용하여 반응기 입구압력(P1)이 계산된다.**"

**(3) 판정**
- "ΔP 단일 출력": **일치**.
- "PT-1100(P2)이 종속값": **정정필요**. 보고서에서 **종속값은 P1(입구압)**이다. 계산 방향은 `P1 = P2 + ΔP`이며, P2는 HV-1101 밸브모델이 독립적으로 계산한다.
- 참고: PT-1100이 **실측으로 쓰이는 곳은 라벨 생성 단계(§2.3.3.1)뿐**이며, 운용 단계에서는 밸브모델 계산값이다. 대단원 3은 이 두 단계를 구분해서 써야 한다.

**(4) 참조 절**
- 관계식·자유도: **§2.3 압력 관계 산출 방안 검토**
- P2 결정(밸브모델): **§2.3.2 ML 기반 반응기 출구압력(P_2) 계산**
- ΔP를 ML 출력으로 설정 + 최종 결선: **§2.3.3.3 ML기반 ∆P_R 계산**

> ⚠ §2.3.2의 **제목이 "ML 기반 …"인데 내용은 ML이 아니라 APS 밸브 모델**이다. 대단원 2 내부 오기로 보이며, 대단원 3이 이 제목을 그대로 인용하면 독자가 P2도 ML 출력이라고 오해한다. 대단원 2에 제목 수정을 요청할 것.

## C. 입력 세트

**(1) 대단원 3 가정**
- 전환율 입력 = [TT-1006.PV(입구온도), FT-1004(프로펜 유량), FRC-1004(벤젠/프로펜 비)]
- ΔP 입력 = [TT-1006.PV(입구온도), 총 질량유량(FT-1003+FT-1004), FRC-1004]
- 온도 태그는 양쪽 모두 TT-1006.PV

**(2) 대단원 2 실제**

§2.4 (1차 선별): "12개의 SP 중 데이터 수집기간 동안 실제로 변화가 부여된 변수는 **FC-1002.SP, FRC-1004.SP, TC-1006.SP, TC-1103.SP, TC-1215.SP의 5개**였다." → "FC-1002.SP, FRC-1004.SP 및 TC-1006.SP는 각각 **반응기 유입 유량, 원료 조성비(B/P) 및 입구온도**를 결정하는 운전조건으로 반응기 유입상태를 직접 구성한다." → "따라서 본 보고서에서는 **유량, B/P 비율 및 반응기 입구온도**를 ML 모델의 1차 입력 후보로 선정하였다."

§2.6 (최종 입출력): "앞선 분석을 통해 **반응기 입구온도와 B/P 비는 두 산출 목적의 공통 입력**으로 선정하였으나 **유량정보는 예측 대상에 따라 서로 다르게 정의**하였다."

> (T_in, B⁄P, F_P) → y_reaction
> (T_in, B⁄P, F_total) → y_pressure
>
> "반응 정도 예측에는 한계반응물 공급량을 나타내는 **프로필렌 유량 F_P**을, 압력 관계 예측에는 고정층의 유동부하를 나타내는 **전체 유량 F_total**을 적용하였다"

**(3) 판정**

| 요소 | 판정 | 근거 |
|---|---|---|
| 입력 3변수 구조 (온도·비율·유량) | **일치** | §2.4, §2.6 |
| 유량 이원화 (반응=프로펜, ΔP=총유량) | **일치** | §2.6 |
| 온도 태그 `TT-1006.PV` | **정정필요** | 보고서 전체에 **`TT-1006`이라는 문자열이 0회**. 온도 변수는 `TC-1006.SP`(조작 SP) 또는 기호 `T_in`으로만 표기 |
| 프로펜 유량 태그 `FT-1004` | **일치(단 다른 맥락)** | `FT-1004`는 §2.2.1.1(라벨 생성)에서 1회 등장: "**FT-1004**의 질량유량은 공급조성을 반영하여 프로펜과 프로판의 몰유량으로 환산하였으며". §2.6의 입력 정의에서는 `F_P` 기호만 사용 |
| 총유량 `FT-1003 + FT-1004` | **보고서에 없음** | **`FT-1003` 등장 0회.** 총유량은 `F_total`, "총 급송유량", `FC-1002.SP`로만 표현되고 **구성 태그 합산식이 없다** |
| B/P 태그 `FRC-1004` | **일치** | 보고서는 `FRC-1004.SP` 표기 사용 |

**(4) 참조 절**
- 1차 선별: **§2.4 입력변수 1차 선별**
- 최종 입출력 세트: **§2.6 예측 목적별 이중 ML 모델 구성**

> ⚠ 대단원 3이 `.PV` 태그를 쓰려면 **대단원 2에 "SP로 선정한 변수를 학습 시에는 대응 PV 태그로 사용한다"는 연결 문장이 필요하다.** 현재 대단원 2에는 SP→PV 전환에 대한 서술이 전혀 없다. `FT-1003` 역시 대단원 2에 추가 요청 대상.

## D. 압력 변수 제외

**(1) 대단원 3 가정**
절대압(PT-1004/PT-1100)은 대단원 2 입력 후보에 애초에 없음(조작 SP 기준). "왜 압력을 뺐나"는 대단원 2 서술.

**(2) 대단원 2 실제**

§2.4에 **SP 기준 선별 논리**는 명확히 있다.

> "이 중 운전자가 직접 설정하는 조작조건에 해당하는 12개의 SP를 우선 검토하였다. **PV는 조작조건 변화에 따른 공정의 응답을 포함하므로 본 단계에서는 입력과 출력의 관계를 명확히 구분하기 위해 SP를 기준으로 조작변수를 식별하였다.**"
> "일정하게 유지된 나머지 SP는 학습 데이터 내에서 해당 조건 변화에 따른 반응기 응답을 확인할 수 없으므로 1차 후보에서 제외하였다."

즉 절대압 PT-1004/PT-1100은 **PV이므로 §2.4 첫 단계에서 후보에 오르지 않는다.** 대단원 3의 "애초에 후보에 없음(조작 SP 기준)"과 논리 구조는 동일하다.

다만 **"압력"을 명시적으로 제외 대상으로 지목하며 이유를 서술한 문장은 보고서 어디에도 없다.** 압력 계측(§1.3.1 "압력 5개")은 분류만 되어 있고, PT-1004·PT-1100은 §2.3 계열에서 **라벨 구성 재료로만** 쓰인다.

**(3) 판정**
- 논리 골격: **일치** (SP 기준 선별 → PV 전체 제외)
- 압력 명시 제외 서술: **보고서에 없음**

**(4) 참조 절**
- **§2.4 입력변수 1차 선별** (첫 단락, PV 제외 논리)
- 보조: **§1.3.1 계측변수 구성** (SP 12개 / PV 38개, 실제 변경된 SP 5개)

> 대단원 3이 "압력 제외 근거는 §2.4"라고 쓰는 것은 **가능하지만**, §2.4가 압력을 명시하지 않으므로 대단원 2에 한 줄 추가를 요청하는 편이 안전하다. 예: "반응기 압력 계측(PT-1004, PT-1100)은 조작 SP가 아닌 응답 PV이므로 입력 후보에서 제외하였다."

## E. 라벨 생성 — 전환율

**(1) 대단원 3 가정**
SRK 상태방정식으로 출구밀도(AT-1100)를 역산해 전환율 라벨 생성(**브렌트법/구간이분법**), 반응기 입구 재순환 큐멘을 **1 mol%(r1)**로 가정. **생성 주체 = 대단원 2.**

**(2) 대단원 2 실제**

**절차는 §2.2.1.1에 상세히 문서화되어 있다.**

- 목적·주체: "프로필렌 전환율은 공정에서 직접 계측되지 않으므로, 이를 ML 학습의 산출값으로 활용 하기 위해서 **실제 운전데이터로부터 전환율을 역산하였다.**" → **생성 주체 = 대단원 2 확정.**
- 기준: "반응기 출구에는 밀도계 **AT-1100**이 설치되어 있으므로 각 운전시점에서 **SRK 상태방정식으로 계산한 출구밀도가 실측 출구밀도를 재현하도록 프로필렌 전환율을 역산**하였다."
- 입력 조성 구성: "**FT-1004**의 질량유량은 공급조성을 반영하여 프로펜과 프로판의 몰유량으로 환산하였으며, 벤젠 유량은 신선 벤젠 **FT-1001**과 재순환 유량 **FT-1300**을 이용하여 구성하였다."
- 재순환 큐멘: "재순환 스트림에 포함되는 큐멘은 문제지 공정 설명에 **재순환 벤젠의 큐멘 함량이 1 mol% 이하로 제시된 점을 근거로, 그 상한값인 1 mol%를 적용**하였다."
- 근 선택: "본 반응기는 기상으로 운전되므로 기상에 해당하는 근을 압축인자 Z로 사용하였으며, 복수의 실근이 존재하는 경우에는 **최대 실근**을 선택하였다."
- 근 탐색: "각 운전시점에서 이 근을 탐색하기 위해 **Brent 방법**을 적용하였다. Brent 방법은 근을 포함하는 구간을 유지하면서 **이분법의 안정성과 보간법의 빠른 수렴성을 함께 이용**하며, 별도의 도함수 계산이 필요하지 않아 본 역산 문제에 적용하였다"
- 수치 설정: "프로필렌 전환율의 물리적 범위 **0 ≤ X ≤ 1**을 기준으로 … 근을 탐색하였으며, **수렴 허용오차는 1×10⁻¹²**로 설정하였다."
- 근 유일성: "본 계산 범위에서 전환율과 계산밀도의 관계를 확인한 결과, **실측밀도에 대응하는 전환율을 하나의 근으로 탐색**할 수 있었다."
- 교차검토: §2.2.1.2에서 단열 에너지수지 기반 X_energy와 비교. 3개 구간에서 증감 방향 일치, 변화량 차이 0.0044 / 0.0006 / 0.0037. 단 "본 비교를 **완전히 독립적인 전환율 검증으로 해석하기는 어렵다**".

**(3) 판정**
- 절차 문서화(SRK·AT-1100 역산·Brent·1 mol%): **일치**
- "구간이분법": **정정필요(표현)**. 보고서는 **Brent 방법 하나만** 적용 방법으로 제시하며, 이분법은 Brent의 **내부 성질 설명**으로만 언급된다. 대단원 3이 "브렌트법/구간이분법"을 병렬 나열하면 대단원 2와 어긋난다.
- **"안전을 위한 보수적(상한) 가정"**: **보고서에 없음**. 보고서는 "1 mol% 이하 → **그 상한값인 1 mol%를 적용**"이라고만 쓰고, **왜 상한을 취하는 것이 보수적/안전한지는 서술하지 않는다.** (K-3 코멘트가 바로 이 지점을 지적함)
- "r1"이라는 기호/케이스명: **보고서에 없음** (파일명 `reactor_conversion_r1.onnx`에만 존재)

**(4) 참조 절**
- 라벨 생성 절차: **§2.2.1.1 SRK 상태방정식 기반 프로필렌 전환율 역산**
- 라벨 타당성 교차검토: **§2.2.1.2 역산 전환율의 에너지수지 기반 일관성 검토**

## F. 라벨 생성 — 압력강하

**(1) 대단원 3 가정**
ΔP = PT-1004(실측) − **25 kPa**(HX-1005 튜브측 손실, **App B Table 4** 스펙값) − PT-1100(실측). 정의·생성 주체 = 대단원 2.

**(2) 대단원 2 실제**

§2.3.3.1 (DP 데이터 구성) 전문:

> "반응기 압력강하의 직접 계측값이 제공되지 않으므로 이용 가능한 압력 계측데이터를 바탕으로 기준 압력강하 데이터를 구성하였다. 앞서 설정한 압력전달 가정에 따라 **혼합기 후단 압력은 프로필렌 공급 배관의 PT-1004와 같으며 여기에서 HX-1005의 압력강하 0.25 bar를 차감한 값을 반응기 입구압력 P1으로 산정**하였다. **반응기 출구압력 P2에는 실측값인 PT-1100을 적용**하였다."
> "이와 같이 구성한 DP는 **직접 계측값이 아니라 앞서 설정한 압력전달 가정과 제공된 계측데이터를 이용해 산출한 값**이다. 이후 반응기 압력강하 산정 방안을 검토하기 위한 **기준 데이터**로 활용하였다."

압력전달 가정의 출처는 §2.3.1: "벤젠과 프로필렌이 혼합되는 **MX-1에서는 별도의 압력강하가 발생하지 않으며 혼합 후 압력은 두 유입 스트림 중 낮은 압력으로 결정**된다고 가정하였다."

25 kPa 값의 출처: §2.3.1 "**프로필렌 공급압력과 HX-1005의 압력강하는 문제에서 제공되므로** …"

라벨 사용처: §2.3.3.3 "모델 학습에는 2.3.3.1에서 압력 계측데이터를 바탕으로 구성한 DP 를 **학습 라벨로 사용**하였다."

**(3) 판정**
- 정의식 `ΔP = (PT-1004 − HX-1005 손실) − PT-1100`: **일치**
- 생성 주체 = 대단원 2: **일치**
- **단위 표기**: **정정필요(경미)**. 보고서는 **`0.25 bar`**, 대단원 3은 `25 kPa`. 수치는 같지만 상호참조 시 표기를 통일해야 함
- **"App B Table 4" 출처**: **보고서에 없음**. 대단원 2는 "문제에서 제공"이라고만 쓰고 **부록 표 번호를 인용하지 않는다**
- **"HX-1005 튜브측"**: **보고서에 없음**. 튜브측/쉘측 구분 서술 없이 "HX-1005의 압력강하"로만 표기
- **MX-1 압력전달 가정**: 대단원 3 가정에 **누락**되어 있음. ΔP 라벨은 이 가정 위에 성립하므로 대단원 3도 이 전제를 명시하고 §2.3.1을 가리켜야 함

**(4) 참조 절**

- 압력전달 가정(MX-1) 및 25 kPa 출처: **§2.3.1 APS 기반 반응기 입구압력(P_1) 계산**
- 라벨 사용: **§2.3.3.3 ML기반 ∆P_R 계산**

## G. 변수 선정 근거 (최소화·영향변수 비교·경계 논거)

**(1) 대단원 3 가정**
선정 근거는 대단원 2 소관(물리·공정 논리). 대단원 3은 통계 L1로 독립 재확인만 한다.

**(2) 대단원 2 실제**

근거가 **세 개 절에 분산**되어 있다.

- **§2.4 (데이터/조작 논거)**: SP 12개 → 실제 변화 5개 → 반응기 유입상태를 구성하는 3개. "TC-1103.SP와 TC-1215.SP는 각각 반응기 후단 냉각계와 증류계의 온도 제어조건으로 반응기 유입조건을 결정하는 변수와는 구분된다."
- **§2.5 (물리·반응공학 논거)**:
  - §2.5.1 반응성능: PBR 설계식 `dX/dW = −r_P/F_P0` 기준. "프로필렌 유량은 F_P0를 통해 전환율 변화에 영향을 미치며, 입구온도와 B/P 비율의 영향은 반응속도 −r_P와의 관계를 통해 살펴볼 수 있다." → 온도는 Arrhenius, B/P는 y_B·y_P → C_B·C_P 경로. "따라서 **세 입력변수 모두 전환율에 영향을 미칠 수 있는 반응공학적 근거가 있음을 확인**하였다." 이어 출력 3종의 물리적 연계(전환율↔출구온도, 전환율·T·P→밀도)를 검토.
  - §2.5.2 압력강하: Ergun equation 기준. ① 전체 유량 → 겉보기 유속 u = Q/A → 점성항·관성항 모두, ② 입구온도 → ρ, μ 및 u, ③ B/P → 조성 → 평균분자량·압축성계수 → ρ, μ.
- **§2.6 (구조 논거)**: "두 산출정보는 동일한 반응기에서 형성되지만, 각 현상을 설명하는 **유량의 물리적 기준과 이에 따른 입력공간이 서로 다르다.** 이를 하나의 모델로 통합하는 것은 서로 다른 지배 메커니즘을 하나의 입·출력 함수로 표현하는 것과 같으며 … 따라서 … **이중 ML 구조를 구성**하였다."

**(3) 판정**
- 물리·공정 논거 존재: **일치**
- **"입력 최소화" 논거**: **보고서에 없음** (변수 수를 줄이는 것 자체를 목표로 서술한 문장 없음)
- **"영향변수 비교"**: **일치** (§2.5가 정확히 이것)
- **"경계 논거"**: **보고서에 없음** (H항 참조)
- 통계 검증(L1/Lasso/상관분석 등): **보고서에 없음** → 대단원 3의 L1 재확인과 **중복 없음**. 대단원 3이 "통계적 재확인은 대단원 3에서 처음 수행"이라고 써도 무방

**(4) 참조 절**
대단원 3은 단일 절로 가리킬 수 없다. 다음과 같이 인용할 것:

> "입력 변수 선정 근거는 **§2.4(조작변수 기준 1차 선별)**, **§2.5(입력–출력 물리적 영향 분석)**, **§2.6(유량 이원화 및 이중 모델 구성)**에 서술되어 있으며, 본 장에서는 이를 통계적으로 독립 재확인한다."
