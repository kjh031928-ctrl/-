# 대단원 3 (ML) — 보고서 작성용 자료 폴더

이 폴더는 **대단원 3 최종 산문(보고서) 작성 전용**이다. 필요한 자료만 복사해 담았고,
원본은 상위 폴더에 그대로 있다. Cowork를 이 폴더로 지정해 작성하면 된다.

## 폴더 내용
- **`ML보고서_초안_대단원3.md`** — 정본 초안(작성 소스). 검증·일관성 감사 완료.
- **`figures/`** — 확정 그림 F1(ΔP 물리방향성)·F2(ΔP parity)·F3(전환율 parity) + 재현 스크립트.
- **`CLAUDE.md`** — 작업 규칙(★산출물 = Word docx, 표·불릿 최소·산문 위주, xlsx 금지, 근거 필수).
- **`ML_마스터데이터_PV_컬럼사전.md`** — 변수·태그 정의(용어 통일 기준).
- **`ML_마스터데이터_PV.csv`** — 데이터 원천(수치 재확인용).
- **`2026 ... rev2.pdf`** — 대회 문제(인용: p7 SRK, p8 App B 등).
- **`8월5일 / 8월7일 인수인계.md`** — 배경·결정 이력.
- **`대단원2_전달_SRK전환율라벨생성.md`** — 대단원 2가 2.2를 채우도록 넘길 snippet(참고).

## 작성 규칙 (요약)
1. **산출물 = Word(.docx)**, 산문 위주(표·불릿·볼드 최소). 그림은 꼭 필요한 F1·F2·F3만.
2. 근거(ref) 없이 서술 금지, 임의 판단 금지, 수치는 데이터로 검증된 값만.
3. **입력·출력 선정, 라벨 생성(SRK·DP), 압력 제외 = 대단원 2 소관** — 본 장은 받아서 모델링.
   L1 교차검증(§3.2.4·부록 C)은 대단원 3 방법검증으로 유지.
4. 페이지 제한(rev2 20장) 고려.
