CLAUDE.md §1-2: 검증 캠페인은 최종 확인 전용. 학습·튜닝·모델선택·조기종료·피처선택에 사용 금지.
승자(모델·하이퍼파라미터) 선택은 **블록20% 로만** 한다(추가 1). 아래는 검증셋을 **확인 목적**으로
평가에 넣은 횟수를 단계별 누적 기록한 것이다. 보고서 §3.3-3 에 인용 가능.

## 규칙 (이후 단계 공통)

1. **선택(승자·하이퍼파라미터)은 블록20% 내부검증으로만.** 검증셋 RMSE 로 모델을 고르지 않는다.
2. 검증셋 수치는 각 단계 종료 시 **확인용**으로만 표에 싣는다.
3. 검증셋에 평가한 모델 수를 이 파일에 **누적 기록**한다. 반복 평가가 늘수록 검증셋 과적합
   위험이 커지므로, 단계가 진행될수록 검증셋 평가 대상을 **소수 최종 후보로 좁힌다.**
4. 검증셋에는 어떤 모델도 **fit 하지 않는다**(LOCO-5 의 10/17-18 폴드도 주 분할 모델을 재사용).

## 누적 집계

- 검증셋 평가 누적 모델-회수: **107** (21 + 22 + 25 + 20 + 18 + 1). 단, 전부 확인용이며 선택은 블록20% 로 수행.
- 다음 단계 진입 시 이 파일에 한 줄을 추가하고 누적 회수를 갱신할 것.
