## 0. 절대 규칙 (위반 시 작업 중단하고 보고할 것)

1. **원본 대회 파일 수정 금지.** 아래 파일들은 읽기만 한다.
   - `2026 Chemical Engineering Process design competition_rev0_Attachment1.csv`
   - `2026 Chemical Engineering Process design competition_rev1 (1).pdf`
   - `2026 Chemical Engineering Process design competition_rev0_Attachment2.pdf`
   - `Centrifugal Pump - ONNX Example/` 폴더 전체
   - `AVEVA Process Simulation *.pdf` 전부
2. **임의 판단 금지.** 지시에 없는 값(임계값, 하이퍼파라미터 범위, 가정)을
   스스로 정하지 않는다. 필요하면 작업을 멈추고 질문한다.
3. **근거 없는 수치 사용 금지.** 코드에 등장하는 모든 상수는 출처를 주석으로
   명시한다. 출처는 (a) 대회 문제 Appendix, (b) AVEVA 제공값,
   (c) 본 지시서, (d) 데이터에서 계산한 값 중 하나여야 한다.
4. **무작위 분할(train_test_split 등) 사용 금지.** 1분 간격 시계열이므로

5. **검증 캠페인(10/17-18)은 최종 평가에만 1회 사용.** 모델 선택,
   하이퍼파라미터 탐색, 전처리 결정 어디에도 사용하지 않는다.
6. **재현성.** 모든 난수 시드는 42로 고정한다.
7. 작업 중 판단이 필요한 지점이 생기면 **추측하지 말고 목록으로 정리해 보고**한다.

## 1. 배경

2026 화학공학 공정설계 경진대회 과제이다. 큐멘 공정(벤젠 + 프로필렌 → 큐멘)의
단열 고정층 반응기 R-1100의 반응속도식이 알려져 있지 않아 first-principles
시뮬레이션이 불가능하다. 실측 데이터로 머신러닝 대리모델을 학습하여 AVEVA
Process Simulation에 ONNX로 통합하는 것이 목표이다.

본 지시서의 범위는 **머신러닝 부분(학습·평가·ONNX export)까지**이며,
시뮬레이션 통합은 별도 단계에서 진행한다.

### 3.1 입력 변수 (feature)

| 기호 | 컬럼명 | 단위 | 비고 |

| x1 | `TT-1006.PV` | °C | 반응기 입구 온도 |
| x2 | `FT-1004.PV` | kg/h | 프로필렌 스트림 질량유량 |
| x3 | `FRC-1004.PV` | 무차원 | 벤젠/프로필렌 **질량**유량비 (몰비 아님) |

`X_propene_conversion` — 프로펜 기준 전환율, 범위 0~1

엑셀에 이미 계산되어 있다. AVEVA의 `X[PROPENE]` 정의와 동일함이 확인되었다
(오차 0.0004%).

### 4.2 Phase 2 — CLAUDE.md 작성

프로젝트 루트에 작성한다. 위 0절의 절대 규칙, 3절의 확정 사항,
그리고 아래를 포함할 것.

- 담당 파일 구분 (train_linear.py / train_gbr.py 는 각자, 나머지는 공용)
- 공용 파일 수정 시 상대에게 알릴 것
- 커밋 전 `git pull` 필수

### 4.3 Phase 3 — 라벨 추가 생성

엑셀에는 재순환 큐멘 0 mol% 가정 라벨만 있다.
1 mol% 가정 라벨을 추가로 생성한다.

```
재순환 스트림(FT-1300.PV)이 벤젠 99 mol% + 큐멘 1 mol% 라고 가정
  MW_recycle = 0.99 x 78.115 + 0.01 x 120.196
  n_recycle  = FT-1300.PV / MW_recycle
  n_cumene_in = n_recycle x 0.01
  n_benzene_in = FT-1001.PV / 78.115 + n_recycle x 0.99
  프로펜·프로판은 0 mol% 경우와 동일
```

이 조성으로 SRK 역산을 다시 수행하여 `X_propene_recycle1` 컬럼을 만든다.
Brent 법(`scipy.optimize.brentq`)을 사용하고, **bracket 실패 시 예외를
처리하여 해당 행을 NaN으로 두고 개수를 보고**한다.

검증: 0 mol% 라벨과의 평균 차이가 약 0.0097 (1.6%) 이면 정상이다.

### 4.4 Phase 4 — 라벨 독립 검증

세 가지를 수행하고 `docs/실험결과_정리.md`에 기록한다.

1. **단열 에너지수지**: `dT_adiabatic_C x (n_total / n_propene)` 와
   전환율의 상관계수. 기대값 +0.99 이상.
2. **쿠멘 물질수지**: 캠페인 평균 기준으로
   `Cumene_predicted_reactor_kg_h` 와
   `FT-1201.PV x 0.99348` (제품 99 mol% 큐멘 순도 보정) 비교.
   ※ 0.99348 = 0.99 x 120.196 / (0.99 x 120.196 + 0.01 x 78.115)
3. **노이즈 바닥**: 10/14 캠페인(반응기 입력 고정)의 전환율 표준편차.
   이 값이 모델이 도달할 수 있는 정확도의 하한이다.

### 4.5 Phase 5 — Full Factorial (기본 설정)

아래 24개 조합을 모두 실행한다. **하이퍼파라미터는 scikit-learn 기본값을
사용한다** (튜닝은 Phase 6).

| 축 | 수준 | 개수 |
|---|---|---|
| 모델 | LinearRegression / GradientBoostingRegressor | 2 |
| 입력세트 | I1(x1,x2,x3) / I2(+PT-1004) / I3(+PT-1100) | 3 |
| 재순환 가정 | r0(0 mol%) / r1(1 mol%) | 2 |

- 학습: `Split == '학습'` (10/13~10/16)
- 검증: `Split == '검증'` (10/17-18)
- **표본 가중치는 사용하지 않는다(2026-07-31 확정).** `ML_weight` 컬럼은 무시한다.
- 각 실행마다 `results/{config_hash}.json` 저장 (설정 + 지표 + 실행시각)

### 4.6 Phase 6 — 지표

모든 조합에 대해 아래를 계산한다.

```
전환율 스케일:  RMSE, MAE, MAPE, R2
쿠멘 생산량 스케일: RMSE [kg/h], 평균 생산량 대비 %
   변환식: cumene_kg_h = X x n_propene_kmol_h x 120.196
```

쿠멘 생산량 환산을 반드시 포함하는 이유는, 전환율 오차가 최종 결과물에
어느 정도 영향인지가 실질적 판단 기준이기 때문이다.

참고: Attachment 2의 AVEVA 예제 코드가 RMSE / MAE / MAPE 를 보고하므로
이 세 지표는 반드시 포함한다.

### 4.7 Phase 7 — 외삽 거동 시험

학습 데이터의 입구 온도 최댓값은 360.0 °C 이나, 대회 사례 연구는
335~365 °C 를 요구한다. 각 모델에 대해 아래를 수행한다.

```
다른 입력을 10/12 정상운전 조건(FT-1004=3000, FRC-1004=5.0)에 고정하고
TT-1006 을 330 → 370 °C 로 1 °C 간격 스윕하여 전환율 예측값을 기록
```

트리 기반 모델은 학습 범위 밖에서 상수로 평탄화될 것으로 예상된다.
이 거동을 표와 그래프로 남긴다. **평가 항목으로 별도 보고할 것.**

### 4.7-2 Phase 7-2 — 외삽 구간 정량화

1. TT-1006 분포를 5°C 구간(330-335 ~ 360-365)별로 집계하되
   전체 / 학습셋 / 검증셋으로 나눠 표를 만든다.

2. 아래 값과 일치하는지 확인한다 (미리 계산된 기준값).
   - 학습셋 TT-1006 최댓값 = 349.977 °C
   - 학습셋에서 350 °C 이상 = 0 행
   - 355 °C 이상 121행은 전부 검증셋(10/17-18)에 존재
   - 355 °C 이상 구간의 X 범위 = 0.8410 ~ 0.9509

3. 외삽 거동 시험(Phase 7)을 두 조건에서 각각 수행하고 곡선을 겹쳐 비교한다.
   (a) 학습셋(10/13~16)만으로 학습한 모델 → 350~365 °C 가 외삽 구간
   (b) 전체(10/13~10/18)로 학습한 모델    → 360~365 °C 가 외삽 구간

4. 결과를 `docs/외삽구간_분석.md` 에 정리한다.

### 4.8 Phase 8 — 정상운전 재현 확인

10/12 캠페인(학습·검증 어디에도 쓰지 않음)에서 각 모델의 예측값을
실제 라벨(X = 0.61589)과 비교한다.

### 4.9 Phase 9 — 결과 정리

`docs/실험결과_정리.md` 에 아래를 작성한다.
- 24개 조합 전체 표 (설정 + 모든 지표)
- 축별 요약 (모델 / 입력세트 / 재순환가정 각각의 영향)
- 외삽 거동 비교
- 정상운전 재현 결과
- **튜닝이 필요한지에 대한 판단과 근거**

여기서 멈추고 결과를 보고한다. Phase 10 이후는 별도 지시를 받는다.

### Phase 11 — ONNX Export

```
출력 1개 (전환율)만. 밀도는 만들지 않는다.
입력 순서 고정: [TT-1006(°C), FT-1004(kg/h), FRC-1004(무차원)]

  onnx = to_onnx(model, X_train.to_numpy(dtype="float32"))
파일명: reactor_conversion_r0.onnx / reactor_conversion_r1.onnx
```

**최종 export 모델의 재학습 (수정):**
최종 시뮬레이션용 모델은 Phase 5~9에서 선정된 구조를 그대로 유지하되
10/13~10/18 전체로 재학습한 뒤 export 한다.
근거: 학습셋만으로는 케이스 스터디 요구 상한(365 °C)에 대해 15 °C 외삽이
되지만, 전체 재학습 시 5 °C 로 축소된다.
재학습 모델에 대한 독립 검증 데이터는 존재하지 않으므로, 보고하는 성능
지표는 동일 구조의 검증 캠페인(10/17-18) 결과임을 명시한다.

※ Phase 5~9는 원래 분할(학습 10/13~16 / 검증 10/17-18)로 진행한다.
  전체 재학습은 Phase 11에서만 적용한다.

## 6. 작업 방식

- 각 Phase 완료 시 무엇을 했고 무엇을 확인했는지 짧게 보고한다.
- 판단이 필요한 지점은 진행하지 말고 질문한다.
- 코드에 등장하는 상수는 모두 출처 주석을 단다.
- 결과 수치를 보고할 때는 계산 근거를 함께 제시한다.
