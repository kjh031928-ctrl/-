분류 기준: **입력(feature)** / **라벨(label, 출력)** / **라벨재료(라벨 계산에 쓰이는 원료·목표값)** /

| 기호 | 컬럼 | 단위 | 비고 |
|---|---|---|---|
| x1 | `TT-1006.PV` | °C | 반응기 입구온도. 반응기 응답 지연 **2~3분(측정값)** — 계단응답·지연스캔·지수평활 3법 일치. `질의응답_준비.md` §4-4~4-5 |

| x4' | `PT-1100.PV` | kPa | 반응기 출구압력. 입력세트 **I3** 후보 → **최종 제외**. (동시에 라벨재료 — 아래 1.3) [README] |

> **압력 제외 근거 (2026-07-31 확정, `압력변수_제외근거_검증.py`):**
> 압력은 물리적으로 중요하다(**r ∝ P^2.31**). 안 중요해서 뺀 것이 아니다. 제외 사유는 셋이다.
> ① 압력을 **독립 조작한 캠페인이 없다** — 유량의 그림자로만 움직였다
>    (10/13 내 corr(PT-1100, FT-1004) = **+0.9997**, 학습셋 전체 +0.7083).
>    입력 3종으로 압력 회귀 시 R² = 0.9492 (PT-1004, VIF 19.7) · 0.9487 (PT-1100, VIF 19.5), 고유 정보 5.1%.
>    편상관은 PT-1004 +0.1435 / PT-1100 +0.1391 → 남은 설명력 약 2%.
> ② **케이스 스터디에서 압력을 지정할 수 없다** — PDF §3.3-6은 T·유량·비율만 준다.
>    시뮬레이션에서 반응기 압력은 플로우시트 계산값이라 ONNX와 순환 의존이 생긴다.
> ③ **PT-1100은 결과 쪽이다** — 2몰→1몰 반응이라 전환율↑ → 압력손실↓ → 출구압↑.
>    10/14 선행/후행에서 전환율이 압력보다 약 12분 앞선다(최대 상관 +0.984).
>
> 성능 비교는 I1 0.02222 / I2 0.02235 / I3 0.02236이나, 60분 블록 부트스트랩 4,000회 판정
> 결과 **통계적으로 차이 없음**(95% 구간이 0 포함). "나빠졌다"고 서술하지 말 것.

> **선택세트 정의** [지시서 §4.5]: I1 = (x1,x2,x3), I2 = I1 + `PT-1004.PV`, I3 = I1 + `PT-1100.PV`.

## 2. 단위·주의사항

1. **FRC-1004.PV는 질량비이지 몰비가 아니다.** [README][지시서 §3.1]
   - 정의(App A): "Mass flow ratio (Benzene / Propene)".
   - 실측 평균 4.961, 정상운전점 5.000 [README]. 같은 조건의 **몰비는 2.820** → 혼동 주의.
   - 케이스스터디 요구 ratio 4~6도 **질량비 기준** [README][PDF §3.3].
   - 라벨 계산: 벤젠 몰수 = FRC-1004 × FT-1004 / 78.115.
2. **질량유량 → 몰유량 변환** [지시서 §3.4][README]
   - 프로펜 피드 조성은 App B Table 3의 **몰** 0.95 : 0.05(프로펜:프로판)이나,
     질량유량 분배에는 **질량분율 0.94773 : 0.05227**을 쓴다.
   - 검산: n_propene / n_propane = **19.000**.
3. **온도 단위는 °C** (TT-*, dT). SRK 계산 시 K 변환 필요(+273.15).
4. **압력 단위는 kPa** (PT-*). App B는 bar로 주므로 시뮬레이션 통합 시 ×100 주의.
5. **X 범위는 0~1** (전환율). float64로 계산·학습, ONNX export 시점에만 float32 [지시서 §11].
6. **AT-1100 / AT-1104 / AT-1201(밀도)은 현재 플랜트에서 측정 불가(*)** [PDF App A].
   → 바로 이 때문에 밀도를 대신할 ML 대리모델이 필요.

## 4. 라벨(전환율) 생성 과정 요약

1. **주 라벨 `X_propene_conversion` (재순환 큐멘 0 mol% 가정, 엑셀에 이미 존재)** [README][지시서 §3.2]
   - 입구 몰조성: n_propene, n_propane, n_benzene(위 1.3 식) + 큐멘 0.
   - 반응 C6H6 + C3H6 → C9H12. 전환율 X를 미지수로 두고 출구 몰조성·상평형을 SRK로 계산.
   - 출구온도 TT-1100, 출구압력 PT-1100에서 **SRK 밀도**가 측정 밀도 **AT-1100**과 같아지는
     X를 이분법으로 역산. → 이 X가 라벨. AVEVA `X[PROPENE]`와 오차 0.0004%.
2. **추가 라벨 `X_propene_recycle1` (재순환 큐멘 1 mol% 가정, Phase 3에서 생성 예정)** [지시서 §4.3]
   - 재순환 스트림 = 벤젠 99 mol% + 큐멘 1 mol% 가정.
   - `MW_recycle = 0.99×78.115 + 0.01×120.196`, `n_recycle = FT-1300 / MW_recycle`,
     `n_cumene_in = n_recycle×0.01`, `n_benzene_in = FT-1001/78.115 + n_recycle×0.99`.
     프로펜·프로판은 0 mol% 경우와 동일.
   - 이 조성으로 SRK 역산 재수행. `scipy.optimize.brentq` 사용, bracket 실패 행은 NaN + 개수 보고.
   - 검증 기대: 0 mol% 라벨과 평균 차이 ≈ 0.0097(1.6%).
3. **라벨 독립 검증(Phase 4)**: ① 단열 에너지수지 상관 ≥ +0.99, ② 큐멘 물질수지 대조,
   ③ 10/14 변동 바닥(σ=0.003068) — **진단 지표. "모델 정확도 하한"으로 쓰지 않는다.**
   > **2026-07-31 정정:** 이 변동은 잡음이 아니라 압력(r ∝ P^2.31)을 통해 전달된
   > 재순환 표류의 물리 변동이다. 10/14 압력 13.16 kPa 변동 → 물리 예측 ΔX +0.0137 vs
   > 관측 ΔX +0.0097. 상세는 `실험결과_정리.md` 검증 3 참조.
