# ONNX1 — 우리가 비교한 ML 모델 총정리 (쉬운 설명)

작성 2026-08-03. 반응기 전환율(프로펜이 얼마나 반응했나)을 예측하는 AI 모델(ONNX1)을 만들기 위해
**어떤 후보들을 어떻게 비교했고 무엇을 남겼는지**를 한 파일로 정리한다. 수치 표는
`docs/ONNX1_평가지표_결과표.md`, 단계별 상세는 `docs/Stage0~5_*.md`.

**최종 채택: 1차 로짓 선형** (입력 3개의 1차 직선식 + 로짓 변환).

---

## 1. 무엇을, 얼마나 비교했나

한 번에 하나씩 바꿔가며 **같은 채점 규칙**으로 비교했다. 개수를 자랑하려는 게 아니라, 매 단계
확실한 근거로 후보를 좁혀갔다.

| 무엇을 비교 | 몇 종 | 결과 |
|---|---|---|
| **모델 종류** (선형~신경망) | 22종 | 선형 계열만 상위권 |
| **예측값 변환** (그대로/로짓/로그 등) | 5종 | 로짓·arcsin만 0~1 안전, 로짓 채택 |
| **입력 변수 조합** | 7종 | 기본 3변수(I1) 유지, 압력은 제외 |
| **출력 종류** (전환율/큐멘 몰·질량) | 3종 | 전환율 예측 후 환산이 3배 정확 |
| **교차 확인 격자** | 18칸 | 로짓이 전 칸에서 물리 통과 |

## 2. 모델 22종 — 무엇이고 왜 남기거나 뺐나

### 남긴 계열: 선형 (단순한 식)
- **1차 선형** ★최종 — 입력 3개의 1차 직선식. 가장 단순(파라미터 4개)하고 강건. 검증 오차 0.0210.
- **2차 다항 / Ridge 2차** — 곡선식. 검증 오차가 1차와 사실상 같음(무승부). 조금 더 정확하지만 복잡.
- Ridge 1차 / Lasso / ElasticNet / PLS — 규제·축소 선형. 쓸 만하지만 1차보다 낫지 않음.

### 반례가 된 계열: 고차 다항
- **3차 다항** — 연습문제(내부검증)는 11위로 멀쩡했는데, 학습에 없던 높은 온도(365°C)에서 **예측이
  폭주**해 검증 22위(오차 0.377, 큐멘 오차 56%)로 무너졌다. → "내부 점수 좋다 ≠ 쓸 수 있다"의 증거.

### 뺀 계열: 트리·거리·신경망 (복잡한 모델)
- 결정트리 / 랜덤포레스트 / 엑스트라트리 / 그래디언트부스팅 / 히스트부스팅 / 에이다부스트,
  KNN, SVR, 가우시안 과정, 신경망(MLP) — 전부 검증 오차 **0.05~0.19** 로 선형보다 뚜렷이 나빴다.
  데이터가 매끄러운 물리 관계라 복잡한 모델이 오히려 손해였다.
- 특히 **평균 기준선(Dummy)과 히스트부스팅은 ONNX 변환 자체가 안 돼** 시뮬레이터에 실을 수 없다
  (대회 §3.1 미충족) → 성능과 무관하게 탈락.

## 3. 왜 성능 1등이 아니라 1차 선형을 골랐나

최종 후보 3종(1차 선형·Ridge 2차·2차 다항)은 검증 오차 차이가 **통계적으로 무승부**다(오차 범위가
겹침). 그래서 정확도 숫자가 아니라 **단순함과 안정성**으로 골랐다.

| | 1차 선형 ★ | Ridge 2차 |
|---|---|---|
| 검증 오차 | 0.0210 | 0.0193(근소 우위) |
| 복잡도 | **4개** | 10개 |
| 날짜 하나 빼면 흔들림 | **0.094** | 0.372(4배) |
| 최악 캠페인 오차 | **0.196** | 0.465 |

→ 정확도는 사실상 같은데 1차 선형이 훨씬 단순하고 캠페인이 바뀌어도 안정적이라, **바꿀 이유가 약하다.**

## 4. "최악 캠페인 오차"가 무슨 말인가 (쉬운 설명)

우리는 강건성(모델이 낯선 조건에서도 버티는지)을 이렇게 잰다:

> **날짜(캠페인)를 하나씩 빼고, 나머지로 학습한 뒤, 뺀 날을 맞혀본다.** 이걸 5개 날짜에 대해 반복하고,
> 그중 **가장 안 맞은 날의 오차**를 "최악 캠페인 오차(LOCO-5 최악)"라고 부른다.

1차 로짓 선형의 날짜별 결과(전환율 오차 RMSE):

| 뺀 날 | 그 날을 맞힌 오차 | 그 날 특징 |
|---|---|---|
| 10/13 | 0.057 | 유량만 흔든 날 |
| 10/14 | 0.006 | 거의 안 흔든 날(제일 쉬움) |
| **10/15** | **0.196 ← 최악** | **유량 + B/P비를 동시에 넓게(4~6) 흔든 날** |
| 10/16 | 0.020 | 온도만 흔든 날 |
| 10/17–18 | 0.021 | 최종 검증(온도+유량) |

- **최악 = 0.196**, 10/15 를 통째로 뺐을 때다. 이유는 어렵지 않다: 10/15 는 **두 가지(유량과 비율)를
  동시에, 그것도 넓게** 바꾼 날이라, 그 날을 아예 안 보고 학습하면 그 조합을 예측하기가 가장 어렵다.
- **주의:** 이 0.196 은 "그 날을 학습에서 완전히 뺐을 때"의 값이라 일부러 가혹하게 만든 시험이다.
  실제 배포 모델은 10/15 를 **포함해** 학습하므로 이런 큰 오차는 나지 않는다. 최종 검증(10/17–18)
  오차는 **0.021** 이다. 즉 최악 캠페인 오차는 **"성능"이 아니라 "강건성"을 보는 스트레스 테스트**다.
- 이 지표가 유용한 이유: 1차 선형은 최악이 0.196 인데 Ridge 2차는 0.465 로 **2배 이상 나쁘다.** 낯선
  조합에서 1차 선형이 훨씬 덜 무너진다는 뜻이고, 이것이 1차를 택한 핵심 근거 중 하나다.

## 5. 함께 확정된 것들 (모델 외)

- **예측값을 로짓으로 변환**한다 → 전환율이 구조적으로 0~1 안에만 나온다(365°C 외삽에서도 27점 전부 정상).
- **입력은 기본 3변수**(입구온도·프로펜유량·B/P비). 압력은 성능이 좋아 보여도 케이스스터디가 값을
  안 주고 시뮬레이터가 되레 계산하는 값이라 **순환**이 생겨 뺐다.
- **출력은 전환율을 예측한 뒤 큐멘 생산량으로 환산**한다(직접 예측보다 3배 정확).
