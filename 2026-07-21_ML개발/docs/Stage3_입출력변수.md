- 총유량(I1b) = `FT-1003.PV + FT-1004.PV` (정본에 FT-1003 없어 원본 CSV에서 Timestamp 병합) **[계산]**.
- **I1b 는 두 모델 모두 검증을 개선**(0.019→0.017)하고 케이스스터디 지정 가능 → Stage 4 후보. 단 FRC 가 주어지면
  총유량과 FT-1004 는 서로 환산되는 **재매개변수화**에 가깝다(새 변수 아님).

### 압력 세트(I2~I5) 제약 심사 — 성능이 좋아도 채택 불가

| 심사 항목 | 결과 | 판정 |
|---|---|---|
| 케이스스터디 지정 가능(rev2 §3.3-6) | 압력 **미지정** → 시뮬레이션 입력 불가 | **불가** |
| ONNX↔플로우시트 순환 의존 | 반응기 압력은 플로우시트가 **계산하는 종속량** → 순환 | **불가** |
| 공선성 VIF(압력\|T,F,R) | PT-1004 **학습 19.7 / 전체 62.6 / 검증 901.1** · PT-1100 19.5/62.3/868.7 | 과도 |
| 계수 안정성(캠페인 부호) | PT-1004 **10/14 +0.00296 / 10/16 −0.00847**(부호 반전), PT-1100 +0.00304/−0.00863 | 불안정 |
| 성능 이득 | 1차선형만 미미 개선(I4 0.02099→0.01747), **다항 모델은 검증 급락**(Poly2 0.021→0.21) | 미미·불안정 |

→ 압력은 **물리적으로는 온도 다음으로 센 변수**지만(참고: r∝P^2.31), 독립 조작 캠페인이 없어 학습된
압력 계수가 사실상 유량의 그림자다(10/13 corr(PT-1100,FT-1004)=+0.9997 [계산, CLAUDE.md]).
따라서 이 단계는 성능 비교가 아니라 **제약 심사**이며, 압력 세트는 성능과 무관하게 제외한다.

## 3-B. 출력(라벨) 비교 — 같은 큐멘 kg/h 상대오차로 통일

| 출력 경로 | Ridge Poly2 큐멘 kg/h 상대RMSE | Poly2 |
|---|---|---|
| **Y1** 전환율 X 예측(logit) → 알려진 프로펜몰유량으로 환산 | **2.80%** | **3.11%** |
| Y2 큐멘 몰유량[kmol/h] 직접 예측 → ×120.196 | 9.27% | 8.50% |
| Y3 큐멘 질량유량[kg/h] 직접 예측 | 9.27% | 8.50% |

- **X 를 예측해 환산하는 Y1 이 직접 예측(Y2/Y3)보다 약 3배 정확**하다. 이유: 환산 시 프로펜 몰유량은
  입력에서 **정확히 아는 값**이라, 모델은 [0,1] 전환율만 학습하면 된다. 직접 예측은 유량 의존까지
  다시 학습해야 해 손해다. Y2·Y3 는 스케일만 다른 동일 대상이라 상대오차가 같다(OLS 스케일 불변) **[계산]**.
- ⚠ Y2/Y3 직접 예측은 큐멘 스케일이 커 raw 타깃·alpha=1.0 고정으로 적합했다(상대오차 비교 목적, 명시) **[가정: alpha 고정]**.

## 보고서용 설명

**1) 이 Stage 가 답하는 항목:** 목차 4.2 / 내부 §3.3-2 — "왜 이 입력·출력 변수를 골랐나".

**2) 무엇을 왜 했는지:** 반응기를 대체할 ML 은 시뮬레이션이 실제로 줄 수 있는 값만 입력으로 받아야 한다.
그래서 입력 후보 7종(기본 3변수, 총유량 치환, 곱항 추가, 압력 4종)과 출력 3종(전환율·큐멘 몰유량·큐멘
질량유량)을 같은 평가 규약으로 비교했다. 핵심 질문은 "성능이 제일 좋은가"가 아니라 "케이스스터디에서
지정 가능한가, 시뮬레이션과 순환 의존을 만들지 않는가"였다. 결론은 (i) 압력 변수는 성능이 좋아 보여도
케이스스터디가 압력을 주지 않고 반응기 압력이 플로우시트의 계산 결과라 순환이 생겨 제외하며, (ii) 출력은
전환율을 예측해 환산하는 편이 큐멘을 직접 예측하는 것보다 약 3배 정확하다는 것이다.

**3) 핵심 수치:**
- 압력 변수 공선성 VIF(PT-1004) 학습 **19.7** / 전체 **62.6** / 검증 **901.1** [계산].
- 압력 계수 캠페인별 부호 반전: 10/14 **+0.00296**, 10/16 **−0.00847** [계산].
- 출력 경로별 큐멘 kg/h 상대오차: 전환율 환산 **2.80%** vs 직접 예측 **9.27%** (Ridge Poly2) [계산].
- 물성 상수 120.196·42.081 [주어짐, AVEVA], 프로펜 질량분율 0.94773 [계산, Appendix B].
- Y2/Y3 직접 예측의 정규화 alpha=1.0 [가정] — 상대오차 비교 목적. 가정을 쓰지 않는 주 경로는 Y1(전환율)이다.

**4) 예상과 달랐던 점(반례):** 압력을 넣으면 **블록20%(내부검증)는 낮아지는데 검증(외삽)은 나빠졌다**.
다항 모델에서 특히 심해 Ridge Poly2 검증이 0.019→0.046, Poly2 는 0.021→0.21 로 급락했다. 1차 선형에서는
반대로 미미하게 좋아진다(I4 0.02099→0.01747). 즉 압력의 이득은 모델 구조에 따라 방향이 뒤집히는
불안정한 신호이며, 이는 "케이스스터디 지정 불가"라는 제약과 **독립적으로** 압력 제외를 뒷받침한다.
곱항(I1c)·압력을 넣은 Poly2 가 검증 0.21~0.28 로 붕괴한 것은 Stage 1 의 Poly3 외삽 발산과 같은 현상이다.

**5) 재현 안 된 값:** 현재 배포본은 프롬프트가 말한 Poly2/0.02111 이 아니라 **로짓 1차 선형(Linear1)**이며
held-out RMSE 는 **0.020987** 이다(ONNX 노드 = LinearRegressor+Sigmoid, `export_onnx.py` 근거). 재현값을 따른다.
