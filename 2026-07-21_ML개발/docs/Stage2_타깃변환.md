# Stage 2 — 타깃 변환 비교 (ONNX1 반응기 전환율)

고정: 입력 I1 · 주 분할 · Stage 0 프로토콜(`src/evaluation.py` 재사용). 대상 = Stage 1 블록20% 상위 4개 + Linear1.
변환 5종: raw / logit / log / log(1-y) / arcsin√y. 각 변환의 역변환 노드를 ONNX 그래프에 실제로 붙여 왕복 검증.

## 승자 · 채택

- **블록20% 전체 최우수**: Poly 2차 / **log1m** (block20 0.007284, 검증 0.015931) — 단 log1m 은 구조적 [0,1] 보장이 아니다(Linear1 1건 이탈).
- **구조적 안전(logit·arcsin) 중 블록20% 최우수**: Ridge Poly2 / **logit** (검증 0.019293).
- arcsin 은 일부 모델에서 검증 RMSE 가 더 낮으나(Linear1 0.01803·Lasso 0.01839·ElasticNet 0.01897), **검증으로 고르지 않는다.** 블록20% 로는 상위 모델(Ridge Poly2·Poly2)에서 logit 이 arcsin 보다 낮다.

### 채택안 — **logit 유지**

근거(성능 아닌 구조):
1. **구조적으로 (0,1) 에 가둔다** — 365°C 외삽(학습 최대 349.977°C 초과)에서도 범위이탈 0. raw·log 는 9~10/27 이탈해 대회 케이스스터디에서 물리적으로 불가능한 X>1 을 낸다.
2. **ONNX 역변환 = Sigmoid 단일 노드**로 배포본과 동일(`export_onnx.py`). arcsin(Sin→Mul)도 가능하나 이점 없음.
3. **블록20% 로 안전변환 중 최우수**(Ridge Poly2/logit 0.00741). arcsin 의 검증 우위는 선택 근거로 쓸 수 없다(확인용).
4. Stage 1 의 Poly3 사례(block20 11위·검증 22위, 외삽 발산)처럼 **범위 안전성이 RMSE 보다 선정에서 우선**한다.

> 보고서 §3.3-1 보조 인용: 전환율은 정의상 [0,1] 이므로 예측을 이 구간에 구조적으로 가두는 변환이 필요하다. 로짓 변환은 학습 범위를 넘는 외삽(365°C)에서도 27/27 격자점을 [0,1] 안에 유지했고, raw·log 변환은 9~10점에서 X>1 을 냈다. ONNX 로는 Sigmoid 노드 하나로 역변환이 배포되며, 이는 성능이 아니라 물리 타당성과 배포 단순성에서 로짓을 채택하는 근거다.


## 보고서용 설명

**1) 이 Stage 가 답하는 항목:** 목차 4.3 보조 / 내부 §3.3-1 보조 — "왜 로짓 변환을 썼나".

**2) 무엇을 왜 했는지:** 전환율은 정의상 0~1 이다. 모델이 이 범위를 벗어난 값을 내면 물리적으로 불가능한
예측이 된다. 그래서 예측 대상(타깃)을 어떻게 변환하느냐를 5가지(그대로/로짓/로그/log(1−y)/arcsin)로 비교했다.
핵심은 RMSE 가 아니라 "케이스스터디 상한 365°C(학습 최대 350°C 를 넘는 외삽)에서도 예측이 [0,1] 안에
머무는가"이며, 27점 격자에서 범위 이탈 개수를 셌다.

**3) 핵심 수치:** 격자 범위이탈 평균 — raw **9.0**/27, log **8.4**, log(1−y) 0.2, **로짓 0.0, arcsin 0.0** [계산].
로짓·arcsin 만 전 모델·전 격자에서 이탈 0(구조적으로 (0,1)에 가둠). 5개 변환 모두 역변환 노드를 표준 ONNX
연산으로 붙여 왕복 성공(최대차 ≤3e-6) [계산]. 로짓 클립 경계 eps=1e-6 [주어짐].

**4) 예상과 달랐던 점:** arcsin 이 일부 모델에서 검증 RMSE 가 로짓보다 낮았다(Linear1 0.01803 vs 0.02099).
그러나 검증으로 고르지 않는 규칙에 따라 블록20% 로 보면 상위 모델에서는 로짓이 더 낮아, 성능 우열이 아니라
구조적 안전성·배포 단순성(Sigmoid 한 노드)으로 로짓을 유지했다. raw·log 는 외삽에서 X>1 을 9~10개 냈다.

**5) 재현 안 된 값:** 없음(신규 분석, 기존 기준값 없음).
