## 1. 개요

### 과제
쿠멘(큐멘) 공정의 반응기 R-1100은 단열·촉매 충전 반응기이나 **반응속도식이 미지(Unknown)**
다(App B Table 5). 정상 상태에서 반응기 출구 밀도(AT-1100)를 직접 측정하면 전환율을
알 수 있지만, **현재 플랜트에서 밀도계는 측정 불가**다(App A). 따라서 값비싼 밀도계를
대신해, **측정 가능한 입력만으로 프로펜 전환율(0~1)을 예측하는 ML 대리모델**을 만드는 것이
과제다.

### 최종 결론 (한 줄)
**로짓(logit) 변환 후 1차 선형 회귀 · 입력 3종(I1: 반응기 입구온도·프로펜유량·질량비) ·
검증셋 쿠멘 생산량 오차 3.19%** — 성능이 전 대안 중 최고이면서, 역변환(시그모이드)이
출력을 **구조적으로 [0,1]에 가둬** 물리 상한 위반을 원천 차단한다.

### 도달 경로 요약
```
라벨 생성:  이상기체 근사(실패) → SRK 상태방정식(성공) → r0/r1 두 벌 + 독립검증 3종
변수 선택:  단순 상관(기각) → 인과 기반 I1 → 압력 I2/I3 검토(효과 미미·누수 아님 확인) → I1 확정
모델 탐색:  24조합 full factorial → 외삽 문제 발견 → 총 17기법 비교 → 로짓 1차만 생존
개선 시도:  2차 다항/물리변환/커널 재평가 → 전부 실패(좁은 학습구간이 근본원인)
최종 확정:  로짓 1차 I1 → 전체 재학습 → ONNX export(시그모이드 내장) → 시뮬레이션 통합
```

## 2. 라벨 생성의 시행착오

라벨(`X_propene_conversion`)이 틀리면 이후 모든 것이 무의미하다. 그래서 라벨 생성에
가장 큰 검증 비용을 들였다.

### 2.1 첫 시도 — 이상기체 근사 (폐기)

- **기대:** 반응기 출구는 고온(~440 °C)·중압(~2.5 MPa) 기상이므로, 이상기체 법칙
  `ρ = PM/RT`로 밀도를 계산하고 전환율 X를 역산할 수 있으리라 기대했다. 상태방정식보다
  훨씬 간단하다.
- **실제:** 목표 밀도(AT-1100)를 재현하는 X를 이분법으로 찾을 때, **bracket(부호가 다른
  두 끝점) 확보에 실패하는 행이 약 7.4% 발생**했다. 즉 X를 0~1 전 구간에서 움직여도
  이상기체 밀도가 실측 밀도에 도달하지 못하는 조건이 다수였다.
- **왜:** 이 조건(대비온도·대비압력 영역)에서 혼합물은 이상기체에서 상당히 벗어난다.
  특히 벤젠·큐멘 같은 무거운 성분의 실제 밀도는 이상기체 예측과 크게 어긋나, 역산
  방정식의 해가 물리적 X 범위 밖으로 밀려나면서 bracket이 성립하지 않았다.

### 2.2 정정 — SRK 상태방정식 (채택)

- **기대:** 대회 지정 열역학 모델이 **SRK(Soave-Redlich-Kwong) VLE**(App B Table 1)이므로,
  같은 EOS로 밀도를 계산하면 라벨이 AVEVA 시뮬레이터와 정합될 것으로 기대했다.
- **실제:** SRK 3차식의 **최대 실근(기상 루트)** 으로 밀도를 계산하고
  `scipy.optimize.brentq`로 X를 역산한 결과, **재순환 1 mol% 라벨의 bracket 실패 0건**
  (CLAUDE.md §5 기준값 = 0건, 일치). AVEVA `X[PROPENE]`와 오차 **0.0004%**로 일치.
- **왜:** SRK는 실제 기체의 압축인자(Z)를 반영하므로 고압 기상 밀도를 정확히 재현한다.
  이상기체에서 X가 범위 밖으로 밀리던 문제가 사라졌다.
- 구현: `src/srk.py`. 물성상수(MW·Tc·Pc·ω·kij·R)는 하드코딩 금지, 전부
  `config/base.yaml`에서 읽는다(AVEVA 제공값, 대체 금지).

### 2.3 판단들 — 성분 구성과 재순환 가정

**(a) 프로판 4성분 포함**
- **기대/쟁점:** 프로펜 피드에는 프로판이 섞여 있다(질량분율 0.94773 : 0.05227). 프로판은
  불활성이라 반응에 참여하지 않으니 무시해도 되는가?
- **판단:** 무시하면 안 된다. 프로판을 조성에서 빼면 몰수·밀도 계산이 틀어져
  **약 −4.84% 편향**이 생긴다. 따라서 라벨 계산 전 구간에서 **벤젠·프로펜·프로판·큐멘
  4성분**을 유지한다(`src/srk.py`의 `COMPONENTS` 고정 순서). 프로판은 반응에 불변이나
  총몰수·밀도에는 기여한다.

**(b) 재순환 큐멘 조성 — r0/r1 두 벌 생성**
- **쟁점:** 반응기 입구 벤젠에는 하류에서 돌아오는 재순환 스트림이 섞이고, 그 재순환에
  소량의 큐멘이 있을 수 있다. 그 조성을 모른다.
- **판단:** 추측하지 않고 **두 가정으로 라벨을 두 벌 생성**해 이후 성능·물리 검증에서
  비교하기로 했다.
  - **r0** (`X_propene_conversion`): 재순환 큐멘 **0 mol%**. 엑셀에 이미 존재.
  - **r1** (`X_propene_recycle1`): 재순환 큐멘 **1 mol%**. 신선 벤젠(FT-1001)과 재순환분
    (FT-1300)을 나눠 입구 조성을 재구성해 SRK 재역산(`src/labels.py`).
- **검증 기대값 대조:** r0 − r1 평균 차이 **≈ 0.0097**(CLAUDE.md §5 기준값과 일치).
  이 차이는 작아, 뒤(§4)에서 보듯 검증 성능에 주는 영향은 미미하다.

### 2.4 독립 검증 3종 — 라벨을 만든 센서가 아닌 다른 센서로 교차확인

밀도로 만든 라벨을, **라벨 생성에 전혀 쓰지 않은** 독립 센서로 검증했다(순환논증 회피).

| 검증 | 사용 독립 센서 | 결과 | 기준 | 판정 |
|------|----------------|------|------|:----:|
| 단열 에너지수지 상관 | TT-1006, TT-1100 (온도차) | **+0.995552** | ≥ +0.99 | ✅ |
| 쿠멘 물질수지 | FT-1201 (제품 유량) | 캠페인별 −1.58 ~ +2.39%, 전체 −0.001% | ±3% 이내 | ✅ |
| 노이즈 바닥(10/14) | 입력 3종 고정 구간 | σ = **0.003068** | =0.003068 | ✅ |

- **에너지수지(+0.9956):** 밀도로 만든 라벨이 온도계만으로 재구성한 반응 진행도와 거의
  완벽히 일치 → 두 독립 경로가 같은 물리량을 가리킨다는 강한 증거.
- **물질수지(±3%):** 반응기 라벨로 계산한 큐멘 생산량이 별개 제품 유량계와 캠페인 평균
  ±3% 이내로 닫힘. 전체 평균 −0.001% → 계통 편향 없음.
- **변동 바닥(0.003068):** 입력 3종이 고정된 10/14에서도 라벨이 σ≈0.003 변동.
  > **⚠ 정정한 판단(§8-③ 참조):** 초기에는 이 값을 "모델 성능의 하한 근거"로
  > 쓰려 했으나, **진단용 지표로 격하**했다. 모델 성능 판단은 별도로 쿠멘 생산량 오차
  > (kg/h 및 평균대비 %)로 수행한다.
  > **⚠ 2026-07-31 추가 정정 — "노이즈"라는 표현을 쓰지 않는다.** 이 변동은 잡음이 아니라
  > 대부분 **설명 가능한 물리 변동**이다. 10/14에서 압력이 13.2 kPa(+0.52%) 움직였고,
  > 적합된 속도식(r ∝ P^2.31)으로 계산한 ΔX = **+0.0137** vs 실제 관측 ΔX = **+0.0097**로
  > 같은 자릿수다. 그 압력 변동 자체는 재순환 고리 표류의 결과다
  > (corr(X, TC-1215) = −0.7969, 선행/후행상 전환율이 압력보다 약 12분 앞섬).
  > 따라서 "어떤 모델도 넘을 수 없는 한계선"이 아니라 "**재순환 조성을 입력에 넣지 않아
  > 남는 변동**"으로 서술한다.

## 3. 변수 선택의 시행착오

### 3.1 단순 상관계수로 고르면 안 되는 이유 (기각한 접근)

- **기대:** 각 태그와 라벨 X의 상관계수를 계산해 높은 순으로 고르면 간단하다.
- **실제/왜 기각:** 라벨 X는 **밀도(AT-1100)를 SRK로 역산**해 만든 값이다. 밀도 정의에
  들어가는 변수(출구 온도·압력 등)는 X와 **정의상 높은 상관**을 갖는다. 이는 인과가 아니라
  **밀도 계산식에 의한 허위 상관**이다. 상관 순으로 고르면 라벨 생성에 쓰인 변수를
  입력으로 끌어들여 **정보 누수(leakage)** 를 자초한다. 따라서 상관 기반 선택을 기각했다.

### 3.2 인과 기반 선택 — 반응기 입구 조건만 (채택)

- **원칙:** 전환율을 물리적으로 **결정하는 원인**만 입력으로 쓴다. 반응기 입구에서 이미
  정해지는 조건 = **입구온도(TT-1006) · 프로펜유량(FT-1004) · 벤젠/프로펜 질량비
  (FRC-1004)**. 이것이 핵심 입력세트 **I1**이다(config `features.I1`).
- 세 변수 모두 반응기 **입구**에서 관측되어 출력(전환율)보다 시간·인과적으로 앞선다.
  (FT-1004·FRC-1004가 라벨의 몰수 산출에도 쓰이나, 이는 입력→라벨의 물리적 정의 방향이라
  누수와 구분된다 — CLAUDE.md §2.1.)

### 3.3 압력의 딜레마 — 물리적으로 **중요하나** 이 데이터로는 분리 불가

> **2026-07-31 재검증으로 전면 개정.** 이전 판의 "물리적으로 필요하나 효과 없음"은
> 오해를 부르는 제목이었다. 압력은 효과가 없는 것이 아니라 **효과를 분리할 수 없다.**
> 재현: `압력변수_제외근거_검증.py`

- **기대:** 밀도·전환율은 압력에 의존하므로, 압력 태그를 넣으면 성능이 오를 것으로 기대.
  후보: `PT-1004`(I2, 프로펜 공급압력) / `PT-1100`(I3, 반응기 출구압력).
- **실제:** 로짓 계열에서 I1 = 0.02222, I2 = 0.02235, I3 = 0.02236.
  60분 블록 부트스트랩 4,000회 판정 결과 **통계적으로 차이 없음**
  (I2−I1 = +0.00013 [−0.00007, +0.00031] / I3−I1 = +0.00014 [−0.00005, +0.00031]).
  → **"나빠졌다"가 아니라 "차이가 없다"가 정확한 서술이다.**
- **왜 안 올랐나 (정보 중복):** 압력을 입력 3종으로 회귀하면 **R² = 0.9492 (PT-1004, VIF 19.7) · 0.9487 (PT-1100, VIF 19.5)**,
  고유 정보는 **5.1%**뿐이다. 편상관(양쪽에서 입력 3종 효과 제거 후)은
  PT-1004 **+0.1435**, PT-1100 **+0.1391** → 남은 설명력 약 2%.
- **공선성의 정확한 범위 (이전 오류 기록 정정):**

  | 범위 | corr(PT-1100, FT-1004) |
  |---|---|
  | 10/13 (유량만 조작) | **+0.9997** |
  | 10/15 (유량+비율) | +0.9252 |
  | 10/17-18 (검증) | +0.6828 |
  | 10/14 (전부 고정) | +0.0203 |
  | 학습셋 전체 | **+0.7083** |
  | 전체 3,066행 | +0.7419 |

  이전 판의 "거의 완전 공선 ≈ 0.9988"은 **틀린 값이 아니라 범위 표기가 빠진 것**이었다.
  유량 스윕 캠페인 내부에서는 사실이며, 학습셋 전체로는 +0.7083이다.
- **압력은 물리적으로는 중요하다:** 하이브리드 타당성 검증에서 적합한 속도식 기준
  **r ∝ P^2.31** (농도 ∝ 압력, 속도 ∝ 농도^2.31). 10/14에서 압력 13.2 kPa(+0.52%) 변동이
  만드는 물리 예측 ΔX = **+0.0137**, 실제 관측 ΔX = **+0.0097**로 같은 자릿수다.
- **그래도 제외한 확정 사유 3가지:**
  1. 압력을 **독립적으로 조작한 캠페인이 없다.** 유량의 그림자로만 움직였으므로 학습된
     압력 계수는 사실상 유량 효과다.
  2. **케이스 스터디에서 압력을 지정할 수 없다.** PDF §3.3-6은 T·유량·비율만 준다. 또한
     시뮬레이션에서 반응기 압력은 플로우시트가 계산하는 값이라 ONNX와 순환 의존이 생긴다.
  3. **PT-1100은 결과 쪽이다.** 2몰→1몰 반응이라 전환율↑ → 압력손실↓ → 출구압↑.
     10/14 선행/후행 분석에서 전환율이 약 **12분 먼저** 움직인다(최대 상관 +0.984).
     12분은 반응기 응답(2~3분)이 아니라 컬럼→재순환 경로의 시간 규모다.

### 3.4 누수 점검 — PT-1100 vs PT-1004

- **쟁점:** `PT-1100`은 **라벨 생성(SRK의 압력 P)에 쓰인 변수**이면서 동시에 I3 입력
  후보다. CLAUDE.md §2.1은 *"I3 성능이 I1보다 크게 좋게 나오면 개선이 아니라 누수를 먼저
  의심하라"* 고 경고한다.
- **검증 방법:** 라벨에 **쓰인** PT-1100(I3) vs 라벨에 **안 쓰인** PT-1004(I2)를 비교.
  누수라면 I3가 I2보다 유의하게 좋아야 한다.
- **실제:** 선형 평균 RMSE **I2 0.033850 vs I3 0.033855** — 사실상 동일, 오히려 I3가 미세하게
  나쁨. GBR도 I2 0.085526 vs I3 0.085865로 동일.
- **결론:** I3가 I1보다 크게 좋지도 않고, 라벨에 안 쓰인 I2와 구별되지도 않는다. 따라서
  관측된 소폭 개선은 **PT-1100 재사용에 의한 누수가 아니라 "압력 정보 일반"의 기여**로
  해석한다. (I3만 튀었다면 누수를 의심했을 것이나 그런 신호는 없다.)

### 3.5 최종 — 압력 없는 I1 채택

압력의 기여가 공선성으로 무효화되고, I1을 씀으로써 **PT-1100 누수 소지를 원천 회피**하며,
센서 3개로 가장 단순하다. → **I1 확정.**

### 4.2 결정적 발견 — 외삽(extrapolation) 문제

기준선의 GBR 열세가 "성능 부족"인지 "구조적 한계"인지 가르기 위해, 학습 온도범위를
정량화하고 그 밖에서 각 모델의 거동을 시험했다(Phase 7).

**외삽 구간 정량화:**
- 학습셋 TT-1006 **최댓값 349.977 °C**(CLAUDE.md §5 기준값 일치), 350 °C 이상 **0행**.
- 검증셋·케이스스터디는 **350~365 °C**를 요구 → **15 °C 폭이 학습범위 밖 = 외삽 필수**.

**TT-1006 스윕 시험(330→370 °C, 다른 입력은 10/12 정상운전 고정):**

| TT-1006 | LinReg (I2/r0) | GBR (I3/r1) |
|:-------:|:--------------:|:-----------:|
| 349 (학습 상한 부근) | 0.82422 | 0.83749 |
| 350 | 0.85233 | 0.84626 |
| 355 | 0.99286 | **0.84626** |
| **356** | **1.02097 ← X>1 위반** | 0.84626 |
| 365 (케이스 상한) | **1.27393** | **0.84626 ← 평탄화** |

- **GBR·트리 계열(6종):** 학습 상한(349.977 °C) 바로 뒤 **350 °C부터 0.84626으로 완전
  평탄화**(이후 변화 0). 트리가 학습범위 밖에서 마지막 잎 값으로 고정되는 **구조적 성질**.
  검증셋 실제 X는 0.84~0.95까지 오르는데 GBR은 이를 전혀 못 따라간다.
  → **`max_depth` 조정으로 해결 불가**(내삽 정확도를 올려도 외삽은 여전히 상수).
- **1차 무처리 선형:** 방향은 물리(고온→고전환)와 맞으나 **356 °C에서 X=1.02**로 물리
  상한 1.0을 초과. 케이스 상한 365 °C에서는 **1.27**(불가능한 값).

**내삽 재현 확인(10/12, Phase 8):** 두 모델 모두 자기 학습 라벨 대비 오차 0.1% 이내
(LinReg −0.081%, GBR +0.014%). → **GBR의 열세는 내삽 정확도가 아니라 오직 외삽에서만**
발생함을 확정. (10/12 정상운전 X = **0.615885**, CLAUDE.md §5 기준값 일치.)

> **핵심 통찰:** 케이스 스터디가 학습범위 밖(365 °C까지) 예측을 요구하는 이상,
> **외삽 거동은 정확도만큼 중요한 선택 기준**이다. 이 발견이 이후 모든 모델 판단의 축이 됐다.

  상수로 고정. 구조적 한계.
- **발산(divergence):** 2차 다항·로짓 2차·MLP — 좁은 학습구간의 곡률이 외삽에서 폭주.
- **위반(violation):** 1차 무처리·MLP — X>1의 물리적으로 불가능한 값.

**상위 12위를 로짓 12개 조합이 독점**했고, 13위 이하(하드클립/Ridge/Lasso)는 한 단계 낮다.

## 5. 개선 시도와 그 실패 (Phase 10-C)

로짓 1차가 잠정 1위였지만, "더 개선할 수 있지 않은가"를 물리·통계적으로 파고들었다.
결과는 **전부 실패**였고, 그 실패가 곧 "로짓 1차가 실질 최선"이라는 증거가 됐다.

### 5.1 오차 구조 분석 — 어디서 틀리는가

로짓 1차 I1/r0의 검증 오차를 구간별로 분해(kg/h):

| 축 | 구간 | \|오차\|평균 | 편향 | 관찰 |
|----|------|-----------:|-----:|------|
| 온도 | 335–350 °C | ~102 | **+**(과대) | 저온에서 과대예측 |
| | 355–360 °C | **218.75** | **−218.19** | 최대 오차원, 과소예측 |
| 전환율 | 0.30–0.70 | ~130 | **+**(과대) | |
| | 0.85–1.00 | 210~350 | **−**(과소) | 상한 근처 포화 못 따라감 |
| 내삽/외삽 | 내삽(≤349.977) | 105.69 | +79.64 | **부호 반전** |
| | 외삽(>350) | 133.09 | −70.78 | |

- **편향의 부호가 뒤집힌다:** 저전환·저온에서 과대(+), 고전환·고온에서 과소(−).
- **최대 오차원은 355–360 °C 외삽 + X>0.85 고전환 구간**(물리적으로 같은 영역). 로짓
  모델이 상한 근처 급포화를 다 못 따라가 과소예측한다. X 0.95–1.00은 **검증셋에 9개뿐**
  이라 오차가 특히 크다(데이터 희소).

### 5.2 2차 다항 — 발산 (실패)

- **기대:** 반응속도의 온도 비선형(Arrhenius형)을 2차항으로 근사하면 고온 곡률을 잡아
  개선될 것.
- **실제:** 로짓공간 2차 다항의 검증 쿠멘 오차 **17.47%**(로짓 1차 3.03%의 5배 이상).
  일반공간 2차는 아예 **>25% 발산**이라 사전 배제.
- **왜:** 학습 온도구간이 **330~350 °C로 약 30 °C밖에 안 되게 좁다.** 이 좁은 구간에서 2차항
  계수가 미세한 곡률에 과적합되고, 그 곡률이 외삽(350~365 °C)에서 급격히 증폭돼 발산한다.
  좁은 구간에서 고차항은 신호가 아니라 잡음을 학습한다.

### 5.3 물리 기반 입력 변환 — 공선성으로 무효 (실패)

- **기대:** 로짓은 유지하되 입력을 물리적으로 변환하면 개선될 것. Arrhenius **역온도
  (1000/T_K)**, 체류시간 **역유량(1/FT)** 을 시도.
- **실제:**

  | 변환 | 쿠멘% | 판정 |
  |------|------:|------|
  | 없음(baseline) | **3.19** | 최선 |
  | 1/T (invT) | 3.44 | 악화 |
  | 1/FT (invF) | 4.28 | 악화 |
  | 1/T + 1/FT | 4.32 | 악화 |

  **세 변환 모두 악화.**
- **왜:** 좁은 온도범위(330~360 °C) 탓 **T와 1/T_K의 상관이 −0.999924**(거의 완전 공선).
  두 변수가 사실상 같은 방향이라 Arrhenius 곡률이 드러나지 않고, 역변환은 예측력을
  더하지 못한 채 조건수만 악화시킨다. — 물리적으로 옳은 변환이 **데이터 범위의 한계
  때문에** 효과가 없었던 사례.
- **부수 확인 — `1000/T_K`의 1000은 결과와 무관:** OLS는 스케일 불변이나, 원시 `1/T_K`
  (≈0.0016)는 조건수가 커(≈1e8) lstsq가 수치붕괴(RMSE 0.2433). 표준화하면 `1/T_K`와
  `1000/T_K`가 RMSE **0.0240157582로 소수점까지 동일**. → 1000은 조건수 보정용일 뿐,
  invT 결과(3.44%)는 스케일과 무관한 공정 비교값.

### 5.4 SVR / GPR 공정 재평가 — 커널 외삽 평균회귀 (실패)

- **기대:** 커널 모델(SVR·GPR)이 기본 설정에서 진 것은 스케일링·하이퍼파라미터 탓일 수
  있으니, 스케일링·설정을 조정해 공정하게 재평가하면 나아질 것.
- **실제:** 재평가 후에도 SVR **26.62%**, GPR **93.00%**, MLP **45.34%**로 크게 열세.
- **왜:** 커널·사전평균 기반 모델은 학습 데이터에서 먼 입력에서 **평균으로 회귀**한다.
  GPR은 표준화된 사전평균 0으로(365 °C 예측 0.000), SVR은 서포트벡터 영향권 밖에서
  0.576으로 붕괴. 외삽이 필수인 이 과제에 커널의 평균회귀 성질은 구조적으로 불리하다.

### 5.5 결론 — 남은 개선은 모델 구조가 아니다

- 시도한 17개 기법 중 **로짓 1차만이 성능·물리타당성을 동시에 만족**했고, 대안(트리·커널·
  신경망·정규화·다항·입력변환)이 **모두 열세**임을 실증했다. **모델 구조로는 로짓 1차가
  실질 최선**이며 구조적 추가 개선의 여지는 사실상 없다.
- **남은 개선은 Phase 11의 전체(10/13~18) 재학습뿐이다.** 검증셋이 학습에 포함되면 현재
  최대 오차원인 355–360 °C가 외삽→내삽으로 바뀌어 오차가 줄 것으로 예상되나, 이는
  **모델 개선이 아니라 데이터 범위 확대**에 의한 것이다.
- **잔여 오차의 하한:** (a) 10/14 노이즈 바닥 σ≈0.003(입력 고정에도 남는 변동),
  (b) 고전환 데이터 희소(검증셋 X>0.95가 9개). 이 두 한계는 재학습으로도 남으며,
  RMSE를 더 낮추는 것은 구조가 아니라 데이터의 문제다.

## 6. 최종 확정 — 로짓 변환 1차 선형

### 6.1 채택 근거
1. **성능 최고:** 전 모델 152개 중 로짓이 상위 12위 독점. 검증 쿠멘 오차 3.03~3.19%로
   차선(하드클립 4.30%)을 뚜렷이 앞선다.
2. **물리 [0,1] 구조적 보장:** 시그모이드 역변환이 출력을 항상 (0,1)에 가둔다. 365 °C에서도
   예측 0.968로 **상한 위반 0**. 하드클립처럼 위반을 "가리는" 것이 아니라 **원천 차단**.
3. **전 대안 열세 실증:** 트리(평탄화)·커널(평균회귀)·신경망(발산)·다항(발산)·정규화(클립
   의존)·입력변환(공선)이 모두 열세임을 데이터로 보였다.

### 6.2 조합 선정 (근소차 → 단순·해석 우선)
상위 로짓 12개가 RMSE 0.0209~0.0224로 근소해, *"근소하면 단순한 쪽"* 원칙 적용.

| 축 | 선정 | 근거 |
|----|------|------|
| 입력 | **I1** | 3개로 가장 단순, PT-1100 누수 소지 원천 회피, 로짓 내 I1이 최상위 |
| 라벨 | **r0** | 원본 직접 라벨, 재순환 조성 가정 불필요 → 해석·방어 용이 |

**최종 후보:** `로짓 1차 · I1 · r0` → RMSE **0.02222**, MAPE **2.4001**,
R² **0.98077**, 쿠멘 **3.1908%**, 365 °C 예측 **0.9684**(위반 없음).
(`results/linear2_logit_I1_r0_unweighted.json`)
**대안(최고 성능 우선):** `I1 · r1` → RMSE 0.020987, 쿠멘 3.0504%.
r0/r1 최종 선택은 시뮬레이션 하류 계측 재현으로 판별(유보).

### 6.3 eps 안정성 — 임의성 없음
- **쟁점:** 로짓변환의 경계 클립값 `eps`가 임의 상수 아닌가? (CLAUDE.md §1-4 임의값 금지)
- **확인:** eps를 **1e-3 ~ 1e-8**로 바꿔 재적합해도 검증 RMSE가 **0.0208608066으로 소수점
  10자리까지 완전히 동일**. 학습 라벨 X 범위가 0.294~0.855로 [0,1] 경계에서 멀어 **어떤
  eps에서도 클립이 한 행도 발동하지 않기** 때문(클립 발동 0행). → eps 선택은 결과에 영향
  없음. 지시서 기본값 1e-6 사용.

## 7. 시뮬레이션 통합의 시행착오

ML 출력(ONNX)을 AVEVA 반응기 R-1100에 연결하는 과정에서도 여러 막다른 길이 있었다.
(`docs/시뮬레이션_인수인계.md`)

### 7.1 출력 연결 방법의 실패들
- **시도 1 — `X[PROPENE]`에 방정식 직접 대입:** "equation has error". `X[PROPENE]`는
  솔버의 **결과 변수**라 방정식 좌변에 놓을 수 없다.
- **시도 2 — `Xrxn[1]` 상수식 대입:** 역시 실패.
- **해결 — 스트림 몰유량으로 반응량(진척도) 지정:** 전환율을 직접 대입하는 대신 "반응한
  프로펜 몰유량"을 정합한다. `X[PROPENE]` spec을 **해제**한 뒤:
  ```
  R-1100.X[PROPENE] * "R-1100_in".Fc[PROPENE]
      = ONNX1.y[1] * ("FCV-1004_out".W * 3600 * 0.94773 / 42.081)
  ```
  좌·우변 모두 "반응한 프로펜 몰유량[kmol/h]"으로, ONNX 전환율(신선 프로펜 기준)과 AVEVA
  전환율(입구=신선+재순환 기준)의 **기준 차이(1.6~2.7%)를 반응량 수준에서 일치**시킨다.

> **정정한 판단(§8-④):** 초기에 "ONNX 출력을 X[PROPENE]에 대입하면 재순환 때문에
> **순환참조**가 생긴다"고 우려했으나, AVEVA가 **방정식 기반 동시 솔버**라 진척도 방정식
> 하나로 처리 가능함을 확인해 해소했다.

### 7.2 정정한 단위·경로 오류
- **3600 단위 오류:** 프로펜 유량 매핑에서 kg/s→kg/h 환산(`×3600`)을 누락하면 값이 3600배
  틀어진다. 오류 없이 조용히 오답이 나오므로 특히 위험. (D절·E절 모두 `×3600` 명시.)
- **ONNX 파일 한글 경로 문제:** ONNXAdaptor의 Path 인식이 한글·공백 경로에서 실패할 수
  있어, `C:\reactor_onnx\` 같은 **한글·공백 없는 경로** 권장으로 정정.
- **ONNX export 방식(방법 A 확정):** 시그모이드 역변환을 **ONNX 그래프에 Sigmoid 노드로
  내장**해, ONNX가 곧바로 전환율(0~1)을 출력하도록 export. 시뮬레이션 쪽에서 로짓·지수
  계산이 불필요. sklearn(Python) 예측과 ONNX 출력이 **최대 3.5e-07** 차이로 일치(float32
  변환오차 포함, 기준 1e-4 충족). r0/r1 두 파일 export 완료.
