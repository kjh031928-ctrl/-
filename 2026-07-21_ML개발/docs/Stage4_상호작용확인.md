## Q1. 입력 I1→I1b 로 바꿀 때 순위가 유지되는가 — 아니오(상호작용 확인)

- **Spearman(I1, I1b) 검증 = +0.283**(약함) · 블록20% = +0.800.
- **I1b(총유량)의 이득은 모델 구조에 의존한다** [계산]:

| 모델 | 변환 | I1 검증 | I1b 검증 | 방향 |
|---|---|---|---|---|
| Linear1 | logit | 0.02099 | 0.02285 | **악화** |
| Linear1 | arcsin | 0.01803 | 0.01979 | **악화** |
| Linear1 | log1m | 0.03674 | 0.03825 | **악화** |
| Ridge Poly2 | logit | 0.01929 | 0.01673 | 개선 |
| Ridge Poly2 | arcsin | 0.02473 | 0.02332 | 개선 |
| Ridge Poly2 | log1m | 0.01917 | 0.01842 | 개선 |
| Poly2 | logit | 0.02111 | 0.01656 | 개선 |
| Poly2 | arcsin | 0.02982 | 0.02327 | 개선 |
| Poly2 | log1m | 0.01593 | 0.02904 | **악화** |

- **배포본(Linear1/logit) I1b 실익 = 없음**: I1 0.02099 → I1b 0.02285 (**악화**). Linear1 은 전 변환에서 I1b 로 악화한다. 반면 Ridge Poly2·Poly2 는 개선한다. 즉 I1b 는 다항 모델에서만 이득이 있어, **입력세트 선택이 모델 선택과 분리되지 않는다.**

## Q2. 유의한 순위 역전 쌍 (잭나이프 CI 양쪽 0 배제 + 부호 반전)

- **1쌍 존재** [계산]:
  - (Poly2/logit) vs (Poly2/log1m): I1 에서 Δ=+0.00518, I1b 에서 Δ=-0.01248 → 입력 바뀌자 우열이 유의하게 뒤집힘.
- 즉 '어느 변환이 더 낫다'는 결론이 입력세트에 따라 통계적으로 뒤집히는 경우가 실제로 있다.

## Q3. 순차 승자 vs 격자 승자

- 순차 스크리닝 승자: **Ridge Poly2/logit/I1**.
- 격자 블록20% 승자: **Ridge Poly2/log1m/I1b** (블록20% 0.007249, 검증 0.018415).
- **둘이 다르다.** 격자를 한꺼번에 최적화하면 log1m/I1b 조합이 블록20% 최소가 되나, log1m 은 구조적 [0,1] 보장이 아니고(Linear1 에서 26/27 이탈) I1b 이득은 다항 모델 한정이다. → 순차 스크리닝의 승자와 격자 승자가 일치하지 않는다는 것 자체가 '단계 독립' 가정이 근사임을 보인다.

## Q4. 물리검사(27/27·9/9)가 전 칸에서 유지되는가 — 아니오

- 전 칸 유지: **False**. 예외 [계산]:
  - Linear1/log1m/I1: **26/27·9/9**
  - Linear1/log1m/I1b: **26/27·9/9**
  - Ridge Poly2/arcsin/I1: **27/27·8/9**
  - Ridge Poly2/arcsin/I1b: **27/27·8/9**
  - Poly2/arcsin/I1b: **27/27·8/9**
- **logit 은 전 6개 (모델×입력) 조합에서 27/27·9/9 를 유지**한다. arcsin 은 다항 모델에서 T-단조가 8/9 로 깨지고, log1m 은 Linear1 에서 범위이탈(26/27)한다. → 물리 안전성까지 요구하면 **logit 이 유일하게 전 칸을 통과**하며, 이는 Stage 2 의 결론(구조적 안전 = logit)을 격자 전체에서 재확인한다.

## 종합 판정

1. 순차 스크리닝의 '단계 독립' 가정은 **엄밀히는 거짓**이다: 입력을 바꾸면 모델·변환 순위가 유의하게 뒤집히고(Spearman 검증 +0.283, 유의 역전 1쌍), 격자 승자가 순차 승자와 다르다.
2. 그러나 **물리 안전성을 제약으로 걸면 그 흔들림이 사라진다**: logit 은 전 칸 27/27·9/9 를 유지하고, 배포본(Linear1)에는 I1b 이득이 없다. → 성능 순위만으로 모델을 고르면 안 되고(§3.3-1 방어), 제약(물리·배포 가능성)이 선택을 안정시킨다.
3. 배포 권고: **입력 I1 유지**(I1b 는 배포본에 실익 없음), **변환 logit 유지**(유일한 전 칸 물리 통과). 모델은 Linear1(현행)·Ridge Poly2 가 잭나이프 동률이며, 블록20% 로는 Ridge Poly2 가 우선 후보.

## 보고서용 설명

**1) 이 Stage 가 답하는 항목:** 목차 4.3 보조 / 내부 §3.3-3 보조 — '순차 비교가 공정했나(상호작용)'.

**2) 무엇을 왜 했는지:** 앞 단계들은 모델·타깃변환·입력을 하나씩 따로 골랐는데, 이렇게 순차로 고르면 각 선택이 서로 독립이라고 암묵적으로 가정한다. 이 가정이 맞는지 보려고, 상위 3모델×3변환×2입력을 한꺼번에 18칸 격자로 돌려 순위가 유지되는지 확인했다. 결론은 순위가 입력에 따라 흔들리지만(가정은 근사), 물리적 안전성을 함께 요구하면 로짓 변환이 유일하게 전 칸을 통과해 선택이 안정된다는 것이다.

**3) 핵심 수치:** Spearman(I1,I1b) 검증 **+0.283** [계산]. 유의 순위역전 **1쌍**(Poly2 안에서 logit↔log1m, I1 Δ+0.00518 / I1b Δ−0.01248) [계산]. 물리 전 칸 유지: **logit 만**(arcsin 8/9, log1m 26/27 예외) [계산]. 배포본 Linear1: I1 0.02099 → I1b 0.02285(악화) [계산].

**4) 예상과 달랐던 점(반례):** 총유량(I1b)은 다항 모델에서는 검증을 개선하지만 **배포본(1차 선형)에서는 오히려 악화**한다. 또 격자를 한꺼번에 최적화하면 순차 승자와 다른 조합(log1m/I1b)이 뽑힌다. 이 두 반례가 '성능 숫자 하나로 최적 조합을 못 고른다 → 제약으로 좁혀야 한다'는 §3.3-1 논리를 강화한다.

**5) 재현 안 된 값:** 프롬프트의 Linear1 I1→I1b(0.02222→0.02428)는 **방향(악화)만 재현**되고 절대값은 재현 로짓값(0.02099→0.02285)과 다르다. 재현값을 따르며 `results/stage1_비재현목록.md` 에 기록.
