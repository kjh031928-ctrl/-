### 왜 블록20% 인가 — LOCO-4 는 검증 순위와 정반대 [계산 재현]

8모델(I1, 로짓) 튜닝기준별 값과 홀드아웃(검증) 비교:

| 모델 | LOCO4 | 블록20% | 홀드아웃 |
|---|---|---|---|
| Linear1 | 0.06946 | 0.00837 | 0.02099 |
| Linear2(Poly2) | 0.19134 | 0.00746 | 0.02111 |
| Ridge2(Poly2+Ridge) | 0.12435* | 0.00741* | 0.01929* |
| KNN5 | 0.06005 | 0.01424 | 0.07230 |
| RF | 0.06454 | 0.01257 | 0.09980 |
| ExtraTr | 0.06585 | 0.01284 | 0.07805 |
| GBR | 0.06378 | 0.01583 | 0.08219 |
| MLP64 | 0.10229 | 0.00888 | 0.05171 |

- **Spearman(LOCO4, 홀드아웃) = −0.714** (재현, ref −0.714) · **Spearman(블록20%, 홀드아웃) = +0.810** (재현, ref +0.810).
- LOCO4 1위=KNN5 / 블록20% 1위=Linear2 / 홀드아웃 1위=Ridge2 (Ridge2 는 설정 미상으로 근사재현, * 표시).
- 이유: LOCO4 는 "학습에서 안 본 축으로 외삽"을 요구한다(캠페인마다 다른 축 1개씩만 스윕:
  10/13 유량 · 10/14 무조작 · 10/15 유량+B/P · 10/16 온도). 그 시험은 "모르면 평균"을 답하는
  유연한 모델에 유리해 실제 검증 순위와 반대가 된다 **[주어짐: 사용자 근거]**.
- ⚠ 블록20% 절대값은 홀드아웃의 0.13~0.42배로 낙관적 → **순위 전용, 성능 수치로 보고 금지.**
- Stage 1 전체 22모델에서도 Spearman(블록20%,검증)=**+0.822** ≫ Spearman(LOCO4,검증)=**+0.397** [계산].

### [설계결정] LOCO-5 를 §1-2 위반 없이 구현

§1-2 는 10/17-18 에 절대 fit 금지. LOCO-5 를 순진하게 돌리면 4폴드에서 10/17-18 에 fit 하게 된다.
해소: **10/17-18 홀드아웃 = 주 분할 모델(10/13-16 학습)**, 나머지 4개(13/14/15/16) 홀드아웃은
다른 학습 캠페인으로만 학습. 이렇게 5-캠페인 강건성을 얻으며 10/17-18 에는 결코 fit 하지 않는다.
LOCO-5 는 강건성 보고용, 튜닝엔 쓰지 않는다.

## 0-3. 불확실성 — 블록 잭나이프(주) + 부트스트랩(교차) [수정 2]

**주 방법: 블록 잭나이프(delete-one-block, 결정적).** 검증 661행을 60분 블록 12개로 나눠 하나씩 빼고
`pseudo_k = nb·RMSE_full − (nb−1)·RMSE_(-k)`, `SE = std(pseudo)/√nb`, `CI = mean(pseudo) ± 1.96·SE`.
난수가 없어 재현성 논란이 없다. `block_jackknife_ci` / `_delta_ci`. 블록 60·120분 둘 다 산출, 본문은 더 넓은(보수적) 쪽.

**교차확인: 블록 부트스트랩**(60분, 2000회, seed 42). `bootstrap_rmse_ci` / `bootstrap_delta_ci`.

재현(Linear1, 검증셋) [계산 재현]:

| 방법 | RMSE | SE | 95%CI | 폭 |
|---|---|---|---|---|
| 잭나이프 60분(12블록) | 0.02099 | 0.00421 | [0.01316, 0.02966] | 0.01650 |
| 잭나이프 120분(6블록) | 0.02099 | 0.00361 | [0.01424, 0.02838] | 0.01415 |
| 부트스트랩 60분 | 0.02151† | — | [0.01373, 0.02901] | 0.01528 |

† 부트스트랩 RMSE 는 재표본 평균. 잭나이프 60분이 가장 넓어 **본문은 [0.01316, 0.02966] 사용**.
모든 값이 사용자 기준값과 일치(잭나이프 SE 0.00421·CI·폭, 부트 CI). Linear1 vs GBR ΔRMSE:
잭나이프 Δ=**−0.06121**, CI[−0.08238, −0.04111] (재현 정확).

## 0-5. 물리 타당성 (합격/불합격)

격자 27점 = T{335,350,365} × 총유량{15000,16500,18000} × B/P{4,5,6} **[주어짐]**.
격자→입력: TT-1006=T, FRC-1004=B/P, **FT-1004 = 총유량/(1+B/P)**. I1 전용. `physical_check`
판정: ① T↑→X↑ (슬라이스 x/9) ② X∈[0,1] (x/27) ③ 365°C(학습 최대 349.977 초과) 외삽 유계·비발산.

**[계산] 단조성 방향은 실측에서 유도**: 밴드(B/P 5±0.05, T 350±3, 10/12 제외)에서 총유량 16200→18000

따라서 기준은 **총유량↑→X↑**(양). "총유량↑→X↓"(일반론)은 성립하지 않는다. 로짓 1차 선형: 27/27∈[0,1],
9/9 슬라이스 T-단조, 외삽 유계 → 합격.

## 보고서용 설명

**1) 이 Stage 가 답하는 항목:** 목차 4.3 / 내부 §3.3-3 — "정확도를 무슨 기준으로 쟀나".

**2) 무엇을 왜 했는지:** 어떤 모델 비교든 평가 규약이 먼저 서지 않으면 숫자가 의미를 잃는다. 시계열
데이터라 아무렇게나 섞어 나누면(무작위 분할) 같은 운전점의 이웃 시점이 학습·검증에 함께 들어가 성능이
부풀려진다. 그래서 분할을 캠페인(날짜) 단위로 고정하고, 검증 캠페인(10/17-18)은 최종 확인 1회에만
쓰기로 했다. 하이퍼파라미터·모델 선택은 학습 캠페인 안에서 "각 캠페인 뒤 20% 시간구간"(블록20%)으로만
정한다. 불확실성은 난수가 없는 블록 잭나이프로 재고, 예측이 물리적으로 가능한 범위([0,1])에 있는지도
성능과 별개로 검사한다.

**3) 핵심 수치:** 로짓 1차 선형 검증 RMSE **0.020987**·R² **0.98290**·큐멘 오차 **3.0504%** [계산].
잭나이프 60분 95%CI [0.01316, 0.02966] [계산]. 큐멘 kg/h = X × 프로펜몰유량 × **120.196**[주어짐] 이며
프로펜몰유량 = **0.94773**[계산, Appendix B] × FT-1004 / **42.081**[주어짐]. 블록 길이 60분은 잔차
자기상관이 120분에서야 0 에 수렴한다는 [계산] 근거로 정했다.

**4) 예상과 달랐던 점:** 흔한 직관인 "총유량↑ → 체류시간↓ → 전환율↓"은 이 공정에서 **성립하지 않는다**.
실측은 반대로 총유량↑ → 반응기 압력↑ → 전환율↑ 이며(corr(총유량, PT-1004)=+0.9988 [계산]), 단조성 기준을
일반론이 아니라 이 실측에서 유도했다.

**5) 재현 안 된 값:** 없음(기존 확정값 전부 재현). 미세 불일치 목록은 `results/stage1_비재현목록.md`.
