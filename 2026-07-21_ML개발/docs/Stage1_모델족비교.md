## (d) 관찰 사실 요약

1. 블록20% 최우수와 검증 최우수가 모두 **Ridge Poly2**(검증 RMSE 0.019293) 로 일치했다. 검증 상위권은 선형 계열(Ridge Poly2·Linear1·PLS·Poly2·Ridge1)이 차지했다.
2. 잭나이프 기준 검증-최우수와 구분되지 않는 모델이 7개로, 상위 선형 모델들은 서로 통계적으로 동률이다.
3. Spearman(블록20%,검증)=+0.822 로 블록20% 는 검증 순위를 잘 예측하나, Spearman(LOCO4,검증)=+0.397 로 LOCO4 는 약하다 → 튜닝 기준으로 부적합.
4. 트리·거리 계열(RF·ET·GBR·KNN·DecisionTree)과 GaussianProcess 는 검증 RMSE 0.06~0.16 으로 선형 대비 뚜렷이 나빴고, 블록길이 전 구간에서 최우수와 구분됐다.
5. ONNX 변환은 Dummy·HistGradientBoosting 2종이 실패(대회 §3.1 미충족). 나머지는 최대절대차 ≤ 2e-6 수준.

**1) 이 Stage 가 답하는 항목:** 목차 4.3 / 내부 §3.3-1 — "왜 이 모델을 골랐나".

**2) 무엇을 왜 했는지:** 단순(선형)부터 복잡(트리·신경망·가우시안 과정)까지 22개 모델족을 같은 규약으로
훑었다. 목적은 "1등 뽑기"가 아니라, 성능 최상위가 곧 채택이 아님을 보이고 선정 기준을 넓히는 것이다.
승자 선택은 검증셋이 아니라 블록20%(내부검증)로만 했고, 검증 RMSE 는 확인용으로만 봤다.

**3) 핵심 수치:** 블록20% 최우수 = **Ridge Poly2**(검증 0.01929)로 검증 최우수와 일치 [계산]. 상위권은
전부 선형 계열이고 잭나이프 기준 7개가 서로 동률 [계산]. Spearman(블록20%, 검증)=**+0.822** 로 내부검증이
검증 순위를 잘 예측하나, 옛 기준 LOCO4 는 **+0.397** 로 약해 폐기했다 [계산].

**4) 예상과 달랐던 점(반례):** Poly3 는 블록20% 11위인데 검증 22위(RMSE 0.377)로 외삽에서 발산했다. 즉
내부검증 순위가 좋아도 학습 범위를 넘는 케이스(365°C)에서 무너질 수 있어, 성능 단독으로 모델을 고르면
안 된다. 이 반례가 "물리 안전성·외삽 강건성을 선정 기준에 넣는다"는 §3.3-1 논리의 근거다.

**5) 재현 안 된 값:** 없음(핵심 지표 전부 재현). Ridge2 설정 미상 등 미세 8건은 `results/stage1_비재현목록.md`.
