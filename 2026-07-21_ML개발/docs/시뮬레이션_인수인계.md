## (C) AVEVA ONNXAdaptor 설정 절차 (Attachment 2 예제 순서)

1. **Model Writing** 역할에서 **Preview 라이브러리**를 import 한다.
2. **ONNXAdaptor** 모델을 흐름도(flowsheet)에 드래그 → `ONNX1` 블록이 생성된다.
3. `ONNX1`의 **Path** 파라미터에 (B)에서 메모한 **절대경로**를 입력한다.
4. **Setup**을 **Solve → Configure**로 토글한 뒤, 모델의 **Description**을
   **NI / NO / InputLabel / OutputLabel** 에 복사한다.
5. **NI = 3, NO = 1** 인지 확인한다(입력 3개, 출력 1개).

## (D) 입력 매핑 (단위 변환 포함 — 틀리면 오류 없이 조용히 오답)

**입력 순서는 반드시 `[온도, 프로펜유량, 질량비]`.** 순서가 바뀌면 완전히 다른 값이 나온다.

```
Eqn:  ONNX1.x[1] = "HX-1005_Tube_Out".T - 273.15               // K → °C  (반응기 입구온도)
Eqn:  ONNX1.x[2] = "FCV-1004_out".W * 3600                     // kg/s → kg/h  (프로펜 스트림 질량유량)
Eqn:  ONNX1.x[3] = "T-1001_out".W / "FCV-1004_out".W           // 벤젠/프로펜 질량비(무차원)
```

| 항목 | 값·의미 | 출처 |
|------|---------|------|
| `x[1]` | 반응기 입구온도 [°C] = TT-1006.PV에 해당 | 학습 입력 1번(TT-1006) |
| 온도 소스 | `HX-1005_Tube_Out`(히터 출구 = 반응기 입구). `R-1100_in.T`를 쓰면 반응기 블록과 **순환 참조**가 생겨 상류 스트림에서 읽는다. 두 스트림의 T·P는 동일해야 정상(실측 확인: 623.15 K / 2,535.6 kPa 일치) | 07-28 시뮬레이션 구현 |
| `x[2]` | 프로펜 스트림 질량유량 [kg/h] = FT-1004.PV | 학습 입력 2번(FT-1004) |
| `x[3]` | 벤젠/프로펜 **질량비**(몰비 아님) = FRC-1004.PV | 학습 입력 3번(FRC-1004) |
| `273.15` | 켈빈→섭씨 오프셋(표준 절대영도) | 단위 상수 |
| `3600` | kg/s→kg/h(초→시간) 환산 | 단위 상수 |

> **주의:** `x[3]`은 **질량비**다(정상운전점 5.0, 실측평균 4.961). 같은 조건의 몰비(2.820)를
> 넣으면 안 된다.

## (E) 출력 연결 — 진척도 정합 (이 대화에서 확정한 핵심)

ONNX 출력은 **신선 프로펜 기준 전환율**이고, AVEVA `R-1100.X[PROPENE]`는 **반응기 입구
프로펜(=신선+재순환) 기준**이다. 재순환 프로펜 때문에 기준이 1.6~2.7% 어긋나므로,
전환율을 직접 대입하지 말고 **반응량(진척도)** 으로 정합한다.

1. **R-1100의 `X[PROPENE]` spec을 해제**한다(체크 해제). — 이걸 빠뜨리면 과지정 오류가 난다.
2. 아래 방정식을 추가한다 (**07-28 시뮬레이션의 실제 구현 형태**):

```
Eqn:  "HX-1005_Tube_Out".Fc[PROPENE] - "R-1100_out".Fc[PROPENE]
        = ONNX1.y[1] * "FCV-1004_out".Fc[PROPENE]
```

> 좌변 = 반응한 프로펜 몰유량(입구 − 출구), 우변 = ONNX 전환율 × **신선** 프로펜 몰유량.
> AVEVA가 계산한 `Fc[PROPENE]`를 그대로 쓰므로 `0.94773 / 42.081`을 손으로 곱할 필요가 없다.
> 상수 하드코딩이 사라져 아래 구식보다 안전하다.

<details><summary>구식 표기(초판) — 수학적으로 동등</summary>

```
Eqn:  R-1100.X[PROPENE] * "R-1100_in".Fc[PROPENE]
        = ONNX1.y[1] * ("FCV-1004_out".W * 3600 * 0.94773 / 42.081)
```
</details>

| 항목 | 의미 | 출처 |
|------|------|------|
| 좌변 | AVEVA 내부 프로펜 전환율 × 반응기 입구 프로펜 몰유량 = **반응한 프로펜 몰유량** | AVEVA 변수 |
| `ONNX1.y[1]` | ONNX 출력 = 신선 프로펜 기준 전환율(0~1) | 본 모델 출력 |
| `"FCV-1004_out".W * 3600` | 프로펜 스트림 질량유량 [kg/h] | (D) x[2]와 동일 |
| `0.94773` | 프로펜 공급 스트림의 **프로펜 질량분율**(나머지 0.05227은 프로판) | CLAUDE.md §2.3 / Appendix B Table 3 |
| `42.081` | 프로펜 몰질량 [kg/kmol] | config `properties.MW.propene`(AVEVA 제공값) |
| 우변 | ONNX 전환율 × **신선 프로펜 몰유량**(= 질량유량×질량분율/몰질량) = **반응한 프로펜 몰유량** | 유도식 |

> 즉 좌·우변 모두 "반응한 프로펜 몰유량[kmol/h]"으로, 기준이 다른 두 전환율을
> **반응량 수준에서 일치**시킨다.

**방법 A/B 구분:**
- 본 인수인계는 **방법 A**(시그모이드를 ONNX 그래프에 내장)로 export했다.
  → **`ONNX1.y[1]`이 이미 0~1 전환율**이므로 위 식에 **그대로** 쓰면 된다.
- (참고) 만약 로짓값을 출력하는 모델이었다면(방법 B) `X_conv = 1/(1+exp(-ONNX1.y[1]))`을
  먼저 계산해 대입해야 하지만, **본 모델은 방법 A라 불필요하다.**

## (H) 확정 사항 및 남은 확인

### H-1. r0 / r1 — **r1 확정** (2026-07-31)

**채택: `reactor_conversion_r1.onnx` (재순환 큐멘 1 mol% 가정).**

사유는 하류 계측 비교가 아니라 **시뮬레이션 구성 제약**이다. r0(재순환 큐멘 0 mol%) 가정으로는
현 플로우시트의 실제 조건에서 구성·수렴이 되지 않는다. 초판에 적어 둔 판별 기준
(`AT-1104` ≈ 798 · `AT-1201` ≈ 730 · `FT-1201` ≈ 5115)은 **선택 근거로 쓰지 않는다.**

> **보고서 서술 주의.** "두 가정을 하류 계측으로 비교해 r1이 더 맞았다"고 쓰면 사실과 다르다.
> "시뮬레이션 구성상 r0가 불가하여 r1을 채택했고, r1의 held-out 성능이 r0보다 낫다"가 정확하다.
> held-out 비교(참고): r1 RMSE **0.020987** / 큐멘오차 **3.0504%** vs r0 0.022220 / 3.1908%.
> 즉 성능 면에서도 r1이 불리하지 않다.

### H-2. 케이스 스터디 조작 범위 — **초판 표기 오류 정정**

초판은 "프로펜유량 15000~18000 kg/h"라고 적었으나 **틀렸다.** 대회 문서의
"reactor feed flow rate"는 **혼합 공급 총량**이다.

| 대회 요구 | 시뮬레이션에서 조작할 값 |
|---|---|
| 반응기 온도 335 ~ 365 °C | `TCV-1006`으로 `HX-1005_Tube_Out.T` 조절 |
| **반응기 총공급 15,000 ~ 18,000 kg/h** | `FCV-1004`(프로펜) **2,500 ~ 3,000** + `FCV-1002`(벤젠) **12,500 ~ 15,000** — **둘을 함께** 움직여 비율 5.0 유지 |
| 벤젠/프로펜 질량비 4 ~ 6 | **총공급 18,000 고정**한 채 `FCV-1004` 3,600 → 2,571.4, 벤젠 14,400 → 15,428.6 |

> 총공급 = `FT-1004` × (1 + `FRC-1004`). 프로펜에 15,000을 넣으면 실제의 5~6배가 된다.

## 부록 — 이 모델에 대해 (참고, 통합에는 불필요)

- **레시피:** 로짓 변환 + 1차 선형 회귀 + 입력 3종(I1) + **라벨 r1**. 17개 기법 비교에서
  성능 최고이면서 출력이 **구조적으로 0~1** 을 보장(외삽 시에도 물리상한 위반 없음).
- **학습 데이터:** 전체 10/13~18(2585행). 10/12는 제외.
- **⚠ 성능 지표 주의:** 이 배포본은 10/17-18을 **학습에 포함**하므로 그 구간으로 성능을
  다시 측정할 수 없다. 보고용 성능(예: 전환율 RMSE≈0.021~0.022, 큐멘오차≈3.0~3.2%)은
  **held-out 검증(학습 10/13-16 / 검증 10/17-18)** 에서 얻은 값이며, 배포본은 **동일 레시피**를
  전체 데이터로 재학습한 것이다.
  채택된 r1 조합의 held-out 실측: **RMSE 0.020987 · R² 0.98290 · MAPE 2.3065% · 큐멘오차 3.0504%**
  (`results/linear2_logit_I1_r1_unweighted.json`).
- **ONNX 검증 완료:** sklearn(Python) 예측과 ONNX 출력이 **최대 3.5e-07** 차이로 일치
  (float32 변환 오차 포함, 기준 1e-4 이하 충족). 시그모이드는 ONNX 내부에서 수행됨(방법 A).
- **입력/출력 스펙:** 입력 `X`[N,3] float32 = [TT-1006(°C), FT-1004(kg/h), FRC-1004(무차원)],
  출력 `conversion`[N,1] = 전환율 0~1.
