# CLAUDE.md — 쿠멘 공정 프로펜 전화율 ML 개발 (Phase 2 작성본)

이 파일은 지시서(`Claude_Code_프롬프트.md`)와 대회 조건을 기준으로 작성한 **작업 규범**이다.
모든 세션은 이 문서의 규칙을 최우선으로 따른다. 이 규칙은 기본 동작보다 우선한다.

---

## 1. 절대 금지 사항 (위반 시 즉시 중단·보고)

1. **원본 대회 파일 수정 금지.** `data/raw/README.md`에 위치가 기록된 원본 CSV·PDF·ONNX
   예제 파일을 편집·덮어쓰기·이동·삭제하지 않는다. `data/raw`는 읽기 전용 포인터일 뿐이다.
2. **검증 캠페인(10/17–18)을 학습에 사용 금지.** 10/17–18 데이터는 최종 검증 전용이다.
   학습(fit), 모델 선택, 하이퍼파라미터 탐색, 조기종료(early stopping) 기준,
   피처 선택 등 **어떤 의사결정에도** 이 구간을 사용하지 않는다.
3. **무작위 분할 금지.** `train_test_split`, `KFold`, `shuffle=True` 등 무작위/셔플 기반
   분할을 쓰지 않는다. 데이터는 1분 간격 시계열이므로 무작위 분할은 데이터 누수를 만든다.
   분할은 오직 아래 §2의 **날짜 기준 분할**만 사용한다.
4. **임의 임계값·가정 금지.** 지시서에 명시되지 않은 임계값, 상수, 물성 가정, 전처리 규칙,
   목표 지표 등을 임의로 정하지 않는다. 필요하면 추측하지 말고 질문한다(§4).
5. **표본 가중치 언급 금지 (2026-07-31 확정).** 데이터셋에 `ML_weight`·`TT-1006_rate_C_per_min`
   컬럼이 존재하지만 **최종 모델은 무가중이며 이 컬럼들을 사용하지 않는다.**
   가중 함수의 형태(1/(1+(τ·rate)²))와 시정수 τ=3분은 **근거를 설명할 수 없어 폐기**했다.
   문서·보고서·발표·질의응답 어디에도 가중치와 τ=3분을 쓰지 않는다.
   - 과도/준정상 구분이 필요하면 `docs/질의응답_준비.md` §4-6의 기준을 쓴다:
     **직전 12분 창의 X 변동폭 > 0.003068이면 과도.** 두 상수 모두 데이터에서 직접 읽은 값이다
     (0.003068 = 10/14 입력고정 캠페인의 X 표준편차, 12분 = 10/17 18:00 계단의 정착시간).
   - 반응기 응답 지연은 **2~3분(측정값)**이다. 계단응답·지연스캔·지수평활 3법이 일치한다.
   - 가중/무가중 실험 기록은 `results/*_weighted.json`에만 남긴다(성능 차 0.0001, 무의미).

## 2. 확정 사항 (지시서 §3 — 변경 불가)

### 2.1 입력 / 출력
- **입력 3종 (핵심 세트 I1)**
  - `TT-1006.PV`  : 반응기 입구 온도 (°C). 반응기 응답 지연 **2~3분** (가정값 아님 — 계단응답·지연스캔·지수평활 3법 일치, `docs/질의응답_준비.md` §4-4~4-5).
  - `FT-1004.PV`  : 프로필렌 스트림 질량유량 (kg/h).
  - `FRC-1004.PV` : 벤젠 / 프로필렌 질량유량비 (무차원). Appendix A "Mass flow ratio".
    **질량비이며 몰비가 아님.** 실측 평균 4.961, 정상운전점 5.000. 같은 조건의 몰비는 2.820.
- **선택 입력 후보 (입력세트 I2 / I3)**
  - `PT-1004.PV` : HX-1005 상류 압력 (kPa) — I2.
  - `PT-1100.PV` : 반응기 출구 압력 (kPa) — I3.
- **출력(라벨)** : `X_propene_conversion` — 프로펜 기준 전환율 (0~1).

> **2026-07-31 확정 — 최종 라벨은 `r1`(`X_propene_recycle1`, 재순환 큐멘 1 mol%)이다.**
> 사유는 성능이 아니라 시뮬레이션 구성 제약(r0로는 현 플로우시트 구성·수렴 불가).
> 최종 레시피: **로짓 1차 선형 · I1 · r1 (무가중)** → held-out RMSE 0.020987 · R² 0.98290 ·
> 큐멘오차 3.0504%. 배포본 `onnx/reactor_conversion_r1.onnx`.
> 상세: `docs/시뮬레이션_인수인계.md` (H)-1, `docs/실험결과_정리.md` Phase 10 §4.

> 대조 확인: `config/base.yaml`의 `features.I1/I2/I3`와 일치.
> I1=[TT-1006.PV, FT-1004.PV, FRC-1004.PV], I2=I1+PT-1004.PV, I3=I1+PT-1100.PV.
> `FRC-1001`·`FRC-1002` 태그는 데이터에 존재하지 않으므로 사용 금지.

> **⚠️ 주의 (정보 누수 소지):** `PT-1100.PV`는 라벨 계산(SRK 이분법의 압력 P)에
> 사용된 변수이면서 동시에 I3 입력 후보이다. 라벨 생성에 쓰인 변수를 입력 피처로도
> 넣으면 정보 누수(leakage) 소지가 있다. 이는 지시서가 I3 세트로 이미 확정한 사항이라
> 그대로 유지하되, **I3 결과 해석 시 이 이중 사용을 반드시 명시**하고 I1과의 성능 차이를
> 누수 관점에서 함께 평가한다. I3 성능이 I1보다 크게 좋게 나오면 개선이 아니라 누수를
> 먼저 의심할 것. (같은 이유로 `FT-1004.PV`·`FRC-1004.PV`도 라벨의 몰수 산출에
> 쓰이나, 이는 입력→라벨 방향의 물리적 정의이므로 누수와 구분된다.)

### 2.2 데이터 분할 (날짜 기준, 무작위 금지)
- **학습셋** : 10/13 ~ 10/16
- **검증셋** : 10/17 ~ 10/18 (최종 검증 전용, §1-2 참조)
- **재현확인 전용** : 10/12 (학습·검증 어디에도 쓰지 않음, 재현성 대조용)

### 2.3 물성 상수
- **몰질량 4종** (출처 주석 필수, §3 규칙)
- **프로펜 공급 조성** : 프로펜 질량분율 **0.94773** : 나머지 **0.05227**
- **난수 시드** : `seed = 42` (전 구간 고정)

### 2.4 수치 정밀도
- 라벨 생성·학습은 **float64**로 수행한다.
- **float32는 ONNX export 시점에만** 적용한다. 그 외 어떤 단계에서도 float32로 내리지 않는다.

## 4. 작업 규칙

1. **세션 시작 시 `git pull`**, 세션 종료 시 `commit + push`. (충돌 방지)

## 5. 검증 기준값 (결과 대조용)

아래 값들은 파이프라인이 올바르게 동작하는지 확인하는 **기대 결과값**이다.
계산 결과가 이 값과 어긋나면 코드에 문제가 있는 것이므로 임의 조정 없이 원인을 조사·보고한다.

| 항목 | 기준값 |
|------|--------|
| 재순환 1 mol% 라벨 bracket 실패 | **0건** |
| r0 − r1 평균 차이 | **≈ 0.0097** |
| 에너지수지 상관계수 | **≥ +0.99** |
| 쿠멘 물질수지 (캠페인 평균) | **±3% 이내** |
| 10/14 **변동** 바닥 σ (구 "노이즈 바닥") | **0.003068** |
| 10/12 정상운전 X | **0.615885** |
| full factorial 실행 횟수 | **24회** (구 기록. 가중/무가중 축 폐기 후 유효 조합은 **12회** — §1-5) |
| 학습셋 TT-1006 최댓값 | **349.977 °C** |

> **2026-07-31 용어 변경:** 10/14의 σ=0.003068을 **"노이즈 바닥"이라 부르지 않는다.**
> 잡음이 아니라 압력(r ∝ P^2.31)을 통해 전달된 재순환 표류의 물리 변동임이 확인됐다.
> 값 자체는 그대로 기대값으로 쓰되, "모델이 넘을 수 없는 한계선"으로 서술하지 말 것.
> 근거: `docs/실험결과_정리.md` 검증 3, 루트의 `압력변수_제외근거_검증.py`.
>
> **압력 변수 제외 근거도 전면 개정됨.** "넣었더니 나빠져서 기각"은 **폐기**.
> 블록 부트스트랩 판정 결과 **차이 없음**이며, 제외 사유는 ① 압력 독립 조작 캠페인 부재
